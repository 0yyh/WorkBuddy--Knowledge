# 十四行诗

**十四行诗**（Sonnet）是一种由十四行构成的诗歌体裁。「十四行」这一限定在起初是音乐性的而非文学性的——它对应着意大利十四行体歌（sonetto）中「十四」的固定乐句结构，其后这一行数被文学本身所接管，成为一个独立的体裁单位。**它与相邻概念的关系须先厘清：与「抒情诗」是格律与文体的关系——十四行诗只是抒情诗的一种体裁形态，而非其上位概念；与「词」与「元曲」是可比较的两种长短句体，但词的长短句依据曲牌、十四行诗依据行数与韵式，两者的格律基础不同。** 本词条的处理重心在格律体系：十四行诗的全部技术特征，都源自「十四行」这一形式限定。

本词条按「起源与格律体系 → 彼特拉克的规范 → 莎士比亚体的结构与变奏 → 跨文化移植与改写 → 现代生命与当代复兴」五章展开。

## 导读

- 「十四」的行数最初来自意大利十四行体歌的乐句结构，其后被文学本身所接管。
- 奥古斯丁的《上邪歌》留下回文式布局的痕迹，但十四行的定型通常归于十三世纪。
- 彼特拉克《歌集》确立意大利十四行体的规范：前八行为 octave，后六行为 sestet。
- 莎士比亚体改用三组四行加一组双行的结构，其十四首组诗的次序设计著称。
- 中国古典诗歌无行数体裁的对应形式，但词的长短句与日本／法国的固定句式诗提供了可比较的思路。

> 📝 编者注：人名依大陆通行译法：Petrarch→彼特拉克、Shakespeare→莎士比亚、Goethe→歌德、Schiller→席勒、Augustine→奥古斯丁、Dante→但丁。本词条所述格律术语（中译）在不同选本中处理不一，octave 与 sestet 依内容分别处理为「八行段」「六行段」；本词条所述历史源流为纲要性梳理，具体年代各研究著作略有出入。
