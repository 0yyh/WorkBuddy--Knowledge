# 语法化

**语法化**（Grammaticalization）研究词汇单位如何逐步演变为承担语法功能的成分，以及既有语法标记如何进一步抽象为更泛用的功能范畴。库里沃维奇（Jerzy Kuryłowicz）最早给出经典定义，霍珀（Paul Hopper）与特劳戈特（Elizabeth Traugott）则系统阐述了这一过程的连续性与认知动因。它通常表现为一个词语由实义用法滑向功能用法：意义泛化、形态句法身份减损、语音形式弱化，并在句法槽位中固定下来。语法化把历史语言学的演变观察、语言接触的比较证据与认知语言学的概念动因熔于一炉，与关注跨语言共性的语言类型学、关注演变机制的语言变化研究互补，是普通语言学回答「语法结构从何而来」的核心议题。

本词条按「界定与经典定义 → 词汇到语法的演变机制 → 原则与典型路径 → 案例分析 → 争议与新发展」五章展开。

## 导读

- 语法化是词汇单位逐步获得语法功能、语法标记进一步抽象的连续演变过程。
- 核心机制包括隐喻化、重新分析与类推，常伴随语义泛化与形态减损。
- 去语义化、去范畴化、语音弱化与强化共同刻画语法化的典型路径。
- 跨语言案例（如「去」「将」「把」）显示语法化具有显著的跨语系共性。
- 单向性假说受到反例与挑战，接触引发的「语法化复制」成为新前沿。
