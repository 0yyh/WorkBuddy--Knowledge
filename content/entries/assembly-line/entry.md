# 流水线

**流水线**（Assembly Line）是把产品的装配过程分解为若干标准化工序、让产品沿传送带在工位间流动、每个工人（或机器）只完成其中一道工序的生产组织方式。它把三项早已存在的技术——**可互换零件**（任何一件都能装到任何产品上）、**专业分工**（亚当·斯密制针厂的经典逻辑）、**节奏控制**（以传送带速度统一劳动节拍）——组合成一种全新的生产范式。1913 年，亨利·福特在密歇根高地公园工厂把流水线应用于 Model T 装配：底盘装配时间从十二小时二十八分钟压缩到一小时三十三分钟；到 1920 年代，福特以半价把汽车卖给大众。流水线由此成为「第二次工业革命」的生产范式，也塑造了此后一百年的制造业、劳工关系与消费社会。

本词条按「流水线之前 → 福特的集成 → 大规模生产范式 → 精益生产的修正 → 自动化与柔性制造」五章展开。

## 导读

- 流水线的本质是**把分工原则工程化**：以传送带统一节拍。
- 可互换零件是前提：没有标准化，就没有流水线。
- 福特的革命是**价格革命**：大规模生产把汽车卖给大众。
- 高效率的另一面：去技能化、单调劳动与「福特主义」劳资矛盾。
- 丰田精益生产以「准时制」修正库存与质量的代价，自动化继续改写范式。

> 📝 编者注：流水线与「大规模生产」（mass production）常被混用：前者是生产组织方式，后者是以此为基础的经济范式。本词条取流水线的组织视角，兼及范式后果。
