# 神义论

**神义论**（theodicy）一词由**莱布尼茨**在一七一〇年创制，取自希腊语的「神」（theos）与「正义」（dikē），字面意思就是「**为上帝的正义辩护**」。它要解决的不是「恶是否存在」——那不需要论证——而是：如果上帝同时是**全能的**（能阻止一切恶）与**全善的**（想要阻止一切恶），那么为什么世界上还有恶？这个问题构成了宗教哲学最古老、也最难缠的一个战场：它不质疑上帝的存在，而是质疑**上帝的存在与我们看到的世界的样子**是否相容。两千年来的每一次回答，都在重新调整这三样东西之一——**全能、全善、恶的实在性**。

本词条按「恶的问题与伊壁鸠鲁悖论 → 奥古斯丁的自由意志辩护与『恶是匮乏』 → 莱布尼茨《神义论》，最好可能世界 → 伏尔泰与休谟的批判 → 当代的回响，逻辑问题与证据问题」五章展开。

## 导读

- **伊壁鸠鲁式诘难是四选一，不是三选一**：不能、不愿、既不能又不愿、既能又愿——只有第四种与「上帝」相容，而这第四种直接引出「恶从何来」。
- **奥古斯丁的两步最经济**：恶不是**东西**（是善的匮乏），恶来自**意志的选择**（而非创造者的设计）。它把责任从创造者转移到了受造者。
- **莱布尼茨的要点不是「一切都好」，而是「一切可能世界中最好的那个」**：恶是**捆绑**在最优整体中的，剔除恶会连带失去更大的善。
- **休谟的批判最锋利**：他不争论逻辑，而是给出**四个经验事实**（痛苦是生存所必需、世界由普遍法则治理、自然物产吝啬、造工粗糙），指出它们最符合「冷漠的神」而非「全善的神」。
- **当代已分家**：「逻辑问题」（恶与上帝是否**逻辑上**相容）与「证据问题」（恶是否构成**反对上帝存在的证据**）是两个不同的论证，前者基本被判为失败，后者仍在争论。
- 指路：与 `free-will`（自由意志）、`ethics`（伦理学）、`metaphysics`（形而上学）构成直接交叉。

> 📝 编者注：讨论这个题目时必须区分三种不同的事业，它们常被混为一谈。**辩护**（defense）只需表明「恶的存在与上帝的存在**在逻辑上不矛盾**」，不必说明上帝的**实际**理由；**神义论**（theodicy）则要给出上帝允许恶的**实际理由**；**辩护学**（apologetics）则试图说服人接受某个宗教。普兰丁格明确把自己的工作称为**自由意志辩护**而非神义论，正是因为他只主张前者。混淆这三者会造成大量无效争论——用「你没说出上帝的理由」去反驳一个只主张逻辑相容性的论证，是不相干的。
