# 元素周期表

**元素周期表**（periodic table）是化学的核心组织工具——一张把已知化学元素按原子序数从小到大排列的表格，它之所以「周期」，是因为元素的性质（如原子半径、电离能、化合价、活泼性）会随原子序数的增加而呈周期性的重复与变化，即「元素周期律」。门捷列夫在 1869 年首倡的这张表，不仅能系统地归类元素，更惊人的是它能**预测尚未发现的元素**。今天，周期表仍是化学家理解物质世界、材料学家寻找新物质的罗盘。

本词条按「从古到门捷列夫 / 现代科学原理 / 读表方法 / 预测与拓展 / 意义与前沿」五章展开。

## 导读

- 周期表的「周期」根源于**电子分层排布**：随原子序数增加，电子按壳层/亚层规则填充，同一纵列（族）的元素因最外层电子数相同而性质相似。
- 门捷列夫的伟大之处在于他留下空格并**预言新元素的性质**，为周期律提供了最强验证。
- 现代周期表已从最初的「按原子量排列」转变为「按原子序数（质子数）排列」，并随超重元素的人工合成不断延伸。
- 学会「读表」——周期（行）、族（列）、金属/非金属分区与几大区块（s、p、d、f）——是掌握化学的一条捷径。
