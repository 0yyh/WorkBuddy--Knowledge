# 国家儒学

**国家儒学**（State Confucianism）指儒学在中国汉代以后被国家政权吸纳，成为统治意识形态与礼制秩序之支柱的那一形态。它常被误解为「儒教国教化」，但这一说法在两个层面上都不准确。其一，中国历代政权从未设立类似「国教」的制度把儒学确立为唯一合法宗教；其二，「儒教」一词在近代以前基本不曾作为教名使用，其出现与 19 世纪以后的中西相遇有关。就实际历史而言，国家儒学是通过三条具体制度通道完成的：其一是**祭祀制度**——郊祀天地、宗庙列祖、社稷五祀与文庙释奠，构成国家礼仪的全部骨架；其二是**官僚选拔**——察举、九品中正至科举，使经学成为通向仕途的通道；其三是**教化治理**——以家训、乡约、学校与地方精英把礼制贯彻到基层。本词条按**宗教与礼制条目**写，故不讨论心性论与格物致知一类的哲学命题；它与**儒家祭祀**的差别在于层级与主体（第四章将说明），与**道教斋醮**的差别在于前者是官方制度而后者是宗教体制。它与相邻的「儒家哲学」词条分工明确：**那一条讲道理，这一条讲机构**。

本词条按「政教关系与概念史 → 国家祭祀的制度骨架 → 文庙与祭孔 → 科举与教化 → 历代调适与近代转型」五章展开。

## 导读

- 「国家儒学」是现代学者用于描述汉代以后政治—儒学关系的分析概念，不是古代的自我称谓。
- 儒家祭祀分为宗庙（内祭）与郊社（外祭）两套，前者祭祖后者祭天地，属不同系统。
- 郊祀的核心不是敬神，而是**沟通与统一**：以天为最高、以祖为次、以山川为附的秩序架构。
- 文庙祭孔把孔子的地位从「师」提升为「天地间之一大统」，但始终未称神。
- 科举把经学文本定为客观标准，使儒学从思想主张变为可操作的选拔技术。
