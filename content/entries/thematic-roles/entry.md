# 题元角色

**题元角色**（Thematic Roles，又译语义角色、格角色）是语义层面赋予句子论元（参与者）的抽象关系标签，如施事、受事、工具、受益、处所、来源等，用以刻画名词短语在事件中所充当的角色。它介于词汇意义与句法位置之间，是连接「谁对谁做了什么」与「句子怎样造句」的桥梁。与「约束理论」追问代词与照应语的指称约束不同，题元角色关注论元在事件中的语义身份；它与「词汇语义学」共享对词义角色的分析，又与「依存语法」在论元—谓词关系上衔接。题元角色是格语法、词汇功能语法与生成语法的题元理论共同倚重的接口概念。

本词条按「题元角色的基本概念与清单 → 主要角色详释（施事、受事、工具、受益等） → 题元角色与论元结构 → 题元角色与句法实现的映射 → 题元角色理论的问题与流派」五章展开。

## 导读

- 题元角色描述论元在事件中的语义身份，是跨语言、跨句式稳定的语义常量。
- 核心角色包括施事、受事、工具、受益、处所、来源、目标等，各有判定标准。
- 题元栅（thematic grid）规定动词携带哪些角色，是论元实现的语义前提。
- 同一语义角色可映射到不同句法位置（如被动化），体现语义—句法接口的灵活性。
- 题元角色清单是否封闭、边界是否清晰，仍是理论争论焦点。
