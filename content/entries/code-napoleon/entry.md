# 拿破仑法典

**拿破仑法典**（即一八〇四年《法国民法典》）是近代法典化运动的里程碑，也是大陆法系私法的母典。法国大革命摧毁了旧制度的等级与特权，亟需一部统一、清晰、属于全体公民的民法；拿破仑以第一执政之位推动编纂，于一八〇四年颁行，故名。它把革命成果——平等、所有权、自由——凝为条文体例，以明白法语使「农民也能读懂」。其后两百年，它以译本与仿本塑造了从欧陆到拉美、从近东到东亚的私法地图，与后来的德国民法典并称大陆法系双柱。读懂它，即读懂现代私法的基因。

本词条按「编纂背景与过程 → 结构基本原则 → 人法与家庭 → 财产法与契约 → 历史影响」五章展开。

## 导读

- 法典以「法律平等、所有权绝对、契约自由、过错责任」确立近代私法四支柱。
- 三类编（人、财产、取得方法）结构简明，便于全民适用。
- 法典巩固革命成果，也保留男性家长式家庭保守面。
- 其全球辐射使大陆法系得以成形，影响远超法国国界。
