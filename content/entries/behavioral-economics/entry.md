# 行为经济学

**行为经济学**（behavioral economics）是经济学与心理学的交叉学科，它用真实人类的认知、情感与社会偏好，替换古典理论里「完全理性、自利、永不失算」的**经济人（homo economicus）**假设。其核心主张是：人并非永远算得清利害，决策常系统性偏离最优，受参照依赖、损失厌恶、时间不一致与从众等力量左右；因此市场失灵与政策效果，都必须在「人会犯错」的前提下重新评估。它之所以重要，是因为小到养老金储蓄、大到防疫与节能的公共政策，都能通过顺应真实心理的「助推（nudge）」被低成本地改善，而不必强制或加税——这是它与「有限理性」这一认知底层（参见「认知偏差」词条）最直接的衔接处。

本词条按「理性经济人假设的裂痕 → 前景理论 → 启发式与偏差 → 时间偏好与自控 → 应用：默认选项与助推」五章展开。

## 导读

- 古典模型把人当成永不失算的计算机；行为经济学指出人有**有限理性、有限意志、有限自私**三重裂痕，偏差可预测、可复现。
- **前景理论**用「参照点+损失厌恶」重写风险选择：人对损失之痛约为等量获利之喜的两倍，故在亏与赚面前并不对称。
- 启发式是大脑省力的捷径，却会产出**代表性、可得性、锚定**等系统性偏差，与「认知偏差」词条同源同理。
- 人不是时间一致的：对近利极度偏爱（双曲贴现）导致拖延与成瘾，需要**承诺机制**这类外部装置来自我约束。
- 政策的杠杆在「选择架构」：把好习惯设为**默认选项**就能大幅提高参与率，这是行为经济学最便宜、也最易被误用的处方。

> 📝 编者注：行为经济学常被误读成「人都不理性所以市场全错」。它真正的贡献不是否定理性，而是给理性划出可测的边界，并把心理学证据装进可检验的经济模型。建议与「认知偏差」并读，前者讲偏差在心智中的生成，本词条讲偏差如何改写市场与政策。
