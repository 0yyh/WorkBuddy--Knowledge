# 查尔斯·赖特·米尔斯

**查尔斯·赖特·米尔斯**（C. Wright Mills，1916–1962）是美国社会学家，二十世纪中叶最具批判锋芒的社会理论家之一。他激烈反对帕森斯式的「宏大理论」与「抽象经验主义」，在《社会学的想象力》里提出核心命题：要能把个人的困扰与社会的公共议题勾连起来。他揭示军事、经济、政治三巨头结成的「权力精英」如何绕过大众共识做出重大决策，又在《白领》中刻画新中产阶级的异化与政治冷漠。米尔斯把社会视为权力斗争的场域而非功能和谐的有机体，既承接又偏离马克思主义与古典社会学的冲突视角，深刻塑造了批判社会学与公共知识分子的传统。

本词条按「生平与《社会学的想象力》 → 《权力精英》：谁在统治 → 《白领》与新中产阶级 → 冲突论立场与对功能主义的批判 → 遗产与批评」五章展开。

## 导读

- 米尔斯把社会学从「宏大理论」与「抽象经验主义」两股潮流中夺回，主张它必须能回答「哪类人正经历怎样的困惑」，否则便失去公共意义。
- 「个人困扰」与「公共议题」的区分是核心方法：一个人失业是困扰，千百万人结构性失业便是议题——想象力要把私人的怨愤翻译成对制度的追问。
- 《权力精英》揭示公司、军队、政府三巨头结成顶层，关键决策在精英内部完成而无需大众共识，这是对功能主义「整合」叙事最锋利的反例。
- 《白领》刻画出从独立老中产到受雇新中产的位移，新中产的异化与政治冷漠使传统民主的「平衡轮」失效，预告了权力结构的集中。
- 米尔斯与马克思主义共享冲突视角，却更强调多元精英与权威关系，而非单一阶级；他既批判功能主义的和谐预设，也拒绝历史决定论。
- 它与**功能主义**构成基本张力：当社会被描绘成自然和谐的体系，既有的不平等便会被合法化为「必要的分工」。

> 📝 编者注：米尔斯常被简化为「反理论的左派」，这是误读。他反对的是脱离经验的抽象体系与脱离问题的数据堆砌，而非理论或经验本身；其全部写作都试图让社会学重新成为一件关乎公共生活的事。本词条五章分别对应他的生平方法、权力诊断、阶级分析、理论立场与身后评价，引用著作以《社会学的想象力》(1959)、《权力精英》(1956)、《白领》(1951)为准。
