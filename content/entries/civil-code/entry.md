# 民法典

**民法典**（Civil Code）是以体系化、成文化方式编纂的民事基本法，集中规定平等主体之间的人身关系与财产关系的基本规则。它把原本散见于习惯、判例与单行法规中的私法规范，整合成一部逻辑连贯、概念严谨的法典，使公民与法人的权利义务获得稳定可预期的统一来源。民法典通常被视作「社会生活的百科全书」，既确认个体的人格尊严与财产自由，也划定国家权力不得任意介入的私域边界。从功能上看，它既是裁判规范，也是行为规范；既承载自由、平等、诚信等价值宣示，也提供物权、合同、婚姻、继承、侵权等具体制度的操作细则。现代民法典的传统始于一八〇四年的《拿破仑民法典》，其后德、日及旧中国相继仿行，形成影响深远的法典化浪潮。

## 导读

- 民法典不等于「民法」全部：它是一部成文的法典，而民法还包括单行法、判例与学说，法典只是民法的体系化主干。
- 法典化的核心价值在于**体系性而非简单汇编**：通过提取公因式形成总则，使规则之间不再矛盾、漏洞可被类推填补。
- 体例之争长期存在「法学阶梯式」（人—物—诉讼）与「潘德克顿式」（总则—分则）两条路线，后者深刻影响东亚民法典。
- 中国民法典采取「民商合一」思路，将物权、合同、人格权、婚姻家庭、继承、侵权统于一典，并单设人格权编凸显时代关怀。
- 数字时代对民法典提出新课题：数据、网络虚拟财产、个人信息保护如何安放在以物债二分为骨架的体系中，仍是开放争论。
