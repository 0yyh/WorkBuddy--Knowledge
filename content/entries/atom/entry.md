# 原子

**原子**（Atom）是构成化学元素的最小单位，也是一切物质的微观基石。一个原子由中央带正电的原子核与外围带负电、质量极轻的电子组成；原子核又由质子与中子构成，质子数决定了元素身份。早在古希腊，德谟克利特便以「不可分割的微粒」构想万物本原；十九世纪初，道尔顿用定量实验把原子论重新奠基为现代化学的支柱。此后一个世纪里，电子、原子核、同位素相继被发现，玻尔模型与量子力学则层层揭开原子内部的结构与规律。今天，从半导体到新药，原子层面的操控已成为工程与现实的核心。

本词条按「原子论思想史 → 电子与原子核发现 → 玻尔模型 → 元素周期与同位素 → 原子在化学与材料中的意义」五章展开。

## 导读

- **思想源流**：原子论从古希腊哲学思辨走向道尔顿的定量科学。
- **结构揭秘**：电子与原子核的发现确立了原子的层级结构。
- **玻尔模型**：能级量子化首次成功解释原子光谱。
- **周期与同位素**：质子数决定元素，中子数带来同位素。
- **物质基石**：原子通过化学键构筑分子与材料。

> 📝 编者注：日常语境中的「原子」常与「分子」混淆；分子可由多原子构成，原子才是元素的最小化学单元。
