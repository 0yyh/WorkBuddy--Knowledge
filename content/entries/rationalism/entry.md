# 理性主义

**理性主义**（Rationalism，又译**唯理论**）要解决的不是「要不要观察」，而是「知识的**根据**放在哪里」。它的回答是：放在**理性自身**。人心带有若干不是从经验获得的观念——逻辑规律、数学真理、实体与因果的概念；真正的知识应当以数学为范型，从少数清楚明白、不可再追问的**直观**出发，靠严格的**演绎**把必然性一路传递下去。感官在这个图景里的地位是机缘而不是根据：它能提醒我们去注意某个真理，却不能**证明**它——因为感官会欺骗我们，而「二加三等于五」不会因为任何一次看错而动摇。

本词条按「理性主义的基本信条与划界 → 笛卡尔：我思与天赋观念 → 斯宾诺莎：实体一元论 → 莱布尼茨：单子论与充足理由律 → 理性主义与经验主义之争及康德的调和」五章展开。

## 导读

- 理性主义的分歧点不是「理性重不重要」，而是**知识的第一根据在不在经验之中**：天赋观念学说是对来源问题的直接回答。
- 演绎之所以被选为知识范式，是因为只有它能**传递必然性**：归纳给不出必然，而感官给不出普遍。
- 「我思」的力量在于它不是三段论，而是**直观**——怀疑这件事本身就证明了怀疑者的存在，不需要任何中介前提。
- 这套方法的代价是**起点无法被外部检验**：如果公理是心灵自己提供的，那么用它推出的体系凭什么及于世界？笛卡尔循环正是这个困难的第一次暴露。
- 莱布尼茨把理性主义推到最高点：充足理由律要求一切都有理由，「最好的可能世界」是这条原则的直接后果，也招来了伏尔泰最锋利的嘲讽。
- 指路：它与**经验主义**的对立构成近代认识论的基本张力；两派各自的死结最终由 `kant` 的「哥白尼式转向」同时拒绝。
