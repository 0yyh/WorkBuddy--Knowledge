# 语言普遍性

**语言普遍性**（Linguistic Universals）指人类自然语言在语音、形态、句法、语义乃至语用层面上，普遍共有、跨越语系家族而稳定出现的特征与规律。它既是乔姆斯基「普遍语法」所主张的先天语言能力的抽象投射，也是格林伯格（Greenberg）类型学方法从跨语言样本中归纳出的分布倾向。与关注「语言如何彼此相异」的语言类型学不同，语言普遍性更关心「所有语言为何都长成某种样子」，以及「人类语言差异的边界究竟在哪里」。它把具体语言现象上升为关于人类语言官能、认知限制与交际功能的普遍命题，是普通语言学、认知科学与演化语言学共同交汇的核心议题，也为语言习得、机器翻译与濒危语言保护提供了理论参照。

本词条按「普遍特征与跨语言共性的基本界定 → 格林伯格蕴含共性与类型学证据 → 语音与形态层面的普遍特征 → 句法与语义层面的普遍现象 → 普遍性的理论解释与争议」五章展开。

## 导读

- 语言普遍性关注「所有语言共有什么」，与关注「语言如何不同」的语言类型学互为补充而非对立。
- 普遍性可分为绝对普遍（零反例）与倾向普遍（统计高频），也可分为形式普遍（结构形态）与实体普遍（具体材料）。
- 乔姆斯基的普遍语法提供先天官能的解释，格林伯格的蕴含共性提供跨语言抽样的证据，两者路径不同却指向同一问题。
- 语音、形态、句法、语义各层面都存在可验证的普遍特征，如普遍音段库、名词动词核心、递归能力等。
- 普遍性的来源仍有先天论与功能—认知论之争，至今未有定论，却深刻影响了语言习得与认知科学。
