# 辩证法

**辩证法**是关于联系、发展与矛盾运动的哲学方法。它主张事物不是孤立、静止、一成不变的，而是通过内部对立面的斗争实现自我否定与前进发展。这个词源自古希腊的"对话论辩"，经康德到黑格尔形成庞大的唯心主义体系；马克思批判地继承了黑格尔的合理内核，把它颠倒到唯物主义基础上，用来剖析社会历史与资本主义生产方式的矛盾运动。

本词条按「源流与黑格尔体系 → 对立统一 → 量变质变 → 否定之否定 → 应用与当代意义」五章展开。其中对立统一、量变质变、否定之否定三大规律是唯物辩证法的主要内容，读者可配合《矛盾论》《反杜林论》等著作词条对照研读。

## 导读

- 辩证法的总特征是**普遍联系**与**永恒发展**，与之相对的是形而上学的孤立、静止、片面观点。
- 三大规律各有侧重：对立统一揭示发展的**动力**，量变质变揭示发展的**状态**，否定之否定揭示发展的**方向**。
- 理解它重在方法而不在名词：看问题要抓内部矛盾、抓主要矛盾、坚持具体问题具体分析。
- 它既不是万能的标签，也不是可套用的公式，滥用反而会退化为空谈。
