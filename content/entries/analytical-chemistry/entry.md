# 分析化学

分析化学是化学学科中专注于「测定」的一支：它研究如何确定一种物质的化学成分、含量、结构以及形态。如果说合成化学关心「如何造出某分子」，那么分析化学关心「我们面前这东西究竟是什么、有多少、长什么样」。这种能力看似基础，却是所有实验科学的共同前提——没有可靠的测定，任何关于物质的结论都无从建立。从古代炼金术士用火焰颜色辨别金属，到今天用质谱仪在万亿分之一的浓度上检出污染物，分析化学的演进史，就是人类「看清物质」的能力不断延展的历史。

分析化学的核心任务可以概括为两个问题。第一是定性，即识别样品中存在哪些元素、离子、官能团或化合物；第二是定量，即测定这些组分的确切含量。二者往往相辅相成：先知道「有什么」，才能准确测「有多少」。此外，现代分析还延伸到形态分析（同一元素以何种化学形态存在）与结构分析（分子的三维排布），使测定从「成分清单」深入到「空间构造」。

本词条按「定性分析与定量分析基础 → 光谱分析 → 色谱分离 → 电化学与其他方法 → 应用场景与前沿」五章展开。

## 导读

- 分析化学回答「有什么」与「有多少」两个根本问题。
- 定性分析识别组分，定量分析测定含量，二者互补。
- 光谱法通过物质与电磁波的相互作用揭示结构与浓度。
- 色谱法先分离混合物再逐一检测，是复杂样品的关键技术。
- 分析数据支撑环境、食品、医药、司法与工业等广泛领域。

> 📝 编者注：分析化学的信条是「可重复、可追溯、可量化」；一个无法被独立复现的测定结果，在科学上几乎不具价值。
