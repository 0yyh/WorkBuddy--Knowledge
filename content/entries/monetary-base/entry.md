# 基础货币

**基础货币**（monetary base / high-powered money）是中央银行资产负债表中的负债项，等于流通中现金（C）与商业银行在央行的准备金存款（R）之和，即 B = C + R。

## 构成

- **流通中现金**：公众持有的纸币与硬币。
- **银行准备金**：商业银行存放在央行的存款，分法定与超额准备金。

> 📝 编者注：基础货币之所以称为"高能"，是因为一元基础货币可支撑数倍于自身的广义货币。

## 与货币乘数的关系

货币供应量 M ≈ 基础货币 B × 货币乘数 m。

## 央行的投放与回笼

央行通过公开市场操作、再贴现、准备金率调节基础货币总量。
