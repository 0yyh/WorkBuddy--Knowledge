# 基础货币

**基础货币**（monetary base / high-powered money）是中央银行资产负债表中的负债项，等于流通中现金（C）与商业银行在央行的准备金存款（R）之和，即 B = C + R。它之所以被称为「高能」，是因为每一元基础货币经商业银行放贷循环都能放大为数倍的广义货币（M1、M2）。理解基础货币，实质是理解现代信用货币「从何而来、由谁创造、受何约束」：它既是央行垄断发行的源头活水，又是利率框架下被银行需求拉动的内生变量，更是零下限时代量化宽松的直接载体。本章词条要解决的，正是把这条从央行账户到实体经济的价格与就业链条，一截一截地拆开看清。

## 导读

- 基础货币是写在经济主体负债端的「欠条总额」，不是央行的资产；央行扩表只改变全社会支付能力，不增加自身财富。
- 货币乘数让一笔基础货币派生出数倍广义货币，但漏损率、超额准备金率与法定准备金率会削弱放大，故「基础货币多」不等于「钱真的多」。
- 货币政策从盯住准备金总量转向盯住利率后，基础货币退居被动、由银行需求驱动；这一内生属性使「央行印钱必然通胀」的直觉判断落空。
- 零下限下央行借量化宽松主动扩表，放出的基础货币大量沉淀为超额准备金而非流入实体，退出（缩表）过快则易诱发金融动荡。
- 基础货币、货币乘数、信用创造三者共同决定物价与就业边界；分清 QE 与财政货币化，是评判一切「印钱」争议的前提。
