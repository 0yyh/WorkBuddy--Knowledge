# 基础货币

**基础货币**（monetary base / high-powered money）是中央银行资产负债表中的负债项，等于流通中现金（C）与商业银行在央行的准备金存款（R）之和，即 B = C + R。


## 导读

- 基础货币是央行负债，由流通中现金与银行准备金构成，是货币供应的源头。
- 货币供应 M 约等于基础货币乘以货币乘数，乘数受准备金率与现金漏损影响。
- 央行用公开市场操作等工具调节基础货币，进而影响货币与信用。
