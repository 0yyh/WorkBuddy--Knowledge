## 第一章 基础货币的构成

基础货币（monetary base，又称高能货币）是现代信用货币体系的总阀门。它不是一个抽象概念，而是央行资产负债表上一项具体的「负债」。本章要回答一个看似简单却极易混淆的问题：基础货币到底由什么构成，以及为什么它写在央行的负债端而非资产端。只有先把这道恒等式与其会计身份弄清楚，后续关于货币乘数、政策传导的讨论才有稳固的支点。

### 恒等式：B = C + R

基础货币在量上定义为两项之和：

B = C + R

其中 C 是流通中现金（currency in circulation），即中央银行发行的、离开银行体系、握在公众与企业手中的纸币与硬币；R 是商业银行存放在中央银行的准备金存款（reserves），包括法定准备金与超额准备金。两者都是「基础」的：现金是公众持有的最底层支付手段，而准备金是银行体系扩张信贷的根基。

这一定义看似朴素，却有两个容易被忽略的边界。其一，C 不包括银行金库中的现金（库存现金），那部分在统计上被计入准备金；真正构成基础货币的现金是「流通于银行体系之外」的部分。其二，R 是商业银行在央行的存款债权，不是商业银行自己持有的资产库存——这一点恰恰是理解基础货币「负债属性」的钥匙。

### 为什么基础货币是央行的负债

初学者常把「央行发行的货币」直觉地当作央行的资产，仿佛印钞就是央行「赚了钱」。这是最典型的误解。在会计上，基础货币全部落在中央银行的负债侧。原因在于：央行发行的每张纸币，本质是央行向持票人出具的、无息的「欠条」——你持有百元钞票，意味着央行欠你价值百元的商品购买力；你随时可以把它用于支付，央行必须保证其法偿性。现金是央行的负债，不是它的财富。

准备金同理。商业银行把资金存入央行，形成在央行账户上的存款余额。这笔余额对商业银行而言是资产（随时可动用、可清算），对央行而言则是负债——央行「欠」商业银行这笔存款。准备金账户的每一次增加，都对应着央行对商业银行的一笔债务确认。所以基础货币 = C + R，等式左边是「央行欠公众的现金」加上「央行欠银行的存款」，两项皆为负债。

> 📝 编者注：把基础货币理解为央行的「欠条总额」，能立刻破除「央行印钱等于央行变富」的幻觉。央行扩表时负债与资产同步增加，净财富并不增加；它真正改变的是全社会可动用的支付能力，而非自身的家底。

### 法定准备金与超额准备金

准备金 R 内部还要再分两类：法定准备金（required reserves）与超额准备金（excess reserves）。法定准备金是监管要求的下限——商业银行吸收的存款中，必须按法定准备金率（例如百分之十）冻结一部分存在央行，不能用于放贷；超额准备金则是超出法定要求、银行自愿多存的头寸。

这一区分至关重要。法定准备金是「被锁住」的基础货币，几乎不参与信用扩张；超额准备金才是银行随时可以贷出、从而启动货币乘数的「活跃弹药」。当银行体系超额准备金充裕，信贷扩张的潜力就大；当超额准备金趋近于零，银行放贷便受基础货币硬约束。这也解释了为何在零利率环境下，央行注入的天量准备金大量沉淀为超额准备金而未能转化为贷款——银行宁愿把「欠条」存在央行账上吃微息，也不愿冒险放贷。

> 📜 「准备金是商业银行在中央银行账户上的余额，它们构成了银行体系创造存款货币的基础。」 —— 米什金《货币金融学》

### 落回主线

至此，基础货币的轮廓已清晰：它是一笔写在央行负债端的「欠条总额」，由流通中现金与银行准备金构成，其中准备金又细分为法定与超额两部分。这一定义与会计身份，正是下一章分析「央行如何创造基础货币」的出发点——我们要进入央行的资产负债表，看负债端的这笔数字究竟如何从零被一笔笔生出来。
