# 指示语

**指示语**（Deixis）是指称意义高度依赖言谈语境的一类语言表达式，包括人称、时间、处所以及话语与社会指示。菲尔莫尔（Charles Fillmore）强调，要理解「我」「这里」「现在」「这」这类词，必须把它们的意义锚定在一个「指示中心」——通常是说话人、说话时刻与说话地点。这暴露了自然语言符号的「索引性」：一旦脱离具体交际场景，这类表达便无法定值，字面意义只提供一套待填充的坐标。指示语研究因此桥接了句法形式、语义指称与语用推理，与依赖推断的会话含义、依赖身体经验的认知语言学相互呼应，是普通语言学理解「语言如何在具体使用中确立指称」的关键入口。

本词条按「概念与语境依赖 → 人称指示 → 时间与处所指示 → 话语指示与社会指示 → 跨语言差异与理论意义」五章展开。

## 导读

- 指示语的指称必须锚定指示中心（说话人、说话时刻、说话地点）才能定值。
- 人称指示围绕自我—他者—第三方建构，常含包含/排除式的复数区分。
- 时间指示以说话时刻为原点，处所指示以说话地点为原点，均呈相对坐标。
- 话语指示回指语篇片段，社会指示折射身份、辈分与敬语等级。
- 跨语言比较显示指示系统差异巨大，对形式语义的「去语境化」假设提出挑战。
