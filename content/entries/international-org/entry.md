# 国际组织法

**国际组织法**是国际法中对国际组织这一特殊主体进行规范的分支。当国家不再仅靠双边条约交往，而把部分权能托付给一个常设多边机构时，便产生一个问题：这个「组织」在法律上是谁？它能签约、起诉、担责吗？其决议对成员国何效？国际组织法就是回答这些问题的规则集合。二十世纪以来，国际组织从零星走向密网，联合国、世贸、世卫等深度介入和平、贸易、卫生，使该领域从边缘走向国际法的中心舞台，也是理解当代全球治理不可缺的钥匙。

本词条按「法律人格与类型 → 组织结构与职权 → 表决制度 → 条约法 → 组织责任与改革」五章展开。

## 导读

- 国际组织随成员国条约而生，其法律人格来自国家授权，而非自然主体。
- 组织职权遵循「授予说」：未明确授予的权力，原则上不归组织。
- 一国一票与加权表决体现民主与实力的不同逻辑。
- 组织责任与改革，是主权让渡与全球治理张力的最前哨。
