# 拓扑学

**拓扑学**研究形状在「连续变形」下不变的性质：允许拉伸、弯曲、扭转，但不许撕裂或粘连。在这一自由度下，咖啡杯与甜甜圈没有区别——都有恰好一个洞；球面与环面却天差地别。拓扑学由此被称为「橡皮膜上的几何」，它剥离长度与角度，只留下最坚韧的连续结构。欧拉对哥尼斯堡七桥问题的解答（1736年）是它的史前史，庞加莱与豪斯多夫把它建成为二十世纪数学的通用语言：现代物理的场论、宇宙的形状、数据的形态、晶体的电子行为，都用拓扑学的词汇言说。

本词条按「直观与定义 → 拓扑空间 → 连通与紧致 → 同伦与同调 → 应用」五章展开。

## 导读

- 拓扑只认**连续性**：变形不撕裂不粘连，形状即视为相同（同胚）。
- **拓扑空间**用开集公理抽象「邻近」，比距离更普适（见「数学分析」第五章的度量空间）。
- **连通**（不分成几块）与**紧致**（有限覆盖可控）是两大基本性质。
- **同伦与同调**给「洞」计数，把形状问题代数化，庞加莱由此创立代数拓扑。
- 应用横跨数据分析（持续同调）、物理学（拓扑相变、宇宙形状）与计算机图形学。
