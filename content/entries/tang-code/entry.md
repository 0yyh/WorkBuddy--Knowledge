# 唐律

**唐律**是中国唐代成文刑律的统称，以唐高宗永徽年间编纂、长孙无忌等注疏的《永徽律疏》即《唐律疏议》为最完整传世定本。它在秦汉刑律、魏晋律学与北朝律令基础上集大成，把「礼」系统地写入「法」，达到中国古代立法「一准乎礼」的成熟形态。唐律不仅是唐王朝二百余年的治理准绳，更成为此后千余年东亚刑律的母本，朝鲜《高丽律》、日本《大宝律令》、越南黎朝刑律皆受其深刻塑造。读懂唐律，便握住了中华法系的主干与灵魂。

本词条按「编纂与疏议 → 结构与篇目 → 刑法原则 → 礼法结合 → 历史影响」五章展开。

## 导读

- 唐律以十二篇五百零二条为骨架，是古代法典结构化的成熟范式。
- 「十恶」重罪与「八议」特权，集中体现身份差等与伦理优先的立法价值。
- 唐律「一准乎礼」：儒家伦理被直接设为法律，礼法由表里的分而合。
- 唐律经宋明清承袭并辐射东亚，是中华法系的核心文本。
