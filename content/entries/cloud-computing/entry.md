# 云计算

**云计算**（Cloud Computing）指通过网络、按需使用计算资源（服务器、存储、数据库、软件）的服务模式。它的物理载体是**超大规模数据中心**——数以万计的服务器集群化运营；它的商业模式是**公用事业化**——像用水用电一样，按用量计费、即开即用；它的技术基石是**虚拟化**——把物理机器切分为可灵活调度的虚拟资源。美国国家标准与技术研究院（NIST）将其特征概括为五条：按需自服务、广泛网络接入、资源池化、快速弹性与可计量服务。云计算把「拥有计算设施」从企业必选项变为可选项，重塑了软件业的成本结构与交付方式，也使机器学习等算力密集技术得以平民化（详见「机器学习」词条）。

本词条按「从机房到云 → 虚拟化与数据中心 → 三层服务模式 → 云原生与产业迁移 → 主权、安全与锁定之辩」五章展开。

## 导读

- 云计算的本质是**计算资源的公用事业化**：按需、弹性、计量。
- 虚拟化与大规模数据中心是其技术与经济前提。
- IaaS/PaaS/SaaS 三层模式对应「租房子/租毛坯/拎包入住」。
- 云原生（容器、微服务、DevOps）重塑了软件开发方法论。
- 效率的另一面：数据主权、供应商锁定与安全集中化。

> 📝 编者注：云计算与互联网的关系是「跑在其上的服务模式」：没有宽带互联网与 TCP/IP，就没有云。本站「互联网」词条讲网络层，本词条讲资源与商业模式层。
