# 自动化

**自动化**（Automation）是让设备或过程在极少人工干预下，依据既定逻辑自主运行的技术体系。它的灵魂不是「机器替人干活」这么简单，而是一套「感知—比较—纠正」的闭环：系统不断测量实际状态，与期望目标比对，再用执行机构消除偏差。恒温器让室温恒定、巡航控制让车速稳定、机器人让焊点精准，背后都是同一个反馈思想。从二十世纪中期的工业自动线，到今天的软件机器人流程自动化与智能控制，自动化把人类从重复、危险与高精度的劳作中解放，却也带来了岗位替代与技能错配的深远议题。

本词条按「自动化的定义与历史 → 控制理论与反馈 → 工业自动化与机器人 → 流程与办公自动化 → 就业与社会影响」五章展开。

## 导读

- 自动化的核心是反馈闭环，而非单纯「无人操作」。
- 控制理论用数学保证系统在扰动下稳定收敛。
- 工业自动化以可编程逻辑控制器与机器人重塑车间。
- 软件自动化把规则性白领工作也纳入自动范畴。
- 自动化重组而非简单消灭岗位，其社会影响取决于再分配。

> 📝 编者注：自动化（automation）与 autonomy（自主）常被混用；前者强调按既定规则闭环运行，后者强调在开放环境中自主决策，成熟度与风险层级不同。
