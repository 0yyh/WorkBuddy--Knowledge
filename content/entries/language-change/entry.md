# 语言演变

**语言演变**（Language Change）是指自然语言在代际传递过程中，于语音、形态、句法、语义与词汇各层面发生的系统性、累积性改变。它并非语言「退化」或「错误」的堆积，而是在社会交际、认知经济、语言接触与随机变异共同作用下持续推进的有序过程。语言之所以会演变，根本原因在于语言既是约定俗成的符号系统，又必须通过每一代使用者的习得与日常使用来维系——任何一次不完美的复制都可能成为新变体的起点。语言演变与「历史比较重建」互为表里：重建法借亲属语言间的共时差异逆推原始共同语，而演变研究则解释这些差异究竟如何发生；它又与「语言接触」密不可分，因为外部借用往往是句法、词汇乃至语音变化的重要诱因；同时，演变研究也是理解「原始语」分化模型与「汉藏语系」内部年代关系的基础。

本词条按「语音变化机制 → 形态与句法变化 → 语义变化 → 词汇扩散与演变动因 → 演变的理论模型」五章展开。

## 导读

- 语音变化具有规律性与条件限制：如格里姆定律描述的日耳曼语辅音推移，但其背后是「词汇扩散」式的逐词扩散过程，而非全或无的瞬间替换。
- 形态与句法变化多由语法化驱动：实词虚化、句法结构重组，使表达经济性原则不断重塑语言的形态句法系统。
- 语义变化沿隐喻、转喻、贬降、扬升等路径展开：词义的扩大、缩小与转移共同构成词汇意义的历时漂移。
- 演变的动因兼具内部诱因（如发音省力、类比类推）与外部压力（如社会阶层、语言接触、双语干扰）。
- 现代变异社会语言学以「进行中的变化」为窗口，用实证方法观察演变如何在社群中分层传播，弥补了历史文献的缺环。
