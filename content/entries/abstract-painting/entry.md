# 抽象绘画

**抽象绘画**（Abstract art）是把「画得像某个东西」这件事放下的绘画。它不画山、不画人、不画碗果，而让色块、线条、形状与笔触本身成为主角。听起来像二十世纪的新花样，其实根系很深：人类早有纹样与书法这类「不模仿自然」的图像。但「抽象」作为自觉的艺术纲领，是二十世纪的事。它的出现有个直接诱因——摄影（见**肖像画**相关脉络）把写实 monopol 抢走，画家若还比谁更像，必败；于是有人干脆不比，转去发掘形色自身的表现力。这条转向从康定斯基、马列维奇、蒙德里安三人为核心成形，一路分出抒情的与几何的两脉，又在二战后渡海到美国，长出抽象表现主义与色域绘画。中国这边，书法与写意本就有「不形似」的底子，被赵无极、吴冠中接去接通中西。本词条先厘清抽象究竟「抽掉」了什么，再分脉、跨国、跨材料地看它如何长成现代艺术的主轴之一。

本词条按「抽象抽掉了什么 → 抒情抽象与几何抽象 → 抽象的美国时刻 → 抽象与中国：书法与写意 → 抽象的当代处境」五章展开。

## 导读

- 抽象不是「画不出像」，而是主动放弃再现，让形、色、线、面自身说话；它常被视为摄影夺走写实后的回应。
- 抽象有两大来源：二十世纪初康定斯基、马列维奇、蒙德里安三人将其纲领化，此前已有纹样与书法铺垫。
- 抒情抽象（热抽象）求音乐般的情感流动，几何抽象（冷抽象）求普遍秩序的纯粹，蒙德里安的网格是其代表。
- 二战后重心移向美国：抽象表现主义以行动与滴洒登场，色域绘画以巨大色场引人冥思。
- 中国书法与写意传统与抽象遥通，赵无极、吴冠中以抽象接通中西，但不宜简单等同。
- 它与**油画**、**西方绘画**、**印象派**、**美学**、**艺术史**交叉最深；同批的**风景画**、**肖像画**也共享「再现松动」的背景。

> 📝 编者注：本词条把「抽象」限定为自觉的艺术纲领，不把一切纹样与装饰都算作抽象，以免概念泛化。站内暂无独立「热抽象」「冷抽象」「色域绘画」词条，相关术语在本词条内解释，请勿引用尚未创建的 slug。
