# 科举制度

**科举制度**（科举）是中国从隋唐到清末以分科考试来选拔官吏的制度。它把选官的依据从门第出身转向**考试成绩**，理论上「一切以程文为去留」，从而为布衣寒士提供了凭才学入仕的可能，也把人才的选拔权从门阀世族收归中央朝廷。科举历经约一千三百年的演变，深刻地塑造了中国社会的流动机制、读书传统与政治结构，既有辉煌的进步意义，也在明清八股中暴露出僵化与束缚思想之弊。

本词条按「科举之前的选官：从察举到九品中正 → 隋唐的创立与演进 → 宋代的改革与公平化 → 明清八股与僵化 → 科举的废除、功过与历史遗产」五章展开。

## 导读

- 科举的核心进步在于以「**考试**」取代「**门第**」，承认凭才学可以改变命运。
- 宋代通过**糊名誊录**等手段大幅提升公平性，是中国古代最讲「机会均等」的制度努力之一。
- 它既是**社会流动的阶梯**，也是**思想统制的工具**——明清八股即是明证。
- 科举于 1905 年废除，但其「考试选才」的基因深刻影响了现代文官制度与教育。
