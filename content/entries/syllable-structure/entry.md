# 音节结构

**音节结构**（Syllable Structure）研究语音如何组织成音节这一基本节奏单元。典型的音节可切分为音首（Onset）、韵腹（Nucleus）与韵尾（Coda）三部分，其中韵腹是必需的核心，音首与韵尾为可选成分。音节并非辅音与元音的自由堆叠，而是受到首音法则、韵尾限制与最大开音节原则等音节音系制约的约束。在以克莱门茨（Clements）为代表的 CV 音系学中，音节被建模为以 X 时序槽为骨架、以辅音与元音自主音段为内容的层级结构，从而统一解释了音节重组、增音与删音等音变现象，是音系学连接语音表层与底层表达的关键枢纽。**

本词条按「音节的内部结构 → 音节制约条件 → CV 音系学 → 音节与音变 → 跨语言音节类型与音节重量」五章展开。

## 导读

- 音节由音首、韵腹、韵尾构成，韵腹为核心且必需，音首与韵尾为可选周边成分。
- 首音法则规定音节内响度由边缘向核心递增，是跨语言高度稳定的音节化约束。
- CV 音系学以 X 槽骨架组织音段，使音节结构成为可推导的层级表征而非原子单位。
- 音节边界常是音变发生的场所，增音、删音与音节重组都围绕音节结构展开。
- 音节重量（轻重音节）直接影响重音指派与诗律，是音系与形态接口的重要参数。
