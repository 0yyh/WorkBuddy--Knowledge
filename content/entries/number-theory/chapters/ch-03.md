模运算下，幂次极易膨胀，却出人意料地守着简洁的周期。费马小定理是第一条这样的规律：若 p 是素数，a 是任意整数，则 $a^p\equiv a\pmod p$；当 a 与 p 互素时，两边约去 a 得 $a^{p-1}\equiv 1\pmod p$。举个具体的例子：取 p=7，a=3，计算 $3^6=729$，除以 7 余 1，正是定理所述。费马在 1640 年写信给出此结论，却未留下令后人满意的证明；首个严谨证明常归功于莱布尼茨与欧拉。

费马小定理的威力在「降幂」。要计算 $a^k\bmod p$ 且 k 极大时，可直接把指数对 $p-1$ 取模（当 a 与 p 互素），因为幂每 $p-1$ 步循环回一。这使得原本指数爆炸的运算变成可控的取模算术——现代计算机对超大指数取模正是靠这条周期。定理还有个漂亮推论：若 $p$ 不整除 a，则 $a^{p-2}$ 恰是 a 在模 p 下的逆元（因为 $a\cdot a^{p-2}\equiv 1$），于是「模逆」可用快速幂直接算出，无需辗转相除。

欧拉把费马小定理推广到任意模数。欧拉定理说：若 a 与 n 互素，则 $a^{\varphi(n)}\equiv 1\pmod n$，其中 $\varphi(n)$ 是欧拉函数（小于 n 且与 n 互素的正整数个数）。当 n 为素数 p 时，$\varphi(p)=p-1$，欧拉定理退回费马小定理；对合数模，它给出更一般的周期长度。欧拉在 1763 年证明此定理，所用的「缩系」思想（把与 n 互素的所有剩余类列出，乘以 a 后只是重新排列）至今仍是最直观的证明：因为乘法在这些类上构成群，群的阶恰为 $\varphi(n)$，而群中任意元素的阶整除群的阶。

这两条定理是公钥密码的直接数学内核。RSA 的加解密建立在：选互素的指数 e、d 使 $ed\equiv 1\pmod{\varphi(n)}$，则对消息 m 有 $(m^e)^d\equiv m\pmod n$——这正是欧拉定理保证的「幂运算互逆」。Diffie-Hellman 密钥交换则依赖「离散对数困难」：已知 $g^a\bmod p$ 与 $g^b\bmod p$，求共享的 $g^{ab}$ 容易，但从单方幂反推指数 a 却极难；而费马、欧拉定理告诉我们这些幂确实落在可预测的循环群里，从而协议正确且不退化。没有这两定理，现代加密的「为什么能还原」就无从说起。

理解费马与欧拉定理，还要看到它们连接了数论与群论（见「代数」）：模 n 下与 n 互素的剩余类在乘法下构成一个阿贝尔群，其阶为 $\varphi(n)$，而「任何元素的阶整除群阶」正是拉格朗日定理的特例。于是数论最实用的两条结论，其实是抽象代数普遍原理在整数上的投影。这种「具体定理↔一般结构」的呼应，正是数学统一性的典范；本章的定理也将是下一章黎曼理论与第五章密码之间的桥梁。

费马小定理还有一则 cautionary tale：存在「伪素数」（卡迈克尔数），它们不是素数，却能让几乎所有底 a 都满足 $a^{n-1}\equiv 1\pmod n$，从而骗过单底数费马检测。这正是加密系统不能只靠费马小定理判定素数的原因——必须用多个随机底（米勒-拉宾检验等）把差错概率压到可忽略。这里数论的「几乎总是成立」与工程的「必须极高可靠」达成妥协：我们不追求绝对证明，而追求足够大的把握，因为素数本身在算法层面已足够「够用」。

欧拉定理的指数 $\varphi(n)$ 也直接决定 RSA 的安全参数。攻击 RSA 的一条捷径是分解 n 得到 p、q，从而算出 $\varphi(n)=(p-1)(q-1)$ 与私钥 d；反之，若能直接从公钥 (n,e) 求出 $\varphi(n)$，也就等价于分解了 n——人们相信这两件事在计算上同样困难。因此 RSA 的安全性可归结为「从 n 求 φ(n) 难」，而这一切都建立在欧拉定理所刻画的幂循环之上。离散对数与整数分解这两道数论难题，构成了第五章公钥体系的两根支柱。

值得一提的是，费马小定理的逆命题并不成立（这正引出伪素数），但欧拉定理的框架提示了更一般的视角：在模 n 的单位群中，元素的幂构成循环子群，其结构完全由群的阶与元素的阶决定。这种「群视角」让密码设计者能精细控制密钥空间大小、避免弱指数。数论从「整除」起步，经同余、定理，最终在群论语言中收束为可证安全的协议——本章正是这条从古朴到现代链条的中段枢纽。

费马本人是位业余数学家，本职是图卢兹的法官，却利用通信在数论上留下大量猜想与方法，被后世尊为「业余数学之王」。他习惯在书页边写结论却少给证明，留下「此处空白太小，写不下」的轶事；小定理只是他随手写下、却影响深远的众多断语之一。欧拉则把费马的碎片系统化为定理与证明，奠定了现代数论的分析取向。师徒般的两人跨越百年，把一条朴素的同余规律锻造成当代信息安全的支柱，堪称数学史上「无用之学终成大用」的最佳注脚。

> 📝 编者注：费马还有著名的「大定理」（$x^n+y^n=z^n$ 在 n>2 时无正整数解），与本章「小定理」不同，它由怀尔斯 1994 年用模形式与椭圆曲线证明。二者同名易混，本词条聚焦小定理这一密码学工具。
