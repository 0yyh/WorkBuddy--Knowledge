素数有无穷多个，这是数论最古老的定理之一，证明出自欧几里得。他用反证法：假设素数只有有限个，把它们全部相乘再加一，得到的新数要么本身是素数（不在原列表中），要么有某个素因子不在原列表中——两种情形都推出矛盾。这个论证的妙处在于「构造性」：它不告诉你第 n 个素数在哪，却保证永远有下一个。自此，「素数有多少」不再是问题，「素数怎么排」才是。

关于排布，最惊人的全局规律是素数定理。记 $\pi(x)$ 为不超过 x 的素数个数，高斯与勒让德都曾猜测 $\pi(x)$ 近似于 $x/\ln x$；严格证明由阿达马与瓦莱·普桑在 1896 年独立给出，关键工具是把素数与复变函数里的ζ函数相连（详见下一章）。素数定理说：在足够大处，相邻素数的平均间隔约为 $\ln x$，且随机整数的「是素数」概率约为 $1/\ln x$。于是素数越往后越稀疏，却永不消失——这与「无穷多个」并不矛盾。

素数定理揭示的是「平均」行为，个体层面却充满意外。素数间隔可以任意大（连续 n 个合数可由 $(n+1)!+2$ 到 $(n+1)!+n+1$ 构造）；也可以异常近，如孪生素数（相差二的素数对：3 与 5、11 与 13……）。孪生素数是否无穷多，是著名的未解猜想；2013 年张益唐证明存在无穷多对素数其差小于七千万，随后合作项目把这一界大幅压缩，但「差等于二」仍然悬而未决。这些结果说明：素数的局部间距既有随机表象，又受未知的深层法则约束。

几个世纪悬而未决的猜想，彰显素数之谜的深浅。哥德巴赫猜想（1742）断言每个大于二的偶数可写成两个素数之和，已对极大范围验证却无人证明；素数在等差数列中的分布由狄利克雷定理保证（只要首项与公差互素，该数列含无穷多素数）；而「素数是否如抛硬币般随机」则由塞尔伯格与埃尔德什的初等证明、以及概率数论持续追问。现代计算已列出万亿量级的素数，统计与猜测高度吻合，却始终差那一步严格的「为什么」。

素数分布之所以迷人，是因为它处在「最简对象」与「最难问题」的交界。素数只由整除定义，却展现出近似随机的全局图景，这种「确定性中的随机感」让数论与混沌、随机性研究产生奇妙呼应（可对照「概率」与「混沌理论」）。更实际地，素数的难以预测正是公钥密码的命脉：若素数分布可被精确预报、或整数分解变得容易，现有加密体系便告崩溃。于是「素数究竟有多随机」不再只是哲学趣题，而是关乎全球信息安全的真问题。

寻找素数有一套古老的实用方法——埃拉托斯特尼筛法：从二起，依次划掉每个素数的倍数，剩下的便是素数。它的思想（用已知素数过滤合数）演化为现代「筛法」，是解析数论估计素数计数的主力工具；陈景润在哥德巴赫猜想上「一加二」的突破，正建立在筛法的精微改良之上。筛法揭示一个深刻事实：要数清素数，往往先要精确刻画「被小素数整除」的合数有多少，素数乃是剔除一切可除性之后剩下的残余。

素数的「随机感」还催生了概率素数检测。面对几百位的大数，逐一试除不可行；但费马小定理（下一章）提供了一条快速判定的捷径：若某个底下的幂不同余于一，则该数必为合数。重复随机选底，可让「误判合数」的概率任意小，这正是现代加密系统生成大素数的办法。这里的悖论是：我们几乎从不完全「证明」一个超大数是素数，却用概率方法获得足够把握——素数的分布规律在这里转化为工程上可用的可靠性。

把素数写在方格纸上、按螺旋排布（乌拉姆螺旋），会看见素数诡异地聚成斜线，仿佛隐藏着某种二维结构；这种视觉上的秩序感与解析上的无序感形成张力，提醒人们素数之谜远未穷尽。对素数分布的探索，因此兼具计算的、分析的、乃至美学的维度：它既是数论的核心，也是检验人类推理极限的试金石。下一章将看到，把素数问题搬进复平面，黎曼ζ函数如何把这场探索推到数学疆域的中央。

> 📝 编者注：素数定理的证明依赖下一章的黎曼ζ函数；而素数间隔的「困难」正是 RSA 等密码的安全假设。本章可与「无穷」对照——素数无穷但稀疏，是「无穷」概念在实数轴上的具体投影。

## 从猜想到定理：间隔的下界

素数间隔可以任意大，却也有可证的下界保证。伯特兰公设（1845）断言：对任何大于一的整数 n，n 与 2n 之间必有素数；切比雪夫在 1852 年给出证明，思路是估算后来所称的切比雪夫函数的量级——这比素数定理早了半个世纪，也是解析数论的第一次重要胜利。后来拉马努金给出更简的证明，埃尔德什十八岁时的第一篇论文也以此为题。公设的现代表述是「第 n 个素数小于 2 的 n 次方量级」，它虽远弱于素数定理，却已足以保证：无论走多远，下一个素数永远不会太远。对间隔的研究由此形成清晰的阶梯——先证「必然有」，再证「有多密」，最后才追问「有多随机」，素数定理正是第二级阶梯的登顶。
