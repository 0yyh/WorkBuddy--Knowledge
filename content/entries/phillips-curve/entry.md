# 菲利普斯曲线

**菲利普斯曲线**（Phillips Curve）是宏观经济学中刻画通货膨胀（早期为工资通胀）与失业率之间反向关系的经典图像。它最初并非理论，而是新西兰经济学家威廉·菲利普斯在1958年对英国近百年失业与货币工资数据做经验回归得到的统计规律：失业越低，工资上涨越快。这一发现后来被萨缪尔森与索洛扩展为「通胀—失业」的权衡取舍，长期主导了凯恩斯主义的需求管理思维。然而弗里德曼与费尔普斯在1960年代指出，这种权衡只在「预期未调整」时成立；一旦人们把通胀纳入预期，曲线便会右移乃至长期垂直。此后理性预期学派与通胀目标制实践，又不断改写这条曲线的政策含义。它既是宏观政策的路线图，也是宏观思想史的缩影。

本词条按「第一章 起源：工资通胀与失业的负相关 → 第二章 货币主义的重构：预期增广的菲利普斯曲线 → 第三章 短期 vs 长期：权衡与政策无效性 → 第四章 通胀目标制：从权衡到锚定预期 → 第五章 应用与当代挑战」五章展开。

## 导读

- 菲利普斯1958年的原始发现是经验规律而非理论：它描述工资通胀与失业负相关，并未主张可用来「交易」失业。
- 弗里德曼—费尔普斯的自然失业率假说把预期引入模型，使长期菲利普斯曲线变为垂直——长期不存在通胀—失业权衡。
- 卢卡斯的理性预期批判进一步指出：只有未被预期到的货币冲击才影响真实失业，系统性政策长期无效。
- 现代央行已较少把菲利普斯曲线当「取舍菜单」，转而用通胀目标制锚定预期，使曲线自身趋于平坦稳定。
- 疫情后通胀回升提醒我们：当冲击来自供给端且预期脱锚时，工资—价格螺旋可让曲线再度陡峭化。

> 📝 编者注：常见误解是把菲利普斯曲线当成「政府随时可沿之取舍」的政策前沿。本词条反复强调，这种菜单只存在于预期未调的短期窗口；把它当长期工程蓝图，正是1970年代滞胀的思想根源。交叉阅读建议见 inflation、unemployment、monetary-policy 与 central-banking。
