# 大乘佛教

**大乘佛教**（Mahayana，梵语「大车」或「大乘」之意）是公元前后在印度兴起、其后向东亚与喜马拉雅地区广泛传播的佛教传统，它以「菩萨道」为最高的修行理想，主张不仅自我解脱、更要发愿度脱一切众生，因而把慈悲与智慧并列为解脱的两大支柱。大乘佛教以「空性」（sunyata）的般若智慧破除对实有之执著，又以「如来藏」「佛性」说肯定众生本具成佛之因，从而在「诸法无我」与「众生可成佛」之间架起义理桥梁。它自视为较早期部派佛教（被其贬称「小乘」）更广大、更彻底的教法，却也始终共享佛陀所立的四圣谛与八正道初基。大乘在经典与宗派上极为繁茂，先后形成汉传、藏传与日本佛教等大河；它与相邻概念「佛教」（整体传统）、「佛陀」（觉者本师）、「四圣谛」（共许基础）、「禅宗」（其汉传一支）层层嵌套，是理解亚洲宗教文明不可缺的一环。

本词条按「大乘的兴起与基本定位 → 菩萨道与普度 → 空性思想 → 佛性、如来藏与净土 → 汉传、藏传、日传分流」五章展开。

## 导读

- 大乘以菩萨道为理想，主张发菩提心、历劫修行、普度众生，区别于唯求自度的阿罗汉理想。
- 空性（般若）是大乘智慧的核，龙树中观以「八不」破边见，立二谛说。
- 如来藏与佛性论肯定众生本有成佛之因，与空性形成互补张力。
- 净土信仰以念佛往生为易行道，是大乘普及的重要形态。
- 大乘分化为汉传八宗、藏传显密与圆融、日本诸宗，脉络各异却同宗般若。

> 📝 编者注：本词条与「佛教」「佛陀」「四圣谛」「禅宗」并列，可对照阅读。文中通译依大陆惯例：Buddha→佛陀、Bodhisattva→菩萨、Mahayana→大乘、Hinayana→小乘、sunyata→空性、Nagarjuna→龙树、Tathagatagarbha→如来藏。部分年代（如龙树约公元二至三世纪）学界有异说，采主流估计。
