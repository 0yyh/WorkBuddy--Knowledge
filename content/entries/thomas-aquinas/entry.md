# 托马斯·阿奎那

**托马斯·阿奎那**（Thomas Aquinas，约 1225—1274）是**拉丁中世纪哲学**的集大成者，道明会士，以《神学大全》与《反异教大全》把亚里士多德体系重新缝进基督教神学。他最锋利的姿态，是把理性摆到信仰之前：不靠启示压制哲学，而主张「**哲学是神学的婢女**」——凡理性可证者（如上帝存在）交给论证，理性不及者（如三位一体）才托付启示。这套安排既在信仰时代为理性留出地盘，也奠定了此后六百年的天主教官方哲学。

本词条按「信仰与理性：哲学是神学的婢女与五路证明 → 存在与本质：esse 与 essentia、类比学说 → 自由意志与神圣预知：自由如何与全知相容 → 自然法：四重法律等级与道德根基 → 政治与共同善：法律等级、世俗权威与财产权」五章展开。

## 导读

- **哲学是神学的婢女，不是其囚徒**：理性与启示同源，凡可证者理性自理，不可证者（三位一体、道成肉身）才属信仰——这把理性从「信什么」中解放出来。
- **五路证明走的是「从果溯因」**：运动、因果、必然、完善、目的，五条都从经验世界的不完满回溯一个无待的「第一」——但康德后来判定这类论证越界。
- **存在（esse）优先于本质（essentia）**：在受造物中本质与存在分离，在上帝中二者同一；这是阿奎那区别于柏拉图主义的根本一步。
- **自由与预知可以相容**：上帝在永恒中「同时看见」一切时间中的选择，其预知不向未来「投射」必然性，故人的自由抉择不被取消。
- **自然法是永恒法在理性受造物中的投影**：自保、繁衍、求真、群居四类自然倾向，构成一切人法都必须服膺的道德地基；不义之法不算真正的法。
- 指路：他与**奥古斯丁**（新柏拉图主义、光照说）构成中世纪内部的根本张力，又与**康德**对五路证明的批判构成「理性能否证明上帝」这一母题的两端。

> 📝 编者注：本词条是**人物**条目，聚焦阿奎那本人的思想结构与文本（以《神学大全》为骨架）。「五路证明」与「自然法」的流派后续可分别见 `scholasticism`（经院哲学）；其自由意志与政治哲学维度可对照站内 `free-will` 与 `political-philosophy`。常见误读是把阿奎那的「理性证明上帝」当成「理性可以穷尽信仰」——恰恰相反，他反复强调理性在奥秘（三位一体、道成肉身）面前的边界，婢女之说正是对理性的定位而非僭越。
