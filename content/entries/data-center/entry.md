# 数据中心

**数据中心**（Data Center）是集中部署服务器、存储与网络设备的专用设施，为互联网服务、云计算与人工智能训练提供源源不断的算力。它看似只是一栋房子里的许多机器，实则是一套由电力、制冷、网络与安全共同支撑的复杂系统工程。任何一次断电或过热，都可能让数以万计的服务瞬间中断。在数字社会里，数据中心就是「发电厂」般的基础设施（详见「人工智能芯片」词条中关于算力底座的讨论）。

本词条按「算力基础设施 → 机房与供电 → 冷却与能耗 → 网络与存储 → 绿色与边缘」五章展开。

## 导读

- 数据中心是**数字社会的物理根基**，集中提供算力与存储。
- 稳定供电与高效制冷是其能否持续运行的关键。
- 能耗巨大，绿色化与液冷成为行业焦点。
- 网络与存储架构决定数据吞吐与可靠性。
- 边缘数据中心把算力推近用户以降低时延。

> 📝 编者注：数据中心常被想象成「一堆服务器」，但它真正的工程难点在看不见的地方：电力如何不断、热量如何排走、故障如何隔离。机房是电力系统的延伸，也是热力学问题。
