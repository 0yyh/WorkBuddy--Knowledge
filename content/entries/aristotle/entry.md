# 亚里士多德

**亚里士多德**（Aristotle，公元前 384—前 322）是古希腊哲学的集大成者，**柏拉图的学生、亚历山大大帝的老师**。他创立**形式逻辑**（三段论），并在物理、生物、伦理、政治等领域留下系统著述；他主张知识始于经验，以"**四因说**"解释事物，其庞大体系主宰了西方学术近两千年。

本词条按「生平与学园 → 逻辑与四因 → 经验与科学 → 影响与遗产」四章展开。

## 导读

- 他既是柏拉图的学生，也是理念论最有力的批评者：**形式不在天上，而在具体事物之中**。
- 创立**形式逻辑**（三段论），为理性推理确立了第一套规则。
- 以**四因说**（质料 / 形式 / 动力 / 目的）解释"事物为何如此"。
- 其博物学与分类工作，是**经验科学**的先声。

> 📝 编者注：亚里士多德与柏拉图的分歧，可概括为"**理念的居所**"之争——柏拉图把普遍者置于超越世界，亚里士多德则把它拉回具体事物之中。
