# 罗丹

奥古斯特·罗丹出生在巴黎一个普通家庭，早年屡试艺术学院不第，却以惊人的毅力与对真实人体的痴迷，最终改写了雕塑的走向。他生活的时代，学院派仍统治着沙龙与纪念碑，要求作品光滑、典雅、寓意明确；而罗丹偏偏让石头保留凿痕，让人体的肌肉在光影里颤抖。他不是第一个反叛者，却是最有力量的那一个。

本词条按「罗丹的生平与突破 → 思想者及其精神重量 → 现代雕塑先驱的方法论 → 肌理与表面的革命 → 对瞬间与动态的捕捉」五章展开。

## 导读

- 罗丹出身平凡，靠自学与坚持突破学院派壁垒。
- 《思想者》以蜷缩沉思的裸体，把哲学凝为可触的形体。
- 他主张保留泥稿的痕迹，让「未完成」本身成为表现。
- 粗粝肌理取代抛光光滑，使表面成为情绪的载体。
- 他捕捉动作的过程而非定格，预示了运动与时间的雕塑。

> 📝 编者注：罗丹常说自己「只是把泥土当作活物」，这份对材料的谦卑，恰恰是他能解放雕塑的前提。
