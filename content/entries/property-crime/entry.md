# 财产犯罪

**财产犯罪**（Property Crime）是以非法占有为目的、侵害他人财产权益的一类犯罪，也是刑法分则里数量最大、离普通人最近的类型。它要回答的根本问题是：刑法到底在保护「所有权」这个抽象权利，还是保护「人对财产的平稳占有与利用」这种生活秩序？两种答案会导向完全不同的罪名边界。

本词条按「概念与保护法益 → 盗窃罪 → 抢劫罪与抢夺罪 → 诈骗罪与敲诈勒索 → 体系与比较」五章展开。

## 导读

- 财产犯罪的灵魂是**非法占有目的**，无此目的（如一时使用）通常不构成。
- 盗窃是「违背意志、打破并转移占有」；抢劫是「以暴力当场取财」。
- 诈骗的特别之处在于：它**利用被害人的错误意思**让其自愿交付。
- 法益之争（所有权 vs 占有）决定了对「偷自己东西」「偷赃物」等边界案的定性。
- 它与同批「未完成罪」「白领犯罪」咬合：本条目是既遂形态，后二者分别是其未完成版与非暴力版。

> 📝 编者注：财产犯罪极易与「经济犯罪」混淆。简单区分：财产犯罪以具体个人/单位的财产为直接对象、多为「取得型」；经济犯罪（含白领犯罪）多破坏制度与整体经济秩序。二者在「职务侵占」「挪用」处常有交叉。
