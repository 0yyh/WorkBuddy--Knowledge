# 词汇语义学

**词汇语义学（Lexical Semantics）是语义学的一个核心分支，专门研究语言中词项层面的意义结构、词义的构成方式，以及词与词之间错综的意义关系。它既追问「一个词的意义由哪些更基本的语义成分组合而成」，也考察「同义、反义、上下义、整体—部分」等关系如何把孤立的词织成可 navigable 的意义网络，还分析多义、同形异义等现象如何在语言使用中生成与分化。作为连接词汇形式与句子整体意义的桥梁，词汇语义学上承语音、形态与句法，下接语用与推理，是词典编纂、词义消歧、自然语言处理与儿童词汇习得共同依赖的基础领域。**

本词条按「对象与方法 → 同义与反义 → 上下义、整体—部分与词场 → 多义与同形异义 → 词义演变与语义网络」五章展开。

## 导读

- 词汇语义学以词项为基本单位，关注词义的内部构成与词间关系，而非整句真值。
- 义素分析把词义拆解为可对立的语义特征，是结构主义留下的核心方法。
- 同义、反义、上下义、整体—部分构成词义关系的主要类型，并编织成语义场。
- 多义指一词多义且义项相关，同形异义指形同而义无关，二者需明确区分。
- 词汇语义学与组合性原则相连，是句子意义由词义组合而生的前提。

> 📝 编者注：本词条与同批的「组合性原则」「乔姆斯基谱系」「转换语法」「语言变体」并列。组合性原则处理整体意义如何由部分加结构得出，词汇语义学则先解决「部分（词项）的意义是什么」这一前置问题，二者构成句义研究的上下游。
