# 犯罪

**犯罪**（Crime）是刑法中最核心也最易被情绪化的概念。严格地说，犯罪不是「很坏的事」，而是「危害社会、触犯刑法、依法应受刑罚处罚的行为」。这三重限定缺一不可：只坏而不违法，不是犯罪；违法而不够刑罚程度（如轻微违章），也不是犯罪；依法应罚却因行为人无责（如未成年），同样不成立犯罪。犯罪因此是法律判断，不是道德呐喊。现代刑法以一套犯罪构成体系把「什么算犯罪」客观化、可检验化，使罪刑法定在个案中落地。理解犯罪，是区分「应当谴责」与「国家可罚」的第一步。

本词条按「犯罪的概念与本质 → 犯罪的分类 → 犯罪形态：预备未遂中止既遂 → 共同犯罪」四章展开。

## 导读

- 犯罪具三重属性：社会危害性、刑事违法性、应受刑罚处罚性，缺一不可。
- 犯罪分类含故意与过失、自然人犯与单位犯、重罪与轻罪、既遂与未遂。
- 预备、未遂、中止、既遂反映行为发展的不同阶段，处罚轻重各异。
- 犯罪中止因自动放弃或防果，得减轻或免除，体现刑罚的教善取向。
- 共同犯罪中主犯、从犯、教唆犯按作用与犯意分别归责。

> 📝 编者注：犯罪是最易被泛化的词。媒体称「某某犯罪」，法律人须先问：有明文规定吗、实质上害了什么、行为人可责吗。把一切恶行称犯罪，既稀释刑法威慑，也侵蚀罪刑法定。犯罪是法律的结论，不是情绪的起点。
