# 模仿说

**模仿说**（Mimesis）是西方最古老的艺术理论：艺术是**模仿**。这句话听起来平常，却埋着整个西方美学的第一场大辩论——**柏拉图**在《理想国》第十卷用「三张床」论证模仿者离真理隔着三层，要把诗人逐出理想国；**亚里士多德**在《诗学》里则把模仿重新解释为人的天性，并断言诗比历史更接近哲学。此后两千年，模仿说时而被奉为常识（镜子说、现实主义），时而被彻底推翻（浪漫主义的表现说、现代主义的形式主义）。本词条沿这条起伏展开，最后看**奥尔巴赫**与**阿多诺**如何在二十世纪让这个概念复活。

本词条按「柏拉图：三张床与诗人的逐客令 → 亚里士多德的翻案：模仿作为天性与可能性 → 从中世纪到现实主义：模仿说的漫长统治 → 反模仿论：浪漫主义、形式主义与现代艺术 → 二十世纪：奥尔巴赫、阿多诺与模仿的回归」五章展开。

## 导读

- 柏拉图的模仿批判是一个**本体论论证**：模仿品在存在等级上最低，因而离真与善最远，这不是审美判断而是形而上学结论。
- 亚里士多德的翻案关键在于改变了模仿的**对象**：不是模仿已发生的事实，而是模仿可然与必然之事——诗因而比历史更富哲学性。
- 模仿说在近代被「镜子说」改造：艺术模仿自然，但「自然」指理想化的自然，这一滑转让模仿说从复制转向了选择。
- 反模仿论的第一枪由浪漫主义打响：如果艺术的根源是心灵的表现，模仿就只是一个次要的技术问题。
- 二十世纪的回归很反直觉：奥尔巴赫把《摹仿论》写成西方文学中「现实的再现」史，阿多诺则把模仿重新解释为艺术对自然的**非支配性关系**。
- 它与**柏拉图**、**亚里士多德**、《理想国》词条直接对峙；与「表现说」「形式主义美学」构成本领域的基本张力。

> 📝 编者注：中文文献里「模仿说」与「摹仿说」混用，本词条正文统一用「模仿说」，书名《摹仿论》（奥尔巴赫）保留通行译名。另需注意：模仿说在当代常被简化为「艺术复制现实」，这是十九世纪现实主义的读法，不是柏拉图与亚里士多德的原意。
