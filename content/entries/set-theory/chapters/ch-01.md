集合论并不是从「研究集合」这个崇高目标出发的。它的起点是 19 世纪分析学中的一堆技术麻烦——这也提醒我们：数学基础的大厦往往砌在具体问题的地基上。

## 从病态点集说起

19 世纪中叶，傅里叶级数理论提出了一个尖锐的问题：一个函数在何处可以展开为三角级数？要回答它，必须精确描述实数轴上「使得某种性质失效的点」所构成的集合。康托尔 1872 年在研究这一问题时的论文中，引入了越来越复杂的点集构造（后来称为康托尔集一类的对象），而这些工作迫使他追问一个此前被视为禁区的问题：**无穷多个点组成的集合，其「大小」能不能比较？**

在康托尔之前，主流意见继承自亚里士多德与高斯：实无穷（把无穷当作一个完成了的整体）只是说话的方式，不是数学对象；数学只应处理潜无穷（可以不断延伸、但永远未完成的过程）。高斯在给友人的信中明确表示，在数学中使用实无穷是「不可容忍的」。康托尔的全部工作，就是把这个禁区变成一门精确的学科。

## 一一对应：不数数也能比大小

康托尔的基本洞见朴素得惊人：**两个集合一样大，当且仅当它们的元素可以一一配对**。对有限集合，这与数数结果一致；它的威力在无穷集合上才显现——因为对无穷集合你根本数不完，一一对应是唯一可行的比较方式。

第一批结果立即违背直觉。康托尔证明：

- **自然数集与正偶数集一样多。** 配对方式是 n ↔ 2n。一个集合居然可以和自己的真子集一样大——伽利略早在 1638 年就注意到这一点，并以此认为无穷之间不能比较大小；康托尔的反问是：这恰恰是无穷集合的**定义性特征**，而不是缺陷。
- **自然数集与有理数集一样多。** 把所有分数按对角线顺序排成一张无穷表格（1/1、1/2、2/1、1/3、2/2、3/1……），沿对角线蛇形扫描，每个正分数恰好被访问一次。稠密的有理数竟然是「可数的」。
- **自然数集与代数数集一样多。** 代数数是整系数多项式的根，康托尔 1874 年的原始证明即为此——这项工作连着「存在超越数」的推论：既然代数数可数而实数更多，超越数必然存在且不可数。这与刘维尔 1844 年手工构造第一个超越数形成有趣对照：康托尔证明了超越数铺天盖地，却一个也没有具体给出。

## 对角线法：一步造出漏网之鱼

真正的问题还在后头：**实数可数吗？** 康托尔 1874 年先给出一个较迂回的证明；1891 年，他发表了如今以「对角线法」之名著称的两页纸论证，简洁到可以直接完整复述。

假设实数区间 (0,1) 中的所有数可以排成一列 r₁, r₂, r₃, ……，每个数写成无穷小数。现在构造一个新数 x：它的第 n 位小数取「与 rₙ 的第 n 位不同的数字」（例如 rₙ 的第 n 位是 5，就取 6，同时避免使用 0 和 9 以绕开 0.999…=1.000… 的双重表示麻烦）。

这个 x 是一个合法的实数，但它与列表中的**每一个** rₙ 都在第 n 位不同——它不在列表上。矛盾。所以任何列表都列不全 (0,1)：**实数不可数**。

注意这个论证的结构：假设列举完备，然后照着列表本身造出一个被遗漏的对象。没有复杂的计算，只有一次自我指涉式的翻转。这个模式的力量远超集合论——哥德尔用它构造不可判定命题，图灵用它证明停机问题不可判定，罗素悖论和塔斯基的真理论中都有它的影子。可以说，对角线法是 20 世纪数学基础领域最锋利的一把刀。

## 无穷的等级

对角线法的直接后果是：**无穷不是一个，而是一类**。自然数有无穷多个，实数也有无穷多个，但后者的无穷严格大于前者。更妙的是，对任意无穷集合 S，其幂集（S 的全部子集构成的集合）总是严格更大——这可以用同样的对角线论证对任意集合成立（康托尔定理，1891）。于是无穷形成一个无顶点的塔：自然数、实数、实数的幂集、再往上……

康托尔用「基数」为这套等级命名：自然数的基数记作 ℵ₀（阿列夫零），实数的基数记作 2^ℵ₀ 或记作 𝔠。他还引进序数，为无穷的「位置」编号，并宣布任意无穷基数都可以写作某个 ℵ（良序原理，后成为选择公理的等价形式之一）。

## 孤独与攻击

康托尔的处境长期艰难。克罗内克称实无穷是海市蜃楼，并动用影响阻挠康托尔在柏林求职；彭加勒把集合论讽刺为一种「病」，认为它将成为后世的笑柄；关于实无穷的争论在哲学与神学圈同样激烈——如果绝对无穷只有上帝才有，那么数学家把无穷纳入运算是不是一种僭越？康托尔本人与神学家通信多年，认真辩驳这一指控。这些压力与几次丧亲之痛叠加，他多次陷入抑郁发作。到 1900 年前后，形势开始扭转：希尔伯特在巴黎大会上把「连续统的大小」列为 23 个问题之首，并预言没有人能把数学家从康托尔创造的天堂里驱逐出去。但此时，一门更年轻、更朴素的集合论正带着一个致命漏洞走向舞台中央——下一章的悖论危机。

> 📜 「没有人能把我们从康托尔为我们创造的天堂中驱逐出去。」 —— 希尔伯特《论无穷》（1926，就其对集合论地位的主旨而言，此为其常被引用的句子）

> 📝 编者注：康托尔定理的证明值得亲手做一遍：假设 f 是集合 S 到其幂集 P(S) 的一个映射，构造 D = {x ∈ S : x ∉ f(x)}。D 是 P(S) 的元素，故 D = f(d) 对某个 d ∈ S 成立；问「d ∈ D 吗」立即自相矛盾。这一问与罗素问集合的问题完全同构——下一章的种子已经埋在这里。
