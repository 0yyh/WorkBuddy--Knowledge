# 爵士乐

**爵士乐**是一种诞生于美国的音乐类型，对没接触过的人，可以把它想成一种带着蓝调味道的即兴合奏：一群乐手围坐，在一段反复的和声与节奏之上轮流站出来自由发挥、彼此呼应，像一场有规则的语言游戏。它大约在二十世纪初成形于新奥尔良，融合了非洲节奏、美国蓝调、拉格泰姆钢琴与欧洲进行曲的血统。它最迷人的地方在于不可复制——同一支曲子，今晚的演奏和明晚绝不相同，因为大量内容是乐手当场现想现奏的。它既是供人跳舞的流行乐，也是后来被请进音乐厅的艺术音乐，更是现代音乐里「即兴」这一观念的源头之一。

本词条按「定义与范畴 → 历史脉络：从新奥尔良到比波普 → 形式语言与技法 → 代表流派与人物 → 影响与当代」五章展开。

## 导读

- 爵士的灵魂是即兴：乐手在固定和声与曲式上临场创造，使每一次演出都成为孤本，这与古典音乐照谱演奏形成根本区别。
- 它的血统是混血的：西非节奏、美国蓝调的音阶、拉格泰姆的切分、欧洲和声与铜管编制，在新奥尔良港汇聚成形。
- 历史有一条清晰线索：新奥尔良爵士到摇摆大乐队，再到比波普的小编制、快速度、复杂和声，最后走向冷爵士与自由爵士的进一步解放。
- 技术语言自成体系：蓝调音把三、七级音降半音、摇摆八分、延伸和弦，让音色既骚动又讲究。
- 它对后世影响极广：摇滚、节奏蓝调、嘻哈采样、电影配乐乃至现代古典都从中取经，是二十世纪声音文化的关键引擎。
