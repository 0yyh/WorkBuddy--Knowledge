# 春秋战国

**春秋战国**指公元前 770 年平王东迁、至前 221 年秦灭六国这一约五百五十年的长时段，习惯以「春秋」（前 770—前 476）与「战国」（前 475—前 221）两段划分。其地域以黄河、长江中下游的诸夏列国为核心，兼及周边的戎、狄、蛮、夷与巴蜀、吴越。核心主题是一条清晰的主线：周室衰微 → 霸政 → 兼并 → 变法 → 郡县官僚制雏形 → 走向统一，即中国由封建向帝制转型的完整过程。代表性特征包括霸政与盟会秩序、铁器牛耕与井田瓦解、各国变法（李悝、吴起、商鞅）、士的崛起与官僚制萌芽，以及贯穿始终的兼并战争与统一趋势。

本词条按「平王东迁与礼崩乐坏：霸政的开端 → 春秋争霸：齐桓晋文与盟会秩序 → 战国格局：三家分晋与七雄并立 → 变法运动：从李悝、吴起到商鞅 → 社会与经济革命：统一条件的成熟」五章展开。

## 导读

- 平王东迁后「天子弱、诸侯强」，周王室沦为名义共主，政治重心由「王权」下移至「霸权」，霸政是封建秩序崩解后的过渡形态。
- 春秋霸主以「尊王攘夷」为旗号、以盟会为约束机制，在缺乏强中央的情况下维系了列国间的脆弱秩序。
- 三家分晋是春秋入战国的分水岭：世袭贵族政治转向以军功与权术立国的集权国家，兼并逻辑不可逆。
- 各国变法本质是同一场比赛——谁能把国家改造成更高效战争机器，谁就存活并扩张，秦的胜利是制度竞争的结果。
- 铁器牛耕与土地私有瓦解了井田与宗族，士阶层从贵族附庸变为可流动的人力资源，官僚制由此萌芽，统一的条件悄然成熟。
