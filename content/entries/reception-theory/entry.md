# 接受理论

**接受理论**（Reception Theory，又译接受美学、读者反应理论）是二十世纪六七十年代兴起的理论范式。核心主张是一次重心转移：**文学意义不是在作者的写作中完成，也不是在文本结构中静止，而是在读者的阅读中实际生成。** 文本提供的只是结构与空白，而空白不可由文本填满；读者须以经验与期待接通它们。因此「一部作品是什么」被换成「它在什么条件下成为什么」。姚斯以「期待视野」与「审美距离」重建文学史，伊瑟尔以「空白」与「召唤结构」刻画阅读建构，费什把意义问题转到读者的「阐释共同体」。与相邻概念的关系是：与「叙事学」一属文本一侧、一属阅读一侧；与「女性主义批评」「后殖民批评」同属后期转向，共享把权力带回理论中心的思路。

本词条按「从作者中心到读者中心 → 姚斯的期待视野与文学史 → 伊瑟尔的阅读行为与空白 → 接受美学的诸种形态与跨文化移植 → 争论、修正与当代影响」五章展开。

## 导读

- 接受理论把文学史的重心从作者的创造移向读者的接受，以「期待视野」为核心工具。
- 姚斯的「审美距离」衡量作品与读者既有经验之间的距离，距离的大小决定评价的高低。
- 伊瑟尔以「空白」说明文本只给结构而意义须由读者填补，因此阅读是一种活动。
- 费什的「阐释共同体」把意义问题转到读者群体的共享常规上，意义由此具社会性。
- 批评集中在接受美学的普遍性预设、文本的确定性被稀释，以及「读者」被当作单一整体。
