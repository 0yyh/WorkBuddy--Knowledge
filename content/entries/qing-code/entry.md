# 清律

**清律**是以《大清律例》为核心的清代成文法律体系，是中国帝制时代最后一部、也最成熟的法典。它要回答的根本问题，是「一个多民族的大一统帝国，如何用一套礼法合一的规则维系伦理秩序与官僚统治」——这既是技术问题，也是正当性工程。

本词条按「编纂与体系 → 结构内容 → 司法适用与条例 → 特色制度 → 历史地位与近代转型」五章展开。

## 导读

- 清律以明律为蓝本，乾隆朝定型为「**律例合编**」：《律》为常典，《例》随时损益。
- 它承袭唐明「**礼法结合**」：十恶、八议、服制把伦理写进刑法。
- 「**秋审**」是清代死刑复核的慎刑大典，体现「刑杀必慎」的治理哲学。
- 清律在满汉、旗民关系上烙有民族统治的特殊印记。
- 它是中华法系晚期的集大成者，经清末修律走向近代转型。
