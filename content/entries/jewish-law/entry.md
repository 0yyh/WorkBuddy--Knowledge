# 犹太法（哈拉卡）

**犹太法（哈拉卡）**（Halakhah，源自希伯来语 halakhah「道路」）是犹太教对**全部生活规范**的体系性表述，涵盖饮食、婚姻、离婚、财产、诉讼、洁净与安息日。**它的权威来源是成文妥拉（moṣeh torah）与口传律法（torah šebe-al pī），二者共同构成「梅绥拿」（Mišnāh）与《塔木德》的解释传统。** 从犹大·哈那西编纂《密西拿》，到巴比伦《塔木德》定本，再到迈蒙尼德《密西拿托拉》的体系化与犹拉·卡罗《哈拉卡》的法典化，犹太法经历了从口传传统到成文法典的完整历程。本词条按哈拉卡的范畴 → 拉比释经方法 → 迈蒙尼德与法典编纂 → 与罗马法的交叉 → 当代身份法争论五章展开。

本词条按「哈拉卡的范畴：从妥拉到口传 → 拉比释经的方法与体系化 → 迈蒙尼德与法典编纂 → 中世纪至现代：与世俗法的交叉 → 身份法、家庭法与当代争论」五章展开。

## 导读

- 哈拉卡不只是宗教诫命，而是一套覆盖生活全域的规范体系，与阿加达（叙事性教义）相对。
- 口传律法的权威在《密西拿》与《塔木德》中被逐步固定，拉比释经方法（情境推理等）是其技术核心。
- 迈蒙尼德《密西拿托拉》与卡罗《哈拉卡》两部法典确立了犹太法典编纂的两条不同路径。
- 犹太法与罗马法的相互影响在拜占庭与中世纪意大利均有具体证据，学界对此已有较清晰的时间线。
- 「谁是犹太人」是当代最难的法律问题之一，它牵涉宗教、族群与国家法的复杂张力。
