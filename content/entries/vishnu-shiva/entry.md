# 毗湿奴与湿婆

**毗湿奴**（Vishnu）与**湿婆**（Shiva）是印度教中两大主神，分别代表**保全与生成**这两个宇宙论原则。**毗湿奴以「化身」（avatāra）观念为核心，通过罗摩、黑天等化身降生人间，其教义在《薄伽梵往世书》与《薄伽梵歌》中达到系统化；湿婆则以不动明王（Mahādeva）的形态、林伽（linga）的象征与瑜伽苦行的实践为特征，其崇拜以湿婆派为中心。** 二者在吠陀时代仅是次要神祇，其地位在笈多时代以后上升，并在中世纪成为印度教的两大主神，泰国那教与锡克教亦由此派生。本词条按吠陀源流 → 《薄伽梵歌》的毗湿奴 → 湿婆的林伽与瑜伽 → 派别分化与融合 → 化身与当代实践五章展开。

本词条按「吠陀中的毗湿奴与湿婆 → 《薄伽梵歌》中的毗湿奴 → 湿婆：不动明王、林伽与瑜伽 → 派别分化与融合 → 化身、庙宇传统与当代实践」五章展开。

## 导读

- 二者在《梨俱吠陀》中地位并不突出，其神学系统化主要发生在笈多时代以后。
- 毗湿奴的「化身」教义把多神教与一神论统一起来，是其宗教史上的关键创新。
- 湿婆的形象极为多样：不只是.destroyer，也包括苦行者、舞者与教师。
- 林伽是湿婆最核心的象征，其意涵随时代与流派而变化。
- 派别分化并非泾渭分明，湿婆-毗湿奴的融合形态在近现代南亚尤为常见。
