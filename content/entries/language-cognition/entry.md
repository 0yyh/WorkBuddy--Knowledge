# 语言与认知

语言与认知探讨的是人类最独特的能力之一——语言——与心智运作之间的深层联系。我们借助语言思考、记忆、计划与交流，几乎无法想象脱离语言的清醒思维。但语言究竟只是表达思想的工具，还是在暗中结构着思想本身？这个问题既古老又常新，牵涉哲学、心理学、语言学与神经科学的交汇。沿着这条线索，我们看到两条相反的直觉反复交锋：一方强调语言对思维的塑造，另一方强调思维对语言的先在。

本词条按「语言与思维的关系 → 乔姆斯基与普遍语法 → 心理语言学的实验发现 → 语言习得与发展 → 具身认知的新视角」五章展开。
