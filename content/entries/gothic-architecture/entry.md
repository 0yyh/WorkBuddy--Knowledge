# 哥特式建筑

哥特式建筑是欧洲中世纪盛期最具标志性的建筑语言，自十二世纪中叶在法兰西萌发，迅速成为西欧教堂、修道院乃至市政厅的主流样式。它诞生于城市复兴、朝圣经济与神学思辨交织的年代，既回应了信徒对更高、更亮、更接近天国的空间渴望，也见证了石匠行会日趋精密的工程智慧。与更早的罗曼式建筑相比，哥特式以骨架化的受力体系取代厚重墙体，让建筑第一次在视觉上获得了近乎失重的轻盈。

本词条按「起源与历史脉络 → 结构与技术革命 → 光、空间与彩绘玻璃 → 雕刻装饰与象征 → 影响与遗产」五章展开。

## 导读

- 哥特式建筑由罗曼式过渡而来，圣德尼修道院的重建常被视为起点。
- 尖拱、肋拱顶与飞扶壁构成其结构三角，使墙体得以大面积开窗。
- 彩绘玻璃与玫瑰窗把神学叙事转化为可感知的光。
- 雕刻从建筑附属走向独立叙事，门楣与圣像承载救赎寓意。
- 哥特式在十九世纪复兴，并持续影响现代对垂直空间的想象。

> 📝 编者注：哥特一词起初带有贬义，是文艺复兴学者用来指称「蛮族」风格的称呼，后来才中性化为一种建筑史分期。
