## SQL 与声明式查询

**SQL（Structured Query Language）** 是关系数据库事实上的标准语言，国际标准编号 **ISO/IEC 9075**。

### 声明式：只说要什么

SQL 的核心特征是**声明式**：你写「我想要哪些满足条件的数据」，而不写「先扫哪张表、用什么索引、怎么连接」。把「取数路径」交给**查询优化器**，是关系模型数据独立性的直接延伸——同一句 SQL，优化器可随数据量与索引选择不同执行计划。

### 查询骨架

一条典型查询由子句组合：

- `SELECT` 投影要返回的列；
- `FROM` 指定来源表；
- `WHERE` 筛选行；
- `GROUP BY` / `HAVING` 分组与分组后过滤；
- `ORDER BY` 排序。

`JOIN` 按匹配键把多张表合并成一张结果表，使「跨整个关系模式」的查询能写成单个表达式——这是关系模型对真实业务（订单连客户、成绩连课程）最直接的价值。

### 标准的演进

SQL 自 1986 年首个国际标准 **SQL-86** 起，经 **SQL-92**（广为人知的大版本）、**SQL:1999**（引入递归查询、触发器、窗口函数、XML）、**SQL:2003**（XML/OLAP）、**SQL:2016**（JSON、多态表）、**SQL:2023**（增强 JSON 与环类型）多次演进。绝大多数主流数据库（PostgreSQL、MySQL、Oracle、SQL Server）都「近似实现」该标准——SQL 是工程近似，而非关系模型的严格化身。

> 📝 编者注：科德本人曾激烈批评 SQL 对关系模型的偏离（如允许空值 `NULL`、表有顺序）。这种「理论纯粹」与「工程实用」的张力，贯穿了关系数据库半个世纪的历史。
