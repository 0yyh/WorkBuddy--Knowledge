互联网修好了「管道」，却迟迟缺少让普通人想用的「内容」。早期上网要记晦涩的命令，文件散落在不同系统的深处，普通人与它隔着重重门槛。把互联网从专家工具变成大众媒介的，是一层架在它之上的服务——万维网。它的发明者蒂姆·伯纳斯-李曾形容，自己只是把「超文本」这一旧点子，嫁接到了刚成形的互联网之上，却意外点燃了信息传播的范式转换。

## 为科研而生的设想

一九八九年，在欧洲核子研究中心工作的伯纳斯-李提交了一份提案：面对分散在多国、多机上的科研文献，能否用「超文本」把它们连成一张可随手跳转的网络？他认为信息之间本应彼此引用，而当时的系统让引用变得困难。一九九一年，他写出了世界上第一个网页浏览器与服务器，并定义了三项至今不衰的基石：描述网页的 HTML、传输网页的 HTTP、定位资源的 URL。关键是，他把这些设计全部免费公开、不申请专利——这一决定让万维网得以无门槛地长成公共财富。

## 三件套如何降低门槛

HTML 用简单的标签把文字、标题与链接组织成网页；URL 给每个资源一个全球唯一的「门牌号」；HTTP 则负责按地址把网页取回来。三者配合，使「点击一个蓝色下划线文字，就跳到另一台机器上的另一页」成为现实。对使用者而言，复杂的网络寻址与传输被完全隐藏，只剩下「链接」这一 intuitive 的动作。信息第一次以「网页—链接—网页」的图谱形态呈现，人类阅读与联想的习惯被原样搬到了屏幕上。

## 浏览器点燃大众化

真正让万维网破圈的，是图形化浏览器。一九九三年，伊利诺伊大学的 Mosaic 浏览器把文字、图片、链接排进同一窗口，不必再敲命令，点鼠标即可漫游。此后网景、微软等公司的浏览器把上网变成一件人人可学的事。网站数量呈指数增长，商家、媒体、个人纷纷建站，互联网从实验室与军方的内网，骤然变成街头巷尾的热词。如果说 TCP/IP 让机器互联，万维网则让内容互联，二者合力才成就了我们熟悉的「上网」。

## 从门户到平台

万维网的早期是「只读」的：多数人浏览别人发布的网页。进入二十一世纪，博客、维基与后来的社交平台把「写」的权限也交给了用户，Web 2.0 让每个人都成为发布者。电商、搜索、视频、短视频相继涌现，互联网经济就此崛起。回望一九九一年的第一个网页，很难想象它会在二十年内重构新闻、零售、娱乐与人际关系的全部规则——而这一切，都建立在伯纳斯-李那套开源、中立、可无限链接的设计哲学之上。

## 浏览器大战与标准的守护

万维网的巨大成功立刻引来商业圈地。一九九四年网景的浏览器一炮而红，微软随即把自家浏览器捆绑进操作系统，两家争相添加互不兼容的私有标签，同一张网页在不同浏览器里面目全非，开发者苦不堪言。业界由此看清：Web 的生命力系于「一处书写、处处可读」，标准不容私藏。伯纳斯-李早在一九九四年就创立万维网联盟，以共识程序维护 HTML 等规范。世纪之交的第一场浏览器大战以微软独大收场，却也埋下反弹的种子——开源的火狐与后来的 Chrome 重新点燃竞争，并把渲染引擎开源共享。竞争与标准这对张力，从此构成 Web 演进的基本节奏。

## 搜索引擎：给无限图书馆编目

网页以指数速度增殖，链接图谱很快庞大到「浏览」无从下手。给这座无限图书馆编目的努力，先是人工分类的网站目录，随后是依据关键词与链接关系自动排序的搜索引擎。一九九八年上线的谷歌把学术引用的思想移植过来：被越多网页引用、且被越权威的网页引用的页面，排名越靠前。这一「网页声望」算法让搜索质量跃升，也把上网习惯从「记住网址」改写为「搜索一切」。搜索成为 Web 的实际入口，注意力随之汇聚，为日后搜索引擎的商业模式与权力争议埋下伏笔——这同样证明，万维网的开端之所以伟大，恰恰因为它足够开放，后来的创新者不必请示任何人。

> 📝 编者注：万维网是互联网之上的「应用层」之一；电子邮件、文件传输等同层服务更早存在，但 Web 因极低门槛成为最耀眼的入口。
