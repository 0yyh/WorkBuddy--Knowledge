# 基督教神学

**基督教神学**（Christian Theology）指基督宗教对上帝、基督、救赎与末世的系统反思与论证，其核心任务是**为信仰提供可理解的说明，并划定信条的边界**。**其最核心的教义是三位一体与道成肉身，而贯穿全部教义的张力是「上帝如何既超越人又临近人」**。从教父时代的《尼西亚信经》，到奥古斯丁的原罪论与恩典论，经院学派的体系化（托马斯·阿奎那），到宗教改革后的称义论重构与巴特的启示论，基督教神学经历了两千余年的发展与多次范式转换。本词条按神学与启示的自我理解 → 三位一体 → 基督论 → 人论与恩典 → 救赎与末世及方法争论五章展开。

本词条按「基督宗教的神学与「启示」的自我理解 → 三位一体 → 基督论与道成肉身 → 人论、罪与恩典 → 救赎、末世与神学方法的争论」五章展开。

## 导读

- 神学不是自由思辨，而是「为信仰作理解的智慧」，其边界由教会与文本共同划定。
- 三位一体是基督教最具原创性的教义，其难题在于「三位一体如何合一」。
- 基督论的核心是「 Chalcedon 二性定义」：不混合、不分割、不改变、不分离。
- 原罪与恩典的争论决定了人如何得救，伯拉纠主义与奥古斯丁之争是这一争论的关键节点。
- 救赎论的三种模型（惩罚说、赎罪说、代表性说）各有解释力，但当代神学普遍认为无一是充分的。
