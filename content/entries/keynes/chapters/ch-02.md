## 有效需求与乘数

凯恩斯革命的核心，是用「**有效需求**」重新解释产出与就业。古典经济学相信萨伊定律——供给自动创造需求；凯恩斯却指出，人们赚到收入后未必全部花掉，储蓄与囤积现金都会让购买力从循环中漏出，于是生产出来的商品未必总能找到买主。决定一国生产多少、雇多少人手的，不是它的生产能力，而是**社会愿意支出多少**。

### 有效需求：两条曲线的交点

凯恩斯用两个总函数刻画这一点。**总供给函数** Z(N) 给出雇主雇用 N 个工人时所要求的最低销售收入；**总需求函数** D(N) 给出社会在同一就业水平上愿意支出的总额。均衡就业量由二者相等处决定，该处的需求量即「有效需求」。它并非无限的愿望，而是**有购买力支撑、并被企业预期到**的需求——雇主正是依据这一预期决定产量与用工。

因此，只要充分就业之前的某一点上 D(N) 与 Z(N) 相交，经济就会停在**低于充分就业的均衡**上：工人愿意按现行工资就业却找不到工作，企业也没有扩大生产的动力。这正是凯恩斯要解释、而古典学说无法容纳的「常态性失业」。

### 需求的四块拼图

有效需求由四部分组成：**消费**取决于收入与边际消费倾向，相对稳定却不足以撑满需求；**投资**取决于资本边际效率与利率的比较，且受「动物精神」的信心波动支配，最不稳定；**政府支出**与**净出口**则提供可以主动调节的外生补充。凯恩斯的关键判断是：前两项的合力常常落在充分就业所需水平之下，缺口须由后两项填补。

## 乘数：一笔支出的连锁反应

有效需求原理给出了诊断，**乘数**则给出药方与剂量。这一概念的雏形来自凯恩斯的学生卡恩（Richard Kahn，1931）对公共工程就业效应的计算：一笔投资不仅直接创造就业，还通过收入—支出的链条派生出更多就业。凯恩斯把它系统化为收入乘数。

机制并不复杂。设边际消费倾向为 c，即每多一单位收入中用于消费的比例（0 < c < 1）。政府多支出 1 元，承包商的收入增加 1 元；他按 c 的比例消费，下游商人的收入便增加 c 元；后者再按 c 消费……如此层层传递，总收入的增加为：

1 + c + c² + c³ + … = 1 / (1 − c)

若 c = 0.8，乘数即为 5：一笔初始支出最终撬动五倍于自身的国民收入。乘数的大小取决于**漏出**的多少——储蓄是漏出，税收与进口同样是漏出，因此开放经济与累进税制下的乘数会明显小于封闭模型的估计值。这也正是乘数在实证中争论不休的焦点：凯恩斯主义者主张萧条期乘数显著大于 1，批评者则认为在接近充分就业、或公众预期到未来增税并提前收缩支出时，乘数可能接近于零。

## 流动性偏好：为什么利率救不了场

乘数讲的是财政。按理，利率本可以承担同样的调节职能：古典理论认为储蓄与投资通过利率自动平衡——储蓄多了，利率下降，投资便被刺激起来。凯恩斯以**流动性偏好**否定了这一自动机制。

他提出人们持有货币出于三类动机：**交易动机**（日常支付）、**预防动机**（应付不时之需）与**投机动机**（等待债券价格回落再入场）。利率因此不是「储蓄的报酬」，而是「放弃流动性的报酬」。当未来充满不确定、或利率已低到某种心理下限，人们宁愿持有现金也不愿买债——货币需求变得近乎无限弹性，利率无法继续下降。这就是**流动性陷阱**。

此时货币政策如同「推一根绳子」：央行可以增加银行准备金，却无法强迫银行放贷、更无法强迫企业投资，扩张因此乏力，财政政策遂成为唯一有力度的工具。反过来，当经济过热、货币需求疲软时，同一套逻辑也解释了为什么紧缩的货币政策在抑制需求上往往比扩张时更有效——你可以把马牵到水边，却不能强迫它喝水。

## 政策含义与争论

三个结论由此合成一部政策手册。其一，**节俭的悖论**：单个家庭多储蓄是美德，全社会同时多储蓄却会压低总需求、进而压低总收入，使实际储蓄量不增反减。其二，萧条期的公共工程是「把闲置资源用起来」，而非「挤占私人投资」——只要经济中确有闲置产能，政府支出的机会成本就极低。其三，繁荣期须反向操作、留出财政空间，否则长期赤字会侵蚀政策的信誉与弹药。

> 📝 编者注：乘数是凯恩斯体系中最容易被误用的部分。它成立的前提是经济中确有闲置资源；若已接近充分就业，同样一笔支出更多会表现为价格上涨，而非产出增加。
