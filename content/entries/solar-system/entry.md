# 太阳系

太阳系是以太阳为引力中心、由八大行星及其卫星、矮行星、小行星、彗星与尘埃组成的天体家族。它占据银河系一条旋臂上毫不起眼的位置，却是人类目前唯一确知孕育生命的家园。对太阳系的研究具有双重意义：一方面，它提供了检验引力理论、行星形成理论与比较行星学的「近场实验室」；另一方面，自 1995 年发现第一颗围绕类太阳恒星运行的系外行星以来，太阳系又成为理解数千个行星系统的参照原型。在「科学/自然科学基础/天文与地球科学」的知识地图中，太阳系是「天文学」观测传统的核心对象，也是从「大爆炸」宇宙学到「星系」尺度的中间环节。

本词条按「太阳 → 行星分类 → 轨道与开普勒定律 → 小天体与卫星 → 形成与演化」五章展开。

## 导读
- 太阳占太阳系总质量约 99.86%，以引力与光热支配整个系统。
- 八大行星可分为靠近太阳的岩质类地行星与外侧的气态巨行星、冰巨行星。
- 行星轨道近似椭圆，遵循开普勒三定律，其后由牛顿万有引力定律给出解释。
- 小行星带、柯伊伯带与彗星构成太阳系形成遗留的「化石」。
- 星云假说认为太阳系由旋转坍缩的气体尘埃盘在约 46 亿年前形成。

> 📝 编者注：本词条中的「太阳系」指以太阳为主星的这一具体行星系统。行星系统的普遍形成机制，请与「星系」词条中的恒星形成部分参照阅读——两者的尺度相差约十亿倍，却共享「引力主导下的坍缩与角动量分配」这一共同逻辑。
