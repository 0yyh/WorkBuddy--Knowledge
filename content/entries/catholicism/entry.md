# 天主教

**天主教**（Catholicism）是基督教三大主流传统中历史最为悠久、信众最为庞大的分支，自称「大公」（catholic，意为普世、全体）教会。**它以罗马主教（教宗）为宗徒伯多禄（彼得）的继任者，主张其在普世教会中享有首席权与训导权威；同时持守七件圣事、将圣经与圣传并列为启示的双重源头，并保留对圣母玛利亚与诸圣的敬礼。** 天主教视自身为使徒时代一脉相承的制度延续，在一〇五四年与东方教会分裂、十六世纪又因宗教改革而与新教分途后，仍维持以罗马为中心的全球教阶体系。一九六二至一九六五年的梵蒂冈第二届大公会议，标志着它主动「跟上时代」、向现代世界与普世对话敞开。

本词条按「历史与罗马权威的起源 → 教阶制度与训导权 → 七件圣事 → 核心教义：圣经传统、圣母与炼狱 → 现代处境：梵二与社会训导」五章展开。

## 导读

- 天主教以「大公」自任，主张教会从使徒时代连续不断，罗马主教为彼得宗座继承人。
- 教阶以教宗、主教、司铎三级为核心，辅以枢机团；教宗无误性于一八七〇年确定。
- 七件圣事是恩典的可见通道，其中感恩祭（弥撒）以「变体」说为信理核心。
- 圣经与圣传并重，圣母与圣徒敬礼、炼狱说构成其区别于新教的特征。
- 梵蒂冈第二届大公会议推动礼仪改革与宗教对话，重塑了现代天主教的公共面貌。

> 📝 编者注：本词条与同批「保罗」「神秘主义」及既有「基督教」「东正教」可对照。保罗书信奠定了教会「身体」论，被天主教发展为教阶与圣事传统；东正教与天主教同源却因首席权之争于一〇五四分裂。人名地名依大陆通译：Rome 译罗马、Catholic 译天主教、Peter 译伯多禄（亦作彼得）。
