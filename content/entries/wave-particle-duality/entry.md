# 波粒二象性

**波粒二象性**（Wave–particle duality）是量子世界最反直觉的特征之一：光与电子等微观客体，在不同实验条件下会分别展现波动与粒子两种看似互斥的面孔。波动面孔表现为干涉与衍射——光过双缝会织出明暗条纹，电子束打晶体也产生衍射图样；粒子面孔则表现为局域与离散——光以一份份光子被吸收，电子作为单个实体击中屏上某点。二者无法在同一实验中同时以经典物理的「既是波又是粒子」形象出现。从牛顿与惠更斯争辩光的本性，到爱因斯坦、德布罗意、玻尔层层推进，二象性最终成为量子力学的基石，并持续叩问着实在、测量与观测者之间的深层关系。

本词条按「光的微粒说与波动说之争 → 光电效应与爱因斯坦 → 电子衍射（德布罗意） → 双缝实验与互补原理 → 量子力学解释之争」五章展开。

## 导读

- **历史之争**：光究竟是粒子还是波，曾争论两百年。
- **光子假说**：爱因斯坦以光量子解释光电效应。
- **物质波**：德布罗意主张电子等也有波动性。
- **双缝之谜**：单个粒子也产生干涉，取决于是否被观测。
- **解释之争**：互补原理、多世界、隐变量等诠释各执一词。

> 📝 编者注：「波粒二象性」并非说微观物体「同时是波和粒子」，而是经典概念均不足以完整描述它，需在量子框架中理解。
