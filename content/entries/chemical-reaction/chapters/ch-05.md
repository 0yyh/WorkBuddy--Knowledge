# 能量变化：放热与吸热

化学反应总伴随能量账的变动：木柴燃烧取暖、炸药释放冲击，是能量放出；碳酸钙分解、电解水储能，则是能量吸入。反应的热效应直接关系能源、安全与工业可行性，也把「化学反应」与「热力学」紧紧相连。理解它，既能解释为什么燃烧能驱动发动机，也能说明为什么有些「理应发生」的反应在常温下依然静止。

## 断键与成键的能量差

用「化学键」的语言看，反应过程总是先断键、后成键：断开反应物中的旧键需要吸收能量，形成产物中的新键则释放能量。两者的净差构成反应的焓变：

ΔH ≈ Σ（反应物断键能）− Σ（产物成键能）

若断键耗能小于成键放能，净结果是放热，ΔH 为负；反之则吸热，ΔH 为正。燃烧反应之所以普遍强烈放热，正是因为产物中的 C=O 与 O–H 键（键能分别约 799 与 463 kJ/mol）远比反应物中的 C–C、C–H 与 O=O 键稳定，成键释放的能量远超断键所需。

## 焓与焓变

严格地说，化学反应在恒压下吸收或放出的热量称为「焓变」，记作 ΔH，单位为 kJ/mol。焓是体系的一个状态函数，只取决于当前状态，与如何到达无关——这一性质是热化学计算合法性的根基。按惯例，ΔH 为负表示体系向环境放热（放热反应），ΔH 为正表示体系从环境吸热（吸热反应）。标准状况下的焓变称标准焓变，通常以 298 K、1 bar 为基准。

需要强调：焓变只说明初末态的能量高低，与反应速率毫无关系。铁生锈同样是放热过程，只是慢到热量难以察觉。

## 放热与吸热反应

**放热反应**：甲烷燃烧 CH₄ + 2O₂ → CO₂ + 2H₂O 的 ΔH 约为 −890 kJ/mol；中和反应、多数化合反应、金属与酸反应以及呼吸作用均属此类。它们向环境释放热量，体系能量降低，是能源利用的主要形式。

**吸热反应**：碳酸氢铵受热分解、碳酸钙在约 900 ℃ 下分解为氧化钙与二氧化碳、以及光合作用固定太阳能，均需从环境吸收热量，ΔH 为正。吸热反应常需持续供热才能维持，因而在工业上意味着更高的能量成本。

## 能量图与活化能

把反应过程画在「能量—反应坐标」图上，可以看到反应物与产物分居两侧，中间横亘一座由过渡态构成的能垒。反应物与产物的能量差就是 ΔH，而能垒的高度则是活化能 Ea。这张图一举说明了两件常被混淆的事：ΔH 决定反应放热还是吸热（热力学），Ea 决定反应快到什么程度（动力学）。催化剂降低的是能垒的高度，而非两侧的高度差——这正是它「只提速、不改平衡」的图示解释。

## 盖斯定律与热化学

许多反应的焓变无法直接测量（如碳不完全燃烧生成一氧化碳），但可以间接求算。1840 年，盖斯提出：反应的热效应只取决于始态与终态，与具体路径无关。据此可把目标反应拆解为若干已知焓变的步骤，加合得到总焓变。这一方法与「标准生成焓」表配合，使化学家能够系统地计算几乎任何反应的焓变，是热化学的基石。

## 自发性：还需要熵

放热反应通常自发，但并非全部自发反应都放热——冰在 0 ℃ 以上自发融化、硝酸铵溶解时吸热却自发发生，都说明焓变不足以判定方向。完整的判据是吉布斯自由能：

ΔG = ΔH − TΔS

其中 ΔS 为熵变（无序度变化），T 为温度。只有 ΔG < 0 的过程才在恒温恒压下自发。这解释了为何高温有利于吸热且熵增的反应（如碳酸钙分解），也解释了为何温度可以「切换」反应方向。具体的热力学体系，请参见「热力学」词条。

## 热化学数据的实际应用

标准生成焓与标准焓变表的价值，在于把能量计算变成「查表加总」：任何一个反应的焓变，都等于产物标准生成焓之和减去反应物标准生成焓之和。借助这一关系，即便某些反应无法直接测量（如碳不完全燃烧生成一氧化碳，或某些寿命极短的中间体），也能间接求得其焓变。

这些数据在工程上用途广泛。燃料的「热值」本质上就是燃烧焓，它决定单位质量燃料能提供多少能量，是发动机、锅炉与燃气轮机设计的基础参数；火箭推进剂的选择同样以单位质量或单位体积的燃烧焓为核心指标，同时兼顾比冲与储运安全。在生活层面，食品包装上的「能量」标注与营养学中的千卡换算，其源头也是燃烧焓的测量——食物在量热计中完全燃烧所释放的热量，近似对应人体代谢可利用的能量。

更进一步，焓变数据还是化学平衡计算的输入。结合熵变与温度，即可由 ΔG = ΔH − TΔS 判断反应在各温度下的自发性，从而为工艺条件的选取提供依据。热力学并不能告诉我们要等多久，但它能告诉我们值不值得等——这条边界，正是热力学与动力学的分水岭。

## 小结

从反应物与产物的配平，到速率、平衡、催化与能量，五章串起了「化学反应」的全貌。它既是「化学键」重组的舞台，又是「热力学」定律的试验场：理解了反应为何发生、多快发生、停在何处、放出还是吸收多少热，我们便握住了改造物质的主动权。
