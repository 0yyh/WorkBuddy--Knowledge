# 无穷

**无穷**（infinity）指没有边界、没有尽头、不可完成的量或整体。它以两种面貌出现在数学中：**潜无穷**——可以无限延续但永远未完成的过程（数数可以一直数下去）；**实无穷**——作为完成整体的无限对象（自然数全体的集合）。两者的区分由亚里士多德奠定，统治西方思想近两千年；伽利略发现无穷集合与自身真子集「一样多」的悖论，以此论证无穷之间不可比较；康托尔的集合论则翻转全局——把「与真子集一一对应」接受为无穷的定义性特征，进而用对角线法证明无穷有严格的大小等级。与此同时，分析学以极限与收敛概念驯服了过程中的无穷，使无穷小、无穷和不再需要形而上学担保。无穷从禁忌变为工具，是数学基础史上最深刻的一次观念革命。

本词条按「芝诺到伽利略的观念史 → 潜无穷与实无穷之争 → 希尔伯特旅馆与无穷算术 → 极限与收敛 → 不同大小的无穷」五章展开。

## 导读

- 无穷不是「非常大」，而是**没有边界**；混淆这两者是绝大多数无穷谬误的源头。
- **潜无穷**与**实无穷**的区别：过程没有尽头，与过程的结果是一个完成的整体，是两回事。
- 伽利略悖论（平方数与自然数一样多）在康托尔手里反转为**无穷的定义**。
- **希尔伯特旅馆**满员仍可再客：无穷集合与真子集一一对应，加减运算在无穷处失效。
- 极限与 ε-δ 语言让「无限接近」获得精确定义——分析学不需要无穷小实体也能运转。
- 对角线法证明实数严格多于自然数：无穷是一个有等级的家族，不是单一的概念。

> 📝 编者注：本词条与「集合论」互为表里——无穷的严格理论是集合论的核心成果，本词条侧重观念史与直觉，技术细节见彼处；与「欧几里得几何」的关联在于：无穷既是几何中「直线可无限延长」的公设背景，也是非欧几何打破单一空间观后「无穷多样貌」思想的先声；与「哥德尔不完备定理」的关联在于：足够强的系统中「真」超出「可证」的剩余部分，正是由实无穷的语义概念所刻画的。
