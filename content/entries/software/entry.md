# 软件

**软件**（Software）是告诉计算机「做什么、怎么做」的逻辑实体，由**程序**（可执行的指令序列）、**数据**（程序处理的对象）与**文档**（说明与约定）三者构成。它不像硬件那样可触摸，却正是它让芯片从「会动的沙子」变成电话、银行、飞船与游戏。一九四七年「软件」一词随程序概念出现，此后软件逐渐从附属于机器的附件，成长为产值与社会影响都极其庞大的独立产业。它的本质特性是**无形可复制**：写一份、印万份，边际成本近乎零，这也使它既带来空前丰饶，也引发版权与垄断的持久争论。理解软件，是理解数字时代如何运转的起点。

本词条按「软件是什么 → 软件工程 → 操作系统作为基础软件 → 应用与系统之分 → 开源、许可与演化」五章展开。

## 导读

- 软件=程序+数据+文档，是无形却承载功能 logic 实体。
- 软件可无限复制，边际成本近零，是版权争论的根源。
- 软件工程用系统化方法应对规模与协作的复杂度。
- 操作系统是承上启下的系统软件，管理硬件、服务应用。
- 应用软件解决具体任务，系统软件提供运行地基。
- 开源以许可证开放源码，重塑了软件的创作与权力结构。

> 📝 编者注：常把「软件」等同于「手机上的App」，这太窄。小到一个微波炉里的控制程序，大到全球股市的交易系统，都是软件。App 只是面向消费者的应用软件一角；更庞大的体积藏在系统软件与工业嵌入式软件里，它们很少被普通人看见，却支撑着现代社会的每一次运转。
