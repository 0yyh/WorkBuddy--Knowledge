# 东正教

**东正教**（Orthodoxy 一词源自希腊语 orthos 直的、真正的，与 doxa 荣耀、敬拜连用，即「正确的敬拜」）是与天主教、新教并立的基督教主要传统之一，其源头是拜占庭帝国的教会。**它以大公会议、正统神学与悠久的礼仪传统为三项支柱，权威结构以牧首区与修道院为中心，而非以单一教宗为首。** 从四世纪的尼西亚与卡尔西顿公会议，到八世纪的圣像破坏之争及其后的圣像崇拜胜利，再到 1054 年的东西互绝与 1453 年拜占庭的陷落，东正教在「正统」的界定上经历了多次论争，而每一次论争都同时是政治性的。其形成塑造了基督教世界的地理分野：东欧、巴尔干、俄罗斯、埃塞俄比亚与亚美尼亚的信仰传统皆源于此。本词条按早期普世教会 → 公会议与正统的确立 → 圣像之争 → 东西分裂 → 多民族形态五章展开。

本词条按「普世教会与君士坦丁的皈依 → 公会议与正统的界定 → 圣像与圣像破坏之争 → 东西分裂的进程 → 莫斯科、巴尔干与多民族形态」五章展开。

## 导读

- 东正教承认前七次大公会议为权威依据，其「正统」是相对于这些会议而定义的。
- 圣像破坏之争不仅是神学争论，也直接牵涉皇权、教权与拜占庭国家的身份。
- 1054 年的互绝是累积分歧的结果，真正的裂痕涉及教义、礼仪与权力三重层面。
- 东正教没有单一教宗，君士坦丁堡牧首区在长时间内居于首位，但地位并不构成最高教权。
- 东正教是一个多民族传统，包含希腊、俄罗、塞尔维亚、罗马尼亚、埃塞俄比亚与亚美尼亚等多个形态。
