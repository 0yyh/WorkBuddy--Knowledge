# 福利国家

**福利国家**（Welfare State）指国家通过社会立法与公共财政，系统性地保障公民最低生活标准、分担疾病失业养老等风险的制度形态。它解决的问题是：市场按边际产出分配，必然留下无力者与失灵时刻；福利国家以社会权利的名义把「人的基本体面」从慈善移出、从市场移出，变成公民身份的组成部分。其规范基础由马歇尔的公民权三段论（公民自由→政治权利→社会权利）确立，比较研究以蒂特马斯的三种模式与艾斯平-安德森的「三个世界」为经典框架，而老龄化、去工业化与全球化则使「危机与改革」成为其下半场的主题。

本词条按「定义与社会权利：马歇尔的公民权三段论 → 蒂特马斯的三种模式 → 艾斯平-安德森：福利资本主义的三个世界 → 危机与改革：结构压力与新右派批判 → 东亚福利模式的特殊性」五章展开。

## 导读

- 福利国家的正当性论证不是「仁慈」，而是权利：马歇尔论证契约自由在实质不平等面前空洞化，社会权利是公民身份的完成——这使福利从可裁量的恩惠变成可主张的地位。
- 蒂特马斯的方法论是本领域的分水岭：社会政策从来不是中性的技术，而是价值的制度化；比较研究的统计口径本身就预设了「什么算福利」。
- 艾斯平-安德森把体制差异变成可测量的问题：去商品化指标测的不是花多少钱，而是摆脱市场胁迫的自由——北欧与英美的支出差距缩小后，规则逻辑的差距仍在。
- 危机叙事需要检验：面对相同的老龄化数据，不同体制给出相反处方——数据设定可行域，价值与制度决定可行域内的选择，紧缩并非唯一解。
- 它与公共财政（public-finance）的对立构成本领域的基本张力：福利的每一项权利都是财政的永久承诺，政治学上的「权利逻辑」与财政学上的「预算约束」无法互相化约。

> 📝 编者注：常见误解是把福利国家等同于「高支出」或「社会主义」。支出水平与体制逻辑可以背离，北欧各国生产资料基本私有——福利国家讨论的是再分配与风险共担的规则，不是所有制的归属。
