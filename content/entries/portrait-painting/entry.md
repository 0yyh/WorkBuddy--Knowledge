# 肖像画

**肖像画**（Portrait painting）是把具体的人——通常是脸，连同姿态、衣饰与 surroundings——画下来的绘画。它和人类其他画种最不同的地方，在于它始终盯着「这一个」而非「这一类」：画的是张三而非「人」。这一定位让肖像画天然背着功能：替远行或已故的人留在眼前（纪念），替掌权者彰显威仪（权力），替家族与行会留下凭证（记录）。可是「画得像」从来不够——观者还想知道这人「是什么样的人」。于是肖像画在「像」与「神」之间拉扯：既要可辨，又要传神。西方多半从可辨走向心理深度，中国则早早把「传神」奉为最高准则。本词条先问肖像究竟替人做什么，再分述中西两条传统，看摄影如何夺走它的老本行，又如何把它推向内心与身份政治的当代现场。

本词条按「肖像画替人做什么 → 西方肖像：从墓葬、宫廷到市民 → 东方写真：从写貌到传神 → 现代肖像：摄影冲击与心理深处 → 当代肖像：身份、自拍与算法」五章展开。

## 导读

- 肖像画的核心是「这一个」具体的人，而非泛泛的「人」；它因此始终带着纪念、权力或记录的功能。
- 「像」与「神」的张力贯穿全史：既要可辨，又要传神，中西都把后者看得越来越重。
- 西方肖像从埃及墓葬面具、古希腊罗马蜡像，走到文艺复兴订制像与荷兰市民群像，渐入心理深度。
- 中国写真重心从「写貌」移向「传神」，帝王图、禅宗顶相与民间容像各有其用。
- 摄影术夺走肖像的纪实垄断，反而把绘画肖像推向个性、内心与现代主义。
- 它与**油画**、**西方绘画**、**文艺复兴**、**美学**交叉最深；同批的**风景画**、**抽象绘画**也常以人为邻。
