# 民族国家

**民族国家**（Nation-state）指一种国家形式：国家的领土边界与一个「民族」共同体的分布大致重合——一个民族拥有一个主权国家，而国家又通过教育、语言与象征塑造民族认同。它不同于中世纪的王朝国家（领土随王室婚姻变动、与民众认同无关），也不同于多民族帝国（如奥斯曼、奥匈）。今天，「民族国家」几乎成为国家形式的默认模板，然而其历史不过三百余年，且始终面临内部族群多元与外部主权让渡的双重张力。理解民族国家，是理解现代政治认同、边界冲突与全球秩序的起点。

本词条按「民族与国家的结合 → 民族国家的形成历程 → 民族主义的类型 → 民族国家与主权体系 → 当代挑战」五章展开。

## 导读

- 民族国家的本质是「**国家与民族的相互塑造**」：国家制造民族，民族支撑国家。
- 印刷资本主义、普及教育与战争竞争，是民族形成的关键引擎。
- 「公民民族主义」与「族裔民族主义」两种路径，决定了民族国家的包容或排他。
- 民族国家体系是全球政治的骨架，主权原则是其保护壳。
- 全球化、分离主义与跨国移民，正同时从内外侵蚀这一形式。

> 📝 编者注：「民族」在此指政治共同体意义上的 nation，而非族裔学意义上的 ethnicity。中文语境中「民族国家」常被误读为「单一民族国家」，实际上绝大多数民族国家都是多族群国家，只是国家努力塑造一个统一的「国族」认同。
