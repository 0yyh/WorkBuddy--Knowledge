买不买保险、上不上大学、贷款是否违约——经济学大量关心的问题因变量只有两个取值。因变量是 0/1 时，普通最小二乘（ordinary-least-squares）虽然能跑，却处处别扭；最大似然框架则提供了一对标准答案：Probit 与 Logit。它们是 MLE 在经济学中曝光度最高的应用，也是理解「分布设定换效率」的最佳标本。

## 线性概率模型的失败

最朴素的做法是直接回归：$P(Y=1 \mid X) = X\beta$，即线性概率模型（LPM）。两个结构性缺陷随之而来。其一，**预测越界**：线性函数无界，而概率必须落在 [0,1]，极端 X 处的「预测概率」会小于 0 或大于 1。其二，**异方差是内生的**：伯努利结果的方差为 $p(1-p)$，随 X 变化，OLS 标准误天然有误。LPM 并非一无是处（系数近似平均边际效应、实现简单，政策模拟中常作快速参考），但作为主模型，它把概率的结构问题交给了一个不为概率设计的函数。

## 潜变量框架与两个链接函数

Probit/Logit 从同一个潜变量模型出发：不可观测的效用或倾向 $Y^* = X\beta + \varepsilon$，观测到的 $Y = \mathbf{1}\{Y^* > 0\}$。于是 $P(Y=1 \mid X) = F(X\beta)$，其中 $F$ 是 $\varepsilon$ 的累积分布函数。两种主流选择：$\varepsilon$ 服从正态分布得 **Probit**（$F$ 为标准正态 CDF $\Phi$）；$\varepsilon$ 服从逻辑斯蒂分布得 **Logit**（$F(x) = e^x/(1+e^x)$）。两个分布形状相近（逻辑斯蒂尾部略厚），绝大多数样本中两组拟合与边际效应相差无几。写出个体对数似然 $\ell_i = Y_i \log F(X_i\beta) + (1-Y_i)\log(1-F(X_i\beta))$，用数值优化最大化即可——这正是第一章「连乘化求和」的教科书舞台。因为概率天然被 $F$ 压进 [0,1]、方差结构内置在模型中，LPM 的两个缺陷被一并解决。

## 系数不是边际效应

解读是初学者最容易翻车的地方。Probit/Logit 系数是**潜变量尺度**上的效应：$\beta$ 变化一单位改变的是 $Y^*$，经由 $F$ 的弯曲形状转换为概率效应。因此：其一，**边际效应随 X 取值变化**——对概率 0.5 附近的人影响最大、对 0.02 的人几乎无效，报告平均边际效应（AME）时应说明其口径；其二，Logit 有额外福利：$e^{\beta}$ 是**几率比**（odds ratio），「几率」对数线性使系数在固定样本结构下跨组可比；其三，同一数据下 Probit 与 Logit 系数**不可直接互比**（尺度不同），比较宜用边际效应或标准化系数。这些细节的共同教训是：非线性模型中，「系数」与「效应」是两个概念。

## McFadden 与离散选择帝国

麦克法登（Daniel McFadden）在 1974 年把二元 Logit 推广为**条件 Logit / 多项 Logit**，奠定了现代离散选择分析：个体在 $J$ 个选项中选择，选项效用含个体特征与选项属性，若误差服从独立第 I 类极值分布，选择概率即为多项 Logit——它由 McFadden 从随机效用理论推导而来，与最大似然天然配套。离散选择模型自此席卷交通需求、职业选择、品牌份额与居住选址，麦克法登因此获 2000 年诺贝尔经济学奖。多项 Logit 的著名软肋是 **IIA 假设**（无关选项独立性）：红色巴士-蓝色巴士悖论揭示了选项间替代模式的过强约束，催生了嵌套 Logit、混合 Logit 等扩展——但那已是另一个词条的故事。

> 📝 编者注：报告 Probit/Logit 结果的规范做法——同时给出系数表与平均边际效应（及标准误），并说明边际效应在哪个点或哪个分布上取平均。只报系数的表格几乎无法被政策读者正确使用。

Probit/Logit 展示了 MLE 的强势场景。但 MLE 与 OLS 的关系远不止「二选一」——正态假设下它们竟是同一个估计量。下一章梳理这对方法的分与合。
