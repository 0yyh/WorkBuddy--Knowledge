# 明治维新

明治维新（1868年起）是日本由幕府封建体制转向中央集权的近代民族国家的根本转折，时间上覆盖幕末危机至明治初期（约1853—1890）。其地域范围以日本列岛为本体，影响外溢至朝鲜半岛、中国与整个东亚旧秩序。核心主题是在西方列强压力下，以「倒幕与中央集权」为政治前提，以「脱亚入欧」为精神旗帜，快速推进宪政、工业化与国民意识改造。其代表性特征包括黑船来航、废藩置县、明治宪法与议会、殖产兴业、文明开化，以及甲午、日俄两战的胜利——它使日本成为亚洲第一个西式强国，也由此开启了对外扩张的轨道。

本词条按「幕末危机：黑船来航与倒幕 → 政治重构：废藩置县与明治宪法 → 殖产兴业：工业化与财阀 → 文明开化：教育、军制与国民意识 → 对外扩张与东亚冲击：甲午、日俄与近代东亚」五章展开。

## 导读

- 明治维新的真正起点是「危机感」而非「蓝图」：黑船来航暴露的技术与国力落差，使日本精英认定不近代化即亡国，倒幕因此获得超越派阀的合法性。
- 废藩置县以和平赎买化解了封建武士的反抗：用公债置换藩主收入，既完成中央集权又不引发大规模内战，这是日本近代化社会成本远低于多数革命的关键。
- 「殖产兴业」走政府先导、财阀接管的路径：官营模范工厂示范后廉价转让给三井、三菱等特权资本，形成政商一体的工业化模式。
- 文明开化实为「国民塑造」工程：义务教育、征兵制与天皇制意识形态把地方臣民改造为效忠中央的国民，民主制度因此长期停留在形式层面。
- 明治日本的扩张逻辑内嵌于其近代化：殖产兴业所需的原料与市场，加上「与列强平等」的身份焦虑，使「脱亚入欧」必然滑向「侵亚」——甲午、日俄两战即其外显。
- 它与鸦片战争后的中国构成镜像对照：同受西方冲击，日本以制度整体置换取胜，清朝洋务运动止步「中体西用」，这一反差深刻塑造了此后百年的东亚格局（可参 opium-war）。

> 📝 编者注：本词条归入「近代史」。明治维新常被简化为「日本成功地西化」，但更应理解为非西方世界面对生存危机时一条特殊的近代化路径：它没有经历欧洲式的社会革命，而是以旧精英（武士、藩阀）为主导，用国家主义统合传统资源来完成近代化。这种「自上而下的近代化」既造就高速崛起，也埋下军国主义与对外扩张的隐患。与中国的比较视角尤值留意——同遭西方冲击，日本的「制度整体置换」对比清朝洋务运动的「器物优先」，结果迥异（可参 opium-war、first-world-war）。
