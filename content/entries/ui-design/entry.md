# 界面设计

**界面设计是安排人与数字系统之间那层接触面的实践，决定了用户如何看见、如何操作、如何被回应。** 它站在人与机器之间，把复杂的计算翻译成人可以直觉上手的秩序。

本词条按「界面作为中介 → 布局与层级 → 交互与反馈 → 系统与组件 → 智能与自适应」五章展开。

## 导读

- 界面是人与系统之间的中介，承担翻译与组织的双重任务。
- 布局与层级决定信息被看见的先后顺序。
- 交互与反馈建立可预期的操作感，减少不确定性。
- 组件与系统保证跨页面的一致，降低学习成本。
- 智能与自适应正使界面从固定走向因人而异的动态。
