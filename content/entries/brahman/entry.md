# 梵

**梵**（ब्रह्मन् / Brahman）是印度教思想中最高的绝对概念，意指遍满万有、超越一切属性与差别的终极实在。在《梨俱吠陀》里，「梵」原指祭祀所具有的神圣创造力与咒力；到了《奥义书》时代，它升华为宇宙本体与终极原理的哲学术语，被描述为「非如此、非如此」的不可言说者，同时又是万物由之以出、依之以存、归之以灭的根源。梵的提出，标志着印度思想从注重外在祭祀转向内在冥想与哲学思辨的关键转折。它不仅是概念，更是修行者亲证的目标：奥义书的名句「汝即彼」（梵我同一）揭示了梵与个体灵魂阿特曼在本体上的同一性。

本词条按「梵在吠陀与奥义书中的起源 → 梵我合一：核心哲学命题 → 梵与世界：创造、维持与幻 → 不同的梵观：不二论与二元论 → 梵在印度教实践与当代思想中的回响」五章展开。

## 导读

- 梵由吠陀的「祭祀效力」演变为奥义书的「绝对本体」，是印度哲学化的枢纽。
- 「梵我合一」主张个体灵魂与绝对者同一，是印度解脱论的理论基石。
- 梵与世界的关系长期争议：不二论视宇宙为幻，二元论视世界为梵的真实显现。
- 商羯罗以「无属性梵」为最高实在，罗摩努阇则主张「有属性梵」更具人格。
- 梵的概念为比较哲学提供了一神论之外的「绝对者」范式。

> 📝 编者注：梵（Brahman）与梵天（Brahma，创造神）常被混淆；前者是中性绝对本体，后者是三相神中的创造位格，二者层级不同。
