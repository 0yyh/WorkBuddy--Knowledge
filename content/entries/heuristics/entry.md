# 启发式

**启发式**（heuristic）是人类在时间、信息或认知资源受限的情境下，用来快速估计与决策的简化策略。它绕开复杂的精确算法，转而依赖「差不多就行」的经验法则。多数情境下，启发式是高效与节俭的；可一旦环境不匹配，它会系统性地把人引向判断偏差。

本词条按「起源与定义 → 三大经典启发式 → 启发式与偏差 → 启发式的边界与价值 → 在学习与决策中的运用」五章展开，并与「认知偏差」「辩证法」词条互参。

## 导读

- 启发式不是非理性的同义词，而是**有限理性**下的适应性产物。
- 启发式与偏差（bias）相伴而生：同一把「快刀」既能切菜也能伤手，关键是看清何时、用什么情境。
- 系统一/系统二：启发式多由直觉快速的系统一驱动；系统二的介入可校正其失准，但会消耗更多时间与心力。
- 学习与决策中，**主动识别启发式边界**比简单抛弃启发式更现实、更有效。

> 📝 编者注：本词条侧重认知心理学与决策科学意义上的「启发式」。其在算法与人工智能语境中另指「启发式算法」（heuristic algorithm），二者共享「以可接受代价获得可用解」的核心理念但用途不同，本文不展开后者。
