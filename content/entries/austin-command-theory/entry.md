# 奥斯汀主权命令说

**奥斯汀主权命令说**（Austin's Command Theory of Law）是英国法学家约翰·奥斯汀（John Austin，1790—1859）在《法理学的范围》（1832）中给出的法律定义，也是现代**法律实证主义**最经典、也最受争议的分析框架。它的核心命题极其锋利：法律不过是政治社会中一个「主权者」对臣民发布的、以**制裁**为后盾的**命令**。换一种说法，所谓法，不是自然秩序、不是神的意志、也不是道德理想，而是某个实际掌握权力的人或团体，凭借对不服从者施加惩罚的能力，要求他人为或不为某种行为的明示愿望。奥斯汀由此把「法实际上是什么」与「法应当是什么」一刀切开，主张法理学只研究前者。这一剥离使法学得以像研究语言或物理一样，对人的命令与服从作冷静的概念分析，却也因此被批评为忽视了法律内在的规则性、制度性与道德维度。

本词条按「主权者与命令的界定 → 法律作为命令的结构分析 → 哈特对命令说的系统批评 → 对功利主义与边沁的继承 → 当代意义与内在局限」五章展开。

## 导读

- 命令说的三要素是「主权者、命令、制裁」：缺了其中任何一项，奥斯汀便不认为是严格意义上的法，这是理解整说的钥匙。
- 它把「实证法」与「自然法/道德」彻底分开：法之所以有效，靠的是命令者的权力，而非其内容是否正义，这是实证主义区别于自然法理论的根本立场。
- 奥斯汀的「主权者」靠「习惯性服从」界定，不依赖成文宪法：这既能解释早期国家的权力现象，却也为「主权者来自何处」留下难题。
- 哈特在《法律的概念》中以「初级规则与次级规则」取代命令说，指出法律并非靠恐惧制裁维系，而是社会成员对规则的「内在观点」。
- 命令说虽被主流法理学修正，但其「先弄清法律是什么再谈好坏」的分析精神，仍是当代法理学不可跳过的起点。
