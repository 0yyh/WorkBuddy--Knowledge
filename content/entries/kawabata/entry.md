# 川端康成

**川端康成**是日本二十世纪最具国际声望的小说家，也是第一位摘得诺贝尔文学奖的日本人。对零基础读者来说，他像一位用文字作画的水墨画家：笔下常是雪国列车窗上的倒影、伊豆山道上清瘦的舞女、古都里盛放的紫花地丁——景致极美，情绪极淡，却总在美丽底下淌着一股「一切终将消逝」的哀愁。他早年参与「新感觉派」，试图以崭新的感官笔法改写日语小说的节奏；中年后则愈加深潜于日本古典美学，把「物哀」「幽玄」与现代人的孤独 connected 起来。代表作《伊豆的舞女》写少年与舞女的淡淡情愫，《雪国》写东京男子与雪国艺伎之间徒劳而纯净的爱，均已成为世界文学中的东方名片。本词条按「生平与文学起点 → 雪国等代表作 → 物哀与日本美学 → 战后创作与诺奖 → 风格争议与文学史地位」五章展开。

## 导读

- 川端康成是首位获诺贝尔文学奖的日本人，一九六八年以「日本之美」的代表性获得世界承认。
- 他早年属「新感觉派」，追求以感官、瞬间印象重构小说语言。
- 代表作《雪国》《伊豆的舞女》写美丽的易逝与官能的哀愁，极具画面感。
- 其美学深植「物哀」「幽玄」，常于虚无中见雅静。
- 晚年作品如《千只鹤》《古都》延续对日本传统之美的挽歌式书写。

> 📝 编者注：川端康成一九七二年在寓所煤气中毒离世，一般认定为自杀，本词条基于通行文学史叙述，对其死因不作渲染。
