# 航空

**航空**（Aviation）指以重于空气的飞行器在大气层内飞行的技术、产业与运输活动。它的工程核心是一组精妙的平衡：**升力**（机翼与空气的相对运动产生）、**推力**（发动机提供）、**重力**与**阻力**——飞行的全部技术史，就是不断在这四力之间争取更大航程、更高速度、更低油耗的历史。从 1903 年莱特兄弟十二秒的颠簸飞行起步，航空经两次世界大战的极限催化（引擎、空气动力学与批量制造），又在战后以喷气发动机进入大众化时代，最终把跨洲旅行从数周压缩到十余小时，成为全球化的人员与高价值货物流动的支柱。航空史的独特结构在于：**军事与商业交替驱动，技术与制度并重**——适航体系与飞行安全制度的成熟，与发动机的进步同等重要。

本词条按「从滑翔到动力飞行 → 两战与喷气革命 → 民航全球化 → 技术体系 → 可持续航空的挑战」五章展开。

## 导读

- 航空的技术内核是**四力平衡**：升力、推力、重力与阻力。
- 莱特兄弟的贡献是「可控性」：让飞行从滑翔变成可操纵的持续飞行。
- 两次大战是航空技术的极限试验场，喷气发动机是分水岭。
- 宽体客机与枢纽网络使民航全球化，跨洲旅行进入大众时代。
- 碳排放约束把航空推向可持续燃料与飞机构型的再创新。

> 📝 编者注：本词条聚焦大气层内的航空，太空飞行见「航天」词条；发动机细节与「内燃机」（活塞式）互为补充。
