# 万维网

**万维网**（World Wide Web，简称 WWW 或 Web）是运行在互联网之上的**超文本信息系统**：任何一份文档都可以通过「链接」指向另一份文档，用户点击链接即可跳转。它由三项技术构成三位一体——**URL**（统一资源定位符，给每个资源一个全球唯一的地址）、**HTTP**（超文本传输协议，规定浏览器与服务器如何对话）与 **HTML**（超文本标记语言，规定文档如何写、链接如何嵌）。1989 年，英国物理学家蒂姆·伯纳斯-李在瑞士 CERN 为解决科研文献共享而发明了这套体系，并说服 CERN 于 1993 年放弃专利、免费开放——这一决定使万维网得以在互联网上引爆大众化浪潮。今天，「上网」在多数人心中就是「上 Web」，它已成为人类知识与商业的基础层。

本词条按「问题与发明 → 三大基石 → 浏览器大战与标准化 → 从 Web 1.0 到移动时代 → 开放与平台化之辩」五章展开。

## 导读

- 万维网 ≠ 互联网：前者是信息空间，后者是承载它的网络设施。
- URL、HTTP、HTML 三位一体，用「链接」重写了知识的组织方式。
- 1993 年 CERN 放弃专利，是 Web 大众化的制度前提。
- Mosaic/Netscape 引爆大众浏览器，随后浏览器大战催生了现代 Web 标准。
- 从门户到社交到移动应用，Web 的每次跃迁都重演开放与垄断的拉锯。
