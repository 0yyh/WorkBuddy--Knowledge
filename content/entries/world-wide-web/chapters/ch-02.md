万维网的力量来自三项技术的**极简组合**。每一项都朴素到几乎平凡，但组合起来，重写了人类知识的组织方式。

**URL（统一资源定位符）**解决「如何指认」。一个 URL 由协议名、主机名与路径构成（如 http://www.example.com/page），全球唯一、可书写、可引用。它的革命性在于：任何文档都可以在正文里写下另一份文档的**完整地址**，读者点击即达——知识的引用从脚注与书单，变成了「一键跳转」。URL 也使 Web 成为一个**可书写的空间**：你可以在自己的页面上链接任何人的任何页面，无须许可。

**HTTP（超文本传输协议）**解决「如何传输」。它是一个极简的**请求—响应**协议：浏览器发一个「GET /page」的请求，服务器返回文档内容。HTTP 刻意设计为**无状态**——服务器不记住上一个请求是谁发的，这使服务器可以为海量并发服务，也使协议简单到任何设备都能实现。它的可扩展性同样关键：头部字段可以携带缓存、认证、内容类型等任意信息，为后来的cookies、API 调用留足了空间（详见「HTTP」词条）。

**HTML（超文本标记语言）**解决「如何呈现」。它用标签描述文档的**结构**——标题、段落、列表、图像，以及最重要的：`<a href="...">` 链接。HTML 刻意不规定「长什么样」，而只规定「是什么」；样式交给浏览器渲染。这一「结构与样式分离」的思想，使同一份文档可以在任何设备上合理显示，也为后续 CSS 的出现留下接口。

> 📜 「Web 的力量在于它的普适性——任何人都能访问，无论何种设备、何种能力。」 —— 蒂姆·伯纳斯-李对 Web 设计原则的表述

三项基石共同的制度属性，比技术属性更重要：它们都是**开放标准**，由 W3C 与 IETF 等组织以公开流程维护，任何人无须授权即可实现自己的浏览器或服务器。正是这种「可自由实现」保证了 Web 的中立与繁荣——它不属于任何公司，因此人人都愿意在上面建设。

> 📝 编者注：URL 的另一个名字 URI（统一资源标识符）更严格，URL 是其子集。日常语境两者常混用。
