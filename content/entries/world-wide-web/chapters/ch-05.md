万维网诞生时被设计为一个**无主的空间**：开放协议、自由链接、无须许可即可发布。但 Web 的商业史，是一部**平台化**的历史——开放的地基上，长出了少数几座流量巨型建筑。开放与平台化之辩，是 Web 四十年来未曾落幕的元问题。

**张力的结构**清晰可见。协议层（HTTP、HTML）属于公共品：任何公司都必须实现它，谁也无法独占。应用层则不同：搜索引擎、社交网络、电商与短视频平台在各自的领域聚合了海量用户，成为事实上的**入口与守门人**——它们决定什么内容被看见（排序与推荐算法）、商家能否触达用户（应用商店抽成）、以及数据归属谁。平台的网络效应（详见「数字革命」词条）使这种权力高度集中，且天然具有自我强化性。

**批评集中于三点**。其一，**锁定与抽成**：应用商店的三成抽成、平台的算法黑箱，被认为抑制竞争与创新。其二，**数据垄断**：用户行为数据沉淀于平台，形成他人难以复制的护城河，也使隐私成为系统性风险。其三，**公共广场的私有化**：言论的边界由平台规则而非公共程序决定，其正当性备受争议。

**制度与技术的回应**沿两条线展开。制度线：欧盟 GDPR 确立数据可携带权与被遗忘权，《数字市场法》要求「守门人」平台开放互操作、不得自我优待——用反垄断与互操作性给平台「松土」。技术线：去中心化尝试层出不穷——联邦宇宙（Mastodon 等 ActivityPub 生态）、P2P 网络、以及区块链社区主张的「Web3」，都试图把身份与数据主权还给用户。

> 📜 「Web 的设计初衷是让任何人都能自由地创造与链接，而不仅是消费。」 —— 蒂姆·伯纳斯-李对 Web 初心的重申

值得清醒的是：**开放协议从未失败**——每一次平台封闭引发的迁移（如 RSS 订阅、开放 API、跨平台互操作）最终都回归协议层的价值。真正的问题不是「开放 vs 封闭」的二选一，而是如何在平台效率与用户主权之间，找到制度与技术都认可的平衡点。这场辩论没有终局，因为它本质上问的是：数字社会的公共空间，应当如何治理。
