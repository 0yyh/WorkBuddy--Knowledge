万维网从小众科研工具到大众媒介的转折点，是**浏览器**——用户直接面对的那扇窗。

1993 年，伊利诺伊大学 NCSA 的**Mosaic** 浏览器发布。它首次把图片与文字混排显示、提供直观的图形界面，使「上网」不再需要命令行知识。Mosaic 在一年内被数十万人下载，Web 流量在互联网总流量中的占比飙升。其作者马克·安德森随后创办 Netscape，1994 年推出 Netscape Navigator——它占据九成市场份额，成为大众互联网的第一个入口。

竞争随之而来。微软把 Internet Explorer 捆绑进 Windows，以系统级免费分发对抗 Netscape 的付费模式。1995—2001 年的**浏览器大战**是一把双刃剑：一方面，竞争使浏览器功能爆炸式增长——JavaScript、CSS、Cookie、动态 HTML 都在此期间诞生；另一方面，两家公司竞相推出**私有扩展**，同一个页面在不同浏览器中呈现迥异，开发者疲于适配，「为 IE 专门优化」甚至成为 Web 世界的既成事实。开放标准面临被两大巨头瓜分的危险。

战后的转折点是**标准化**。W3C（万维网联盟，伯纳斯-李 1994 年创立）与后来的 WHATWG 推动浏览器回归公开规范；2003 年起，Netscape 遗产孵化出的 Firefox、苹果 Safari、谷歌 Chrome（2008）相继以「严格遵循标准」为卖点，私有扩展的碎片化逐步收束。HTML5 与现代 JavaScript 引擎（V8 等）确立了今天统一、跨平台、能力强大的 Web 平台——浏览器从「看文档的窗口」进化为「跑应用的操作系统」。

> 📜 「浏览器大战真正留下的遗产，不是某家公司的胜利，而是标准对商业的胜利。」 —— Web 史研究的共识性结论

这段历史的启示在于：Web 的中立与统一不是技术的自然结果，而是**标准治理与商业博弈**的产物。每一次新平台（移动应用、小程序、AI 入口）的出现，都重演着「开放 Web vs 封闭平台」的同一场拉锯——这是下一章的主题。

## 大战的三个阶段

浏览器大战并非一场混战，而可大致分为三段。**第一段（1993—1995）**是图形浏览器的普及：Mosaic 让图片与文字同页显示，Netscape 以更快的迭代与更好的体验占据绝对优势，Web 从科研工具变成大众媒介。**第二段（1995—1998）**是捆绑与私有扩展的对抗：微软把浏览器并入操作系统，以免费分发摧毁对手的付费模式；双方各自推出新标签与新脚本能力，同一页面在不同浏览器中渲染迥异，开发者被迫为特定浏览器写分支代码。**第三段（1998 年以后）**是标准化与多元化的回归：Netscape 以开源方式延续为 Mozilla 与 Firefox，苹果与谷歌相继入场，市场份额重新流动。

## 私有扩展为何危险

私有扩展的风险不在于「用了新技术」，而在于**兼容性成本的外部化**。当一家厂商能单方面定义网页的写法，开发者就不得不向强势者适配，标准组织沦为追认机构；对用户而言，则是「只有装了某个浏览器才能打开某个网站」，选择权被剥夺。更深一层的后果是，创新方向被市场份额而非实际需求决定。

因此标准化并不只是技术工作。它需要厂商愿意把短期优势让渡给长期互操作，也需要标准组织足够开放、足够快，避免被某一家绑架。HTML5 之所以成功，正是因为它同时满足了「多家实现」与「能力真能用」两个条件。

## 浏览器如何变成操作系统

当网页中加入了脚本、样式、存储与网络请求，浏览器就具备了执行任意程序的能力，也就必须承担操作系统的职责：进程与内存隔离（一个标签页崩溃不应拖垮全部）、沙箱与权限控制（摄像头、定位、剪贴板需用户授权）、资源调度与安全更新。现代浏览器的复杂度因此与操作系统相当。

这一演变带来一组张力：页面越强大，体验越接近原生应用，Web 就越有竞争力；但能力越大，攻击面也越大，浏览器厂商不得不持续投入安全工程，并对跨站脚本与第三方内容施加越来越严格的限制。浏览器从「看文档的窗口」到「跑应用的平台」的转变，正是 Web 演化在终端上的集中体现。
