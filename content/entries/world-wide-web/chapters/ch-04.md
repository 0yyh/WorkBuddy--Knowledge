万维网的演进，常被概括为从 1.0 到 2.0 再到移动时代的**三次交互跃迁**。每一次跃迁，都是「人在 Web 上做什么」的重新定义。

**Web 1.0（约 1991—2004）：浏览的 Web**。网站是少数人编写、多数人阅读的静态文档集合：门户网站（Yahoo、新浪）、搜索引擎、企业官网。用户是读者，内容是稀缺品，交互主要是「找与看」。「网页」的概念由此深入人心——一份份通过链接相连的文档。

**Web 2.0（约 2004—2010）：参与的 Web**。技术（AJAX 使网页可局部刷新、带宽与存储成本下降）与理念（「用户生成内容」）共同引发跃迁：博客、维基百科、YouTube、Facebook 相继兴起，**用户成为内容的生产者**。蒂姆·奥莱利在 2004 年提出「Web 2.0」概念，核心判断是：Web 的价值不再来自页面，而来自**参与的网络效应**——用户越多，平台越有价值（平台逻辑与「数字革命」词条所述同构）。网页也从此越来越像「应用」：Gmail 证明邮件客户端可以跑在浏览器里，地图、文档、表格相继上线。

**移动时代（2010 至今）：随身的 Web 与应用的分工**。智能手机把 Web 装进口袋，但也带来一次结构分化：**原生应用**（App）凭借更好的性能、传感器访问与推送通知，接管了大量高频场景（社交、视频、支付）；**移动 Web** 则保留为触达长尾信息的入口与「免安装」的补充形态。微信小程序、PWA（渐进式 Web 应用）等形态，可视为 Web 与 App 两种范式的混合尝试。其结果是：Web 的开放性优势（无需许可即可发布）与 App 的体验优势（性能与系统集成）形成了持续的分工与拉锯。

> 📜 「Web 2.0 的本质是：参与即架构。」 —— 蒂姆·奥莱利《什么是 Web 2.0》的核心思想

三次跃迁的共同规律是：**技术降低创作与交互的门槛，门槛降低改变参与结构，参与结构重构商业格局**。理解这条规律，也就理解了为何 Web 的治理之争（开放协议 vs 平台权力）从未平息——它是下一章的主题。

> 📝 编者注：Web 2.0 不是技术标准的更替，而是使用模式与商业模式的代际标签。类似的「Web 3.0」一词已被区块链社区借用，含义与本文所述演进线不同，读者须注意区分。

## 跃迁背后的技术条件

把「用户成为生产者」归结为理念变化并不完整，它同样是若干技术条件同时成熟的结果。**Ajax** 让页面可以只更新局部而不必整页刷新，使网页具备接近桌面软件的交互手感；**宽带普及**让图片与视频的实际传输变得可行；**存储成本下降**使平台可以长期保存用户上传的内容；**搜索引擎的成熟**让海量新增内容不至于沉入无人可寻的角落。没有这些条件，所谓「参与」只会停留在少数人写博客的阶段。

## 平台逻辑的诞生

Web 2.0 真正的分水岭不是某类内容形态，而是**平台逻辑**的形成：网站不再只是一个发布页，而是一个能让第三方创造价值、并由平台分配收益的场所。开放接口与嵌入式组件让外部开发者把功能接入平台，平台则通过规则、排序与分成掌握分配权。这种结构在移动时代被应用商店继承并强化，成为数字经济的组织原型。

## 移动时代的分工与拉锯

移动时代的核心问题是「谁来承载用户」。原生应用在性能、传感器访问与推送通知上有优势，于是社交、短视频、支付与游戏等高频率、强交互的场景迅速被应用接管；而链接可达、免安装、跨平台的长尾信息与轻量服务，则继续由 Web 承载。微信小程序与渐进式 Web 应用可视为两种范式的混合尝试：前者借用应用的生态规则，后者把应用的能力塞回浏览器。

分野的后果是有得有失。用户获得了更顺滑的体验，但应用之间的链接不再通畅，内容的可搜索性下降，「Web 上的一个链接」在很多场景里被「打开某个应用」取代。开放 Web 的可组合与可引用优势因此被部分侵蚀，这也让关于平台权力的讨论变得更为紧迫。

## 名词的边界

需要澄清的是，Web 2.0 并不是一套技术标准，而是对使用模式与商业模式的代际标签；它的具体实现随时间不断更换，唯一稳定的是「用户产生内容、网络效应放大价值」这一机制。近年被借用为「下一代互联网」的 Web3 一词来自区块链社群，主张以链上身份与代币激励重构平台，与本词条描述的演进线并非同一脉络——相似的名词未必指同一件事。
