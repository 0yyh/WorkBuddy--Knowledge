在特征几何的标准模型中，最顶端是「根节点」（或称 root ，有时标注为「韵律节点」），它统领整个音段的区别性内容。根节点之下首先分出「主干节点」（ supralaryngeal / cv 节点 ），统辖所有在声道上层（喉部以上）实现的特征，包括发音部位与发音方式；喉部相关的清浊、送气等则常归到独立的「喉部节点」。这种划分对应着语音产生的生理模块：喉部负责声源，声道上部负责滤波塑形，二者在表征上各有归宿，互不混淆。

## 发音部位节点

部位节点（ place node ）下辖双唇、齿龈、硬腭、软腭、咽、声门等具体部位特征。许多语言存在「部位同化」，即一串辅音共享同一部位，几何观用「部位节点整体复制」统一解释，比逐特征列举更经济。部位之下还可再分「唇化」「舌体前伸」等更细特征，形成多级子树，使「部分同化」（只迁移部位的某一维）也能在结构上自然表达，从而精细刻画那些看似局部却系统性的音变。

## 喉部节点

喉部节点（ laryngeal node ）统辖清浊（ voicing ）、送气（ aspiration ）、紧松（ constricted glottis / spread glottis ）等由声门状态决定的特征。这类特征在亚洲、美洲许多语言中构成重要对立，例如印地语的浊送气系列、亚美尼亚语清送气系列。由于喉部节点独立，喉特征可与部位特征脱钩参与规则，解释「只变清浊不变部位」或「送气在词首脱落」等不对称音变，显示了层级表征对例外现象的解释弹性。

## 方式节点与依存关系

方式节点（ manner node ）下辖延续、鼻音性、阻塞等特征，决定气流受阻的方式。几何模型还强调节点之间的依存：例如鼻音性 presuppose 某个部位节点（鼻音必须有一个发音部位），喉特征通常依赖主干存在。这些依存约束使非法表征（如没有部位的鼻音）在生成时就被排除。总之，根—主干—部位/喉/方式的分层，把音段组织成有内在逻辑的结构，既反映生理模块，又约束音系规则的可及范围，成为现代音系表征的通用骨架。

## 部位节点的内部细分

部位节点并非铁板一块，其内部还可细分为更低的子节点。例如双唇、齿龈、硬腭、软腭等具体部位，可能先归并为更大的唇、舌冠、舌背等上位类，再向下展开。这种多级结构使部分同化得以自然表达：当一处同化只迁移舌背特征而保留舌冠特征时，树上的局部复制就能精确刻画，而无需牵动整个部位节点。内部细分也帮助解释为何某些部位对立比另一些更稳固，因为位于更上层的特征在规则中更易被整体捕获，位于更末梢的特征则更容易单独漂移。

## 喉部特征的类型学表现

喉部节点所统辖的清浊、送气、紧松等特征，在不同语言中的表现极不均衡。许多语言只用清浊构成对立，部分语言额外拥有送气对立，少数语言发展出紧喉与松喉的系统性对比。这种分布差异提示，喉部特征虽普遍可用，但被具体语言激活的程度各不相同。特征几何把喉部独立设节点，正好解释了为何喉特征常与部位特征脱钩参与音变：送气可以在词首整体脱落而丝毫不扰及部位，清浊也可以在完全不触及发音部位的前提下发生翻转。

## 方式节点与音变制约

方式节点决定气流受阻的方式，下辖延续、鼻音性、阻塞等特征。它与部位、喉部节点协同，限定了一个音段能否以及如何参与特定音变。例如在诸多语言中，鼻音性 presuppose 一个明确的发音部位，因此无部位的鼻音在表征层面即被禁止；又如阻塞类音更易在词尾清化，而响音则相对稳定，这种不对称可被追溯到方式节点所决定的结构位置。节点之间的依存关系，实际上把大量看似零散的音系限制，压缩为少数几条结构性原则。

## 特征组织在语言接触中的作用

特征几何不仅在单一语言内部解释音变，也在语言接触与借词研究中发挥作用。当一种语言的词汇被借入另一种语言时，借词的音系适应往往以特征为单位发生：借入语通常会保留来源词的区别特征组合，但若某些特征在借入语中不构成对立，便可能被系统性地替换或抹除。例如某语言缺乏浊送气对立时，借词中的浊送气特征常被调整为最相近的已有特征组合，这种适应过程在几何模型中表现为喉部节点的局部改写。此外，接触引发的音系迁移也常呈现成组面貌：一种语言的唇化特征可能整体扩散到邻近语言的某一类辅音上，而非零散地影响个别音段。用节点层级刻画这类现象，能够清晰区分整类迁移与个别替换，为接触语言学提供形式化的分析工具，也展示了特征理论超越单个语言、进入社会语言维度的解释潜力。

因此，节点层级的设定并非任意的美术选择，而是对语音生理与音系行为双重事实的理论回应，其合理性终须由跨语言证据来裁决。
