# 音系特征

**音系特征**（Phonological Features）指语言用来区分语音的最小区别性属性，是音系学刻画音段对立的基本单元。它主张：任何一个音段都不应被当作不可再分的原子，而应由一组可赋值（如二元对立或有无）的特征组合而成，例如「是否浊音」「是否鼻音」「舌位高低」等。与早期把音素当作清单式单位的做法不同，特征理论用数量很少的普遍特征去生成全部音段，并能自然表达同化与异化等音系规则。它起源于雅柯布森（Jakobson）的区别特征说，经乔姆斯基（Chomsky）与哈勒（Halle）在《英语音式》中发展为形式音系学的核心工具，又在自主音段音系学与特征几何框架中进一步获得层级化的结构。

本词条按「概念起源：从音素到区别特征 → 区别特征矩阵与生成音系学 → 特征几何的提出 → 特征的组织：根、部位、喉部、方式节点 → 特征理论的应用、修订与争议」五章展开。

## 导读

- 音系特征把音段还原为可组合的最小区别属性，取代清单式的音素观。
- 雅柯布森的区别特征说受信息论启发，主张普遍可用的二元特征维度。
- 乔姆斯基与哈勒用特征矩阵与重写规则，使音系规则以特征为单位运作。
- 特征几何以层级树取代扁平矩阵，把「自然类」编码进表征结构。
- 当代争论聚焦于二元与私性特征、特征的先天性与类型学浮现。
