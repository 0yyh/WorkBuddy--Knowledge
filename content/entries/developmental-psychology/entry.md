# 发展心理学

**发展心理学**（developmental psychology）研究人类心理与行为从受孕到死亡的系统性变化，既描述变化的时序与形态，也追问变化的机制——变化究竟源于成熟、经验，还是二者持续的交易。它以婴儿的抓握反射为起点，同样关心青少年的冒险、中年人的自我重构与老人的记忆衰退。这门学科的基本信念是：要理解任何一个年龄阶段的心智，都必须理解它从哪里来、正往哪里去。

本词条按「学科对象与历史：从儿童传记到毕生发展 → 皮亚杰的阶段理论 → 维果茨基与最近发展区 → 依恋理论：从鲍尔比到安斯沃斯 → 毕生发展与当代议题」五章展开。

## 导读

- 发展研究围绕四大经典争论展开：天性与教养、连续性与阶段性、早期经验是否决定终生、儿童是主动建构者还是被动接受者——几乎所有理论都能在这些问题坐标上定位。
- **皮亚杰**认为儿童是「小小科学家」，通过同化与顺应不断重构图式，认知发展经过感知运动、前运算、具体运算、形式运算四个质上不同的阶段。
- **维果茨基**反对把发展看成个体内部的独角戏：高级心理机能起源于社会互动，最近发展区把「能独立做」与「在帮助下能做」之间的距离变成教学的罗盘。
- **依恋理论**主张婴儿与照料者的情感联结有进化根基，早期形成的内部工作模型会迁移到日后的人际关系——但后续研究修正了「早期决定论」。
- **毕生发展观**把发展扩展到全生命周期：老化不是单向衰退，而是获得与丧失并存的过程，可以通过选择、优化与补偿主动管理。

> 📝 编者注：本词条与站内「记忆」「注意」「情绪」构成基础与发展的关系——后者提供认知功能的横断面刻画，发展心理学则为其加上时间轴。皮亚杰与维果茨基之争，也可视为「心理学」内部个体建构论与社会文化论之争的缩影。
