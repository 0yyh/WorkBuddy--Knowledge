# 阿拉伯文学

**阿拉伯文学是以阿拉伯语为载体的世界性文学传统，其历史横跨中世纪与近现代两个大阶段。它的起点是一批以口传形式流传的部族诗歌，这些诗歌在半岛上被吟诵、竞赛与传写，最终以「贾希利叶」之名成为后世效法的古典典范；它的第一个伟大综合物是《古兰经》，它把诗性的语言能量提升为宗教与典籍文体；它的古典高峰出现在阿拔斯王朝的巴格达，其标志是翻译运动所支撑的学术繁荣与《一千零一夜》的故事汇纂。它的近代形态则是在西方压力下的一次文体转型，纪伯伦、塔哈·侯赛因、努瓦尔·莎达维各自代表了不同路径。** 本词条按「分期 → 贾希利叶诗歌 → 古典散文形态 → 黄金时代 → 现代复兴」五章展开。

## 导读

- 阿拉伯文学的核心遗产是一套高度发达的韵律学，即对格律与音韵规则的精密规定。
- 贾希利叶诗歌以悬殊、演说与矜夸为基本主题，确立了阿拉伯诗歌的基本母题。
- 阿拔斯王朝的翻译运动把希腊、波斯与印度典籍带入阿拉伯语，催生了知识与文学的繁盛。
- 《一千零一夜》在长期口传与民间增补中成型，不存在唯一的作者。
- 二十世纪的阿拉伯小说与散文在纪伯伦、塔哈·侯赛因等人手中重新确立现代形式。
