# 托马斯·霍布斯

**托马斯·霍布斯**（Thomas Hobbes，1588—1679）是英国哲学家，近代政治哲学中**绝对主权**学说最彻底的代表。他的核心命题是：人在自然状态下彼此平等，而平等恰恰意味着谁也压不倒谁，于是彼此恐惧、互相防备，结果就是「**所有人对所有人的战争**」。为避免这种「孤独、贫乏、险恶、残忍而短促」的生存，理性提出了唯一的出路——人们相互立约，把全部权利交给一个**利维坦**式的绝对主权者。霍布斯的革命性不在于他拥护专制，而在于他把政治权威的根据从上帝、传统或自然等级，挪到了「**每个人都害怕暴死**」这件最平等、最普遍的事实上。这一步使国家第一次可以用人的欲望而非神意来解释。

本词条按「生平与时代：内战、保王派与欧陆之行 → 唯物主义与人性论：自然状态即是战争 → 社会契约与绝对主权：利维坦的诞生 → 对教会与共和的批判：主权囊括宗教 → 后世批评：从反抗权到施密特」五章展开。

## 导读

- **自然状态是战争状态的论证起点**：人人能力相近，相近即互相猜忌；为保证安全而先下手，使和平永不可得。
- 主权者**不在契约之内**：契约只在臣民之间订立，主权者未参与，故臣民对其无「违约」可言，也就无从正义地反抗。
- 霍布斯的唯物主义是彻底的一元论：连思想、意志也都是物质的运动，没有不朽灵魂，也没有天赋的道德观念。
- **主权囊括宗教裁判权**：他让世俗主权者兼任信仰的解释者，直接砍断了罗马教会与长老会的独立权威。
- 他的结论被自由主义视为毒药，却被后来的决断论者（如施密特）奉为现代国家理论的原型。
- 指路：他与**洛克**共享「社会契约」的框架，却一个通向绝对主权、一个通向反抗权，这一对照构成近代政治思想的基本张力。

> 📝 编者注：本条为人物词条，聚焦霍布斯本人的论证结构与其文本（《利维坦》为主，兼及《论公民》《法之要素》）。其「自然状态」常被误读为对史前人类的经验描述，实则是一项**思想实验**：用来显明没有共同权威时，理性会推导出什么结果。与之对读可参 `social-contract`（社会契约）、`sovereignty`（主权）、`john-locke`（洛克）与 `liberalism`（自由主义）。
