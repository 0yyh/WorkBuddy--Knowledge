# 薄伽梵歌

**薄伽梵歌**（भगवद्गीता / Bhagavad Gītā）是印度教最负盛名的圣典之一，字面意为「尊神之歌」。它并非独立成书，而是嵌入大史诗《摩诃婆罗多》第六篇「毗湿摩篇」中的七百颂对话，通常被视为整部史诗的哲理核心。其戏剧情境极简而深刻：两大王族即将在俱卢之野决战，战士阿朱那望见对方阵中尽是师长亲族，不忍下手，放下弓矢；其御者黑天——即毗湿奴的化身——随之展开长篇教示。这首歌由此把一场具体战争，升华为「人如何在责任与慈悲、行动与超脱之间安身」的普遍拷问，是印度思想中连接哲学、伦理与虔信的枢纽文本。

本词条按「薄伽梵歌的文本背景与结构 → 行动的瑜伽：业瑜伽与无执 → 智慧瑜伽与虔信瑜伽 → 薄伽梵歌的核心哲学：自性与梵 → 薄伽梵歌的诠释史与当代影响」五章展开。

## 导读

- 歌以阿朱那的道德困境开场，借黑天之口回应「该不该履行杀戮之战的责任」。
- 业瑜伽主张以无执态度行动，超脱果报而不弃职责，调和行动与解脱。
- 智慧瑜伽与虔信瑜伽提供另两条路，最终以奉爱为最高归宿。
- 歌把不二论的梵与有属性的神（黑天）结合，影响后世虔信运动。
- 甘地以「行动而不恋果」解读为不合作运动的伦理资源。

> 📝 编者注：薄伽梵歌在《摩诃婆罗多》中的位置显示，印度教常把高度哲理嵌入叙事史诗，而非写成系统论文；读歌宜先入其戏剧情境。
