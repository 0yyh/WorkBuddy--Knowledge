# 化学元素

**化学元素**（Chemical Element）是构成一切物质的基本成分之一，其定义为「原子核内质子数目相同的一类原子的总称」，这一数目即原子序数。与化合物不同，元素在化学反应中不会被拆解为更简单的物质，因而是化学分析的不可再分质点。元素的概念使人类得以用有限种类的砖石解释无穷多样的物质：金与氧是元素，水与盐则是元素的组合。理解元素，也就理解了物质何以千变万化却又可被还原为有限种类。

本词条按「元素概念史 → 原子序数与原子结构 → 周期律与周期表 → 元素合成（恒星核合成） → 元素与生命及工业」五章展开。

## 导读

- **元素的定义**：以原子序数（质子数）为唯一判据，同种元素原子质子数相同而中子数可以不同。
- **历史脉络**：从古希腊四元素说到拉瓦锡确立质量守恒与现代元素清单，元素观经历了根本质变。
- **周期律**：门捷列夫依原子量排列发现性质周期重现，后由原子序数给出更深层解释。
- **宇宙起源**：轻元素生于大爆炸，重元素由恒星核合成与超新星爆发锻造而成。
- **现实意义的双重性**：元素既是生命分子的骨架，也是冶金、能源与材料工业的基础。

> 📝 编者注：元素的「不可再分」仅在化学意义成立；在核物理层面，元素可通过聚变或裂变相互转化。
