# 佛教宇宙观

**佛教宇宙观**（Buddhist Cosmology）指佛教关于世界结构、时间尺度与众生处境的整体宇宙论图式。**其基本框架是「三界六道」：欲界、色界、无色界各有其特征，其中众生依业报流转于地狱、畜生、乾闼婆、阿修罗、人间与天六道之中，构成长劫相续的轮回。** 世界的空间结构以须弥山为中心，四大洲环绕，日月运行；时间则以成住坏空四劫与无量劫相续为尺度。阿毗昙传统对这一图式作了系统的概念化，而大乘佛教的宇宙观则把它扩展为十方三世与无量世界。宇宙观在佛教中不仅是对客观世界的描述，更是解脱实践的框架。本词条按三界框架 → 须弥山与六道 → 轮回与业报 → 劫的时间观 → 现代诠释与比较五章展开。

本词条按「三界的基本框架 → 须弥山、世界结构与六道 → 轮回与业报的机制 → 劫与时间：成住坏空 → 现代诠释与跨传统比较」五章展开。

## 导读

- 三界不只是地理分区，而是对应不同的欲见与修证层次，因此宇宙观同时是一张修行地图。
- 须弥山世界是印度宇宙观的移植，其结构在中晚期佛教中逐渐被「十方世界」的表述取代。
- 轮回的机制在阿毗昙中以「界」的分析来处理，其核心是烦恼与业的关系。
- 成住坏空四劫与无量劫的时间尺度，把生命放在宇宙尺度中重新定位。
- 佛教宇宙观不是「前科学」，它有独立的宗教与解脱意涵，现代比较研究须避免化约。
