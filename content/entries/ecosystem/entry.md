# 生态系统

**生态系统**（Ecosystem）是生物学与地球系统科学交汇处最核心的概念之一。它指在特定空间范围内，全部生物（植物、动物、微生物）与光照、温度、水、土壤、大气等非生物环境，通过取食、分解、物质交换等过程结成的功能整体。英国生态学家**阿瑟·坦斯利**于一九三五年正式提出这一概念，意在纠正当时把「生物群落」与「环境」分开研究的割裂倾向。今天，从一滴池塘水到整片热带雨林、乃至整个生物圈，都可被视为生态系统。理解它，等于理解生命赖以存续的能量与物质之网，也理解人类活动为何会动摇这张网的根基。

本词条按「概念史（坦斯利） → 能量流动与营养级 → 物质循环 → 群落与稳定性 → 人类扰动与恢复」五章展开。

## 导读

- **整体观**：生态系统把生物与环境视为不可分割的功能单元，而非可独立研究的零件。
- **能量单向流**：太阳能经生产者固定，沿营养级传递并逐级损耗，决定了系统的生产力上限。
- **物质循环**：碳、氮、水等在生物与非生物间往复，循环而非耗散。
- **稳定性有界**：多样性与冗余提升抵抗力，但系统存在可崩溃的阈值。
- **人类既是扰动者也是修复者**：栖息地破坏与污染削弱系统，保护与恢复工程则可挽回部分功能。

> 📝 编者注：生态系统不是有清晰边界的「物体」，而是研究者为方便划定的功能单元。一片森林与邻侧草原有连续过渡，边界常是人为约定。这不妨碍它作为分析工具的有效性，但提醒我们避免把边界绝对化。
