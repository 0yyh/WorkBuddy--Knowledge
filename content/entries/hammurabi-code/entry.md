# 汉谟拉比法典

**汉谟拉比法典**是约公元前十八世纪古巴比伦国王汉谟拉比颁布的一部楔形文字成文法，以黑色玄武岩柱铭刻、于一九〇一年出土于伊朗，今藏巴黎卢浮宫。它是现存最完整、最早的古代 Near Eastern 法典之一，正文二百八十二条，涉及司法审判、土地租佃、商贸、婚姻家庭、人身伤害与奴隶。法典以神授王权为正当性，以「同态复仇」（以眼还眼、以牙还牙）与按身份等级差别量刑为特征。它不仅是研究美索不达米亚社会的钥匙，也作为早期国家「以成文法确立秩序」的范本，被后世法律史反复援引。

本词条按「发现与历史背景 → 结构与形式 → 刑法原则 → 民法内容 → 历史地位与影响」五章展开。

## 导读

- 法典以神授王权宣示「使强不凌弱」的正义，是早期国家的秩序工程。
- 「同态复仇」原则只在同一等级内部适用，跨等级以赔偿替代。
- 法典按自由民与奴隶的身份严格差别量刑，等级色彩浓厚。
- 作为最早完整成文法之一，它是理解早期法律文明的标本。
