# 保守主义

**保守主义**（Conservatism）是对以抽象理性全面重构社会的政治方案的系统性怀疑。它主张制度、习俗与成见（prejudice，在柏克那里是中性词，指未经推理而传承的实践智慧）是时间检验过的知识存量，任何变革都应尊重这一存量、循序渐进，而不是按照设计图推倒重来。它解决的核心问题是：一个既需要变革又不能被理念驱赶着狂奔的社会，如何安排变革的速度与方向。

本词条按「柏克《法国革命论》 → 核心命题：有限理性与自发秩序 → 与自由主义/社会主义的谱系关系 → 20世纪的变奏 → 批评与回应」五章展开。

## 导读

- 柏克是保守主义的奠基人，但他的立场常常 surprising：他支持美国革命、反对英国在印度的暴政，他反对的是以「自然权利」的名义从零重建社会。
- 保守主义的核心论证不是「旧的就是好的」，而是「社会知识是累积的、分散的、无法被任何单一头脑完全掌握的」——这是它与一切计划主义分歧的根。
- 哈耶克以经济学重述了这一论证：价格机制作为分散知识的协调装置，任何试图以理性设计取代它的方案必然失败或通向奴役。
- 保守主义是不是意识形态，本身就有争议：亨廷顿说它有体系性的定义（捍卫贵族秩序）与情境性定义（为任何受到威胁的既定秩序辩护）；奥克肖特则说它是一种「习性」而非学说。
- 20世纪保守主义的最大变奏是新保守主义与新右派的合流，自由至上主义（诺齐克式的最小国家）与保守主义的婚姻并不稳固。
- 「为既得利益辩护」是保守主义最持久的批评；第五章将给出柏克式的辩护及其无法消解的弱点。

> 📝 编者注：把「保守主义」读成「反对一切变革」是最大的误解。柏克的原话是「无法保守的国家是无法改革的」——保守与改革互为条件。区别在于变革由经验与制度引导，还是由理念与蓝图驱动。
