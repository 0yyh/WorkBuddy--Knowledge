# 可计算性

**可计算性理论**（computability theory，亦称递归论）研究计算这个概念本身的边界：给定一个数学问题，是否存在一套完全明确的机械步骤（算法）能对每个实例给出答案？直觉上「按固定规则一步步做」人人会用，但「可计算」要成为数学对象，必须先有精确定义。1936 年，图灵用一条纸带和一个读写头的最简装置给出定义；同年邱奇用 λ 演算给出等价定义。两个迥异模型恰好重合，支持了**邱奇-图灵论题**：可计算性即图灵可计算性。紧随其后的停机问题证明：不存在判定任意程序是否停机的程序——计算的边界被划出，希尔伯特判定问题随之得到否定回答。可计算性与哥德尔不完备定理共享同一个对角线结构：不可判定性与不可证明性是同一现象的两种表述。

本词条按「机械化数学之梦 → 图灵机 → 邱奇-图灵论题与通用机器 → 停机问题 → 不可判定性版图与不完备定理」五章展开。

## 导读

- 「可计算」需要定义：图灵的贡献不是造计算机，而是给「机械步骤」以数学定义。
- **图灵机**是一切真实计算机的抽象母型：一条带、一个头、有限状态、逐格操作。
- **邱奇-图灵论题**是论题而非定理：「直观可计算 = 图灵可计算」无法被证明，只能被证据支持。
- **通用图灵机**可以模拟任何图灵机——存储程序计算机的理论原型，早于真实硬件十年。
- **停机问题不可判定**：用对角线法证明不存在万能的停机判定器；几乎所有非平凡的性质都随之不可判定。
- 不可计算性与不完备定理同源：图灵的构造可以看作哥德尔自指句的机器版。

> 📝 编者注：本词条与「哥德尔不完备定理」构成 1930-31 / 1936 两幕的连续剧：哥德尔划定了证明的边界，图灵划定了计算的边界，两者在技术上互相翻译。与「计算机」词条的关系是理论与造物：图灵机是后者的数学原型，但图灵 1936 年的目的恰恰是**理论的**——为判定问题造一个精确的反例装置。与「集合论」的关系在对角线法：康托尔、哥德尔、图灵共用同一根杠杆。
