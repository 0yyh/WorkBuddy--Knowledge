# 诗学

**诗学**原本是亚里士多德一部讲稿的名字，今天泛指「研究诗（文学）的本质与创作规律」的理论。对零基础读者，可以把它想成古人最早认真追问的一件事：为什么人要看戏、听诗、读故事？这些虚构的东西不真，为什么还能让人又哭又笑、久久难忘？亚里士多德给出的核心答案叫「摹仿说」——人天生爱摹仿，诗（悲剧、史诗）摹仿的虽不是真实发生的事，却是「可能发生的事」，比历史更富哲理；而看悲剧时那种又痛又痛快的感觉，来自「卡塔西斯」，即恐惧与怜悯被疏泄后的清明。这部讲稿大半失传，却像一粒种子，长出西方两千年文论的主干。本词条沿用「定义与范畴 → 历史脉络 → 核心理论 → 流派与代表 → 争论与当代意义」五章，带你从这部古书读到一个仍在生长的学科。

本词条按「定义与范畴（什么是诗学）→ 历史脉络（从柏拉图到亚里士多德）→ 核心理论（摹仿说与悲剧六要素）→ 流派与代表（古典、浪漫、形式诗学）→ 争论边界与当代意义」五章展开。

## 导读

- 诗学不是「写诗的方法」，而是「追问文学为何成立、如何成立」的理论；亚里士多德《诗学》是它最古老的体系性文本。
- 摹仿说是基石：诗摹仿「行动中的人」，而且摹仿「应当或可能如此的事」，因此比记实的历史更具普遍哲理。
- 悲剧六要素里「情节」排第一：亚里士多德认为事件的组合（mythos）比性格、思想更决定一首诗的成败。
- 卡塔西斯解释悲剧快感：恐惧与怜悯在观剧中被唤起又获疏泄，使心灵回到平衡，这是诗学的第一批「接受理论」。
- 诗学传统并未终结于古希腊：浪漫派、形式派、结构主义叙事学都从它借题，今天的「虚构」「叙述者」讨论仍可回溯到它。

> 📝 编者注：本词条所说「诗」取古希腊广义，泛指一切用语言摹仿的文艺（史诗、悲剧、喜剧），并非仅指抒情诗。中文语境里「诗学」后来也指诗歌理论，二者同源而范围不同，读时请留意。
