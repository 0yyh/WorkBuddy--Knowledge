# 道藏

**道藏**是道教经典的集成总称，也是中国现存最大的一部宗教丛书。其形成并非一蹴而就：从早期单经并行、符图与斋仪书的零散流传，到唐宋的汇编尝试，再到明代《正统道藏》与清代《万历续藏》两大部相继定型，道藏经历了由地方与教派汇集走向国家敕修、由散佚文本走向系统丛书的路径。其分类以三洞（洞真、洞玄、洞神）为骨干，辅以四辅与本门附录，形成一套严整的目录体系。理解道藏，须同时把握其作为经典文本、编纂制度与传承载体的三重身份，并留意敦煌、吐鲁番等地出土文献对传统道藏观的挑战。

本词条按「经典的集成观念 → 三洞分类体系 → 《正统道藏》的敕修 → 《万历续藏》与近代影印 → 出土文献与版本源流」五章展开。

## 导读

- 「道藏」既是经典总称，也是一部具体丛书的书名，二者须分辨。
- 三洞分类以「洞」为骨干，源出道经的宇宙论分层，而非图书馆式的学科划分。
- 《正统道藏》五百三十七种，是明永乐至正统间敕修的国家级道藏总集。
- 《万历续藏》补收宋元以后新出文献，二书合为道藏完整主体。
- 敦煌、吐鲁番出土道经多为单叶写本，提供了传统丛书之外的另一面向。
