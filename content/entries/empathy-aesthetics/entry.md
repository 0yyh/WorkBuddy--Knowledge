# 移情说

**移情说**（Einfühlung）主张：审美愉悦的根源在于主体把自己的生命情感**移入**对象，然后在对象身上重新感受它——我们觉得石柱「向上腾起」，其实是把自己的奋发力投射了进去。这个概念由十九世纪德国心理学美学提出，**立普斯**（Theodor Lipps）把它系统化为「我在对象中感受到我自己」，**谷鲁斯**（Karl Groos）则以**内模仿**给出身体性的竞争解释。移情说在二十世纪初一度主导美学讨论，随后被形式主义与表现说夹击，又在当代以「共情」的名义部分回归。

本词条按「从费肖尔到立普斯：Einfühlung 的建立 → 谷鲁斯的内模仿与立普斯之争 → 技术架构：对象化、自我投射与审美愉悦 → 与表现说、形式主义的分歧 → 批评与当代：现象学的改造与共情研究的再评估」五章展开。

## 导读

- 移情说的德语原词 *Einfühlung* 字面即「感入」——它描述的不是同情他人，而是**把感受输入到非人的对象**中。
- 立普斯的核心命题看似荒谬：审美愉悦是「**在一个感性对象上对我自己的欣赏**」——我们喜欢的是对象化的自己。
- 谷鲁斯的分歧在于身体：他认为移情的机制是**内模仿**（肌肉的微弱收缩），而不是纯粹的精神投射。
- 移情说与表现说的根本分歧在**方向**：表现说是外化（内在 → 作品），移情说是内化（对象 → 我）。
- 形式主义的攻击最致命：如果审美愉悦来自投射，那么同一根石柱对不同人应有完全不同的美，而这与我们的经验不符。
- 本词条与「表现说」「形式主义美学」构成三角关系，其心理学基础则连着**心理学**与**情感**研究。

> 📝 编者注：「移情」这个中文译名容易与「同情」「共情」混淆。本词条严格区分三层：**移情**（Einfühlung，审美中把感受移入对象）、**同情**（sympathy，对他者处境的关怀）、**共情**（empathy，当代心理学与哲学中对他者内心状态的把握）。三者在历史上纠缠不清，但含义不同。
