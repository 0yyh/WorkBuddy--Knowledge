# 船舶

**船舶**（Ship）是凭借浮力漂浮于水面、借风力或机械动力航行的运输与作业平台。与飞机挣脱重力不同，船舶的难题是如何在「随波逐流」中保持稳性与航向，并尽可能多装、快跑、少耗。从独木舟、木帆货船到载箱上万的超级集装箱船与巨型油轮，船舶始终是人类跨越海洋最经济的方式：一艘大型货轮单次可运数万吨货物，单位重量的能耗远低于卡车与飞机。正是凭借这种成本优势，船舶承载了全球贸易约九成的货运量。它的演进史，也是材料（从木到钢到复合）、动力（从桨帆到蒸汽到柴油）与航海术（从星盘到卫星定位）的共同进步史。

本词条按「浮力原理与船体设计 → 从木帆到蒸汽轮船 → 现代商船与集装箱化 → 船舶动力与导航 → 造船工业与航运经济」五章展开。

## 导读

- 船舶以排水体积产生的浮力平衡自重，稳性设计决定了它会不会翻。
- 蒸汽轮船终结了风帆对航期的不可控，使海运走向准时化。
- 集装箱标准化是二十世纪物流最伟大的革新之一，它把装卸时间从天缩短到小时。
- 现代商船以低速柴油机为主动力，其热效率远超多数陆上内燃机。
- 造船是资本与产业链高度密集的产业，其格局随全球制造业迁移而变动。

> 📝 编者注：本词条聚焦民用商船；军用舰船（如航空母舰、驱逐舰）的技术脉络另成体系，仅在与民用交叉处提及。
