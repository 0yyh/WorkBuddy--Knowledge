C 原则是约束理论的收尾一条，规定指称表达式必须总是自由，即绝不被任何同指名词约束。指称表达式含专有名词（张三、北京）与普通名词短语（那个医生、每只猫），它们自带充足指称信息，独立自足，不依赖句中他词获得身份。因此 C 原则说：这类名词无论远近，都不该被同指名词约束——若句中出现两个同指的指称表达式，后者不被前者约束，二者各自独立指称（可能碰巧同指，但非约束关系）。例如 *John loves John 中两 John 同指却非约束（都独立），句怪在语义重复而非约束违规；而张三说李四骂了张三，远处张三与近张三可同指却不受 C 禁止，因 C 只禁约束不禁同指。C 原则补全了三类名词的覆盖：照应语必绑、代词必自由、指称表达式总自由。

## 指称表达式为何总自由

C 原则的理据在指称表达式的语义自足。专有名词天然指向唯一个体，普通名词短语靠限定词锁定指称，二者都不缺身份，故无需近亲绑定。若强行让指称表达式受约束，反而是冗余甚至矛盾——它本身已能指，何须再绑？这与 A 原则恰成两极：照应语因无身份而必绑，指称表达式因有身份而总自由，代词居中（有身份却可远绑）。三者构成连续统：身份缺失度越高，越需约束；身份越足，越拒约束。C 原则因此不只是补充条款，而是揭示名词身份与约束需求的反比关系。它也解释为何专有名词在句中位置灵活、可作多种成分而不必顾忌绑定——其自由是结构性的。理解 C 原则，便理解了指称表达式在约束体系中为何是规则例外中的恒定项：它永远自由，因它本就自足。

## 与 A、B 原则的体系关系

三条原则合观，构成对名词短语的完全分类覆盖。A 管照应语（必绑），B 管代词（域内自由），C 管指称表达式（总自由），三类互不重叠，穷尽名词类型。这种对称是约束理论的形式美感所在：用三条同向原则（约束强度递减）覆盖全部名词，无一漏网。也需注意三者强度递进：A 最严（必绑），B 次之（域内禁绑），C 最宽（总自由）。它们共同预测任何名词在句中的约束行为。若某语言出现违背，研究者先查是否分类错置（如把某词误归代词），再查局部域参数，而非轻易判原则失效。体系的完备性使约束理论成为可证伪的精密工具：每条原则都可单独测试，任一条的反例都构成对普遍语法的压力。C 原则作为收尾，确保体系无盲区，是理论自洽的关键一环。

## 岛效应与约束的边界

C 原则的总自由也牵出岛效应问题。某些结构（关系从句、复杂名词短语）构成岛，约束难以跨越。例如那个张三爱的人来了，内嵌张三虽是指称表达式，却因其处岛内，对外约束受限，这虽不违 C 原则（C 只禁约束），却显示约束跨越受结构阻隔。岛效应本属移位理论，却与约束交互：被岛围住的名词，其约束关系被切断，影响指代解读。约束理论须与岛条件协调，避免约束原则越过结构边界生效。这提示约束不是无界同指，而是受句法结构窗与岛双重限制。C 原则的总自由，是在这些结构限制之内的自由——它不要求跨岛绑定，只禁本地约束。理清岛与域，约束理论的适用边界才完整。它也表明约束理论与移位、结构模块深度耦合，非孤立三句可尽，须置于整座生成语法建筑中方见全貌。

## C 原则与指称的语用层

C 原则管句法自由，指称表达式的最终所指仍靠语用与百科知识。专有名词张三在句中自由，但其指哪个张三由语境定；普通名词那个医生自由，却靠指示与语境锁定。C 原则只保证它不被句内同指名词约束，不干预语用指派。这与 B 原则类似：句法关窗，语用开窗外。区别在 C 原则更彻底——它连域内同指绑定都不禁（因指称表达式本可同指并存），只禁约束关系本身。这种彻底自由使指称表达式成为句中最不受约束牵制的成分，也使其成为语篇指称的主要载体。理解 C 原则，须把它与语用指称分开：句法保证自由，语用填充所指。二者分工，使专有名词与限定短语既能灵活指称，又不卷入句内约束纠葛。C 原则以此收束约束体系，并为下一章讨论局部域精化与反例埋下伏笔——那将是三原则共同面对的精细战场。

## 指称表达式的重叠与同指

C 原则禁约束不禁同指，这引出指称表达式重叠的有趣现象。句内出现两个同指专名（张三说李四打了张三），后者不受 C 禁止，因 C 只禁约束关系而非同指并存。但这类句常显冗余别扭，其不自然来自语用（既已说张三，何必重复）而非句法违规。这说明 C 原则的边界：它保证指称表达式句法自由，冗余问题交语用处理。普通名词短语同理：那个医生说他来了，那个医生可指外指医生，域内无同指约束对象则自由成立。C 原则因此把句法层与语用层干净切开——句法只保自由，语用管经济与歧义。理解这一刀，许多看似反例的重复句便得正解：它们句法合法、语用欠佳，不应算作约束理论的反例。C 原则的克制由此显现价值：它不越界管语用，使理论职责清晰，也避免把语用冗余误读为句法违规，维护了体系的整洁与可检验性。

## C 原则与限定词的关系

C 原则还连着限定词系统。指称表达式之所以总自由，深层因它含限定词（定冠词、指示词、数词）锁定指称，无需依赖句中他词。无限定词的裸名词（如光杆医生）指称不定，约束行为可能近似代词或受另规管，提示 C 原则的适用以指称自足为前提。跨语言看，缺定冠词的语言其指称表达式识别靠语境与语序，但一旦可判定为限定短语，仍总自由。这把 C 原则与限定范畴挂钩：自由性源于指称确定性，确定性源于限定词。约束理论由此与名词短语内部语法衔接，显示三条原则的适用不只看词类，也看短语的语义完足度。对汉语，限定常靠量词与语境（那个医生）实现，完足的限定短语同样总自由。C 原则因此触及名词短语信息结构的根本：谁自足、谁依赖，决定它受哪条约束。这种纵深联系，使 C 原则不只是一句收尾，而是牵动整个名词短语语义接口的枢纽条款。
