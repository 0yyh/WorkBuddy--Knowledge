# 约束理论

**约束理论**（Binding Theory）是生成语法中处理名词短语指称依赖关系的一组普遍原则，由乔姆斯基（Chomsky）在「原则与参数」框架中系统提出。它先把名词短语分为照应语（如反身代词、相互代词）、代词（如他、他们）与指称表达式（如专有名词、普通名词）三类，再以 A、B、C 三条原则规定它们在局部管辖域内必须「被约束」或「自由」的资格条件。与「题元角色」刻画论元的事件身份不同，约束理论刻画的是名词短语之间的指称呼应；它与「普遍语法」同属先天原则系统，是检验儿童语言习得中参数设定最经典的案例之一，也是生成句法从纯结构走向指称接口的枢纽。

本词条按「约束理论的由来与名词分类 → A 原则（照应语约束） → B 原则（代词自由） → C 原则（指称表达式自由） → 局部域、反例与理论发展」五章展开。

## 导读

- 约束理论把名词短语分成照应语、代词、指称表达式三类，分别适用 A、B、C 三原则。
- A 原则要求照应语在其局部域内被约束（如反身代词须有本地先行词）。
- B 原则要求代词在其局部域内自由（如英语 him 不可指代同句本地主语）。
- C 原则要求指称表达式总是自由，不参与局部约束关系。
- 局部域（管辖语类）的界定与跨语言参数差异，是理论修正的重心。
