# 微处理器

**微处理器**（Microprocessor）是把计算机**中央处理器**的运算与控制的全部或核心功能，集成到单块集成电路上的器件。在它出现之前，一台处理器由成百上千个分立元件焊成，占满机柜；一九七一年英特尔四百零四把它首次装进一枚芯片，运算的载体从此从「机器」缩成「零件」。此后晶体管密度指数攀升，微处理器把算力压缩进指甲盖大小，直接催生了个人计算机、手机与物联网。理解数字时代，微处理器是那颗跳动的心脏。

本词条按「从分立元件到集成 → 英特尔四百零四的诞生 → 架构演进：从八位到多核 → 个人计算机革命 → 移动与万物互联时代」五章展开。

## 导读

- 微处理器的本质是把「处理器」从系统缩成「芯片」，使计算可批量制造、随处嵌入。
- 英特尔四百零四是公认的第一颗商用微处理器，虽原始却开创了范式。
- 位宽、时钟与指令集的演进，使同一芯片能做越来越复杂的事。
- 微处理器是个人计算机的前提：没有廉价算力，电脑走不进家庭。
- 移动时代把它从桌面带入口袋，系统级芯片融合多种功能。
- 它既是算力民主化的引擎，也带来性能、功耗与安全的新约束。

> 📝 编者注：常见误解是「微处理器就是电脑」。其实它只是电脑的核心运算件，尚需存储、输入输出与软件配合才成系统。把芯片等同于整机，会低估周边生态的分量，也高估单颗芯片的能耐。
