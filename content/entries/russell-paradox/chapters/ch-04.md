与罗素的分层思路不同，恩斯特·策梅洛选择了另一条路：**不去规定哪些对象可以构成集合，而是规定集合如何生成**。这条路最终成为现代数学的标准基础。

## 分离公理

策梅洛在 1908 年发表的《集合论基础研究之一》中，用一条公理替代了无限制的概括原则：

**分离公理**（Aussonderung，也称子集公理）：给定一个已有的集合 A 与一个性质 P，存在一个集合 B，其元素恰好是 A 中满足 P 的那些元素。

形式写法：∀A ∃B ∀x (x ∈ B ⟺ x ∈ A ∧ P(x))。

关键的差别只有一处：**必须先有一个集合 A**。你不能再凭空由一个性质造出一个集合，只能从已有的集合里切出一块。

这个小小的限制足以挡住罗素悖论。用分离公理，我们能得到的只是：

> R_A = { x ∈ A | x ∉ x }

即「在 A 中那些不属于自身的集合」。对 R_A 问「是否属于自身」，得到的结论是：**R_A 不属于 A**。因为若 R_A ∈ A 且 R_A ∈ R_A，则矛盾；若 R_A ∈ A 且 R_A ∉ R_A，则按定义 R_A ∈ R_A，也矛盾。两种情形都推出 R_A ∉ A。

于是悖论被转化为一条**定理**：对任意集合 A，总存在一个不属于 A 的集合（即从 A 中分离出来的 R_A）。这直接蕴含：**不存在所有集合的集合**——否则把 A 取为它，就得出一个属于它又不属它的集合。

这是一个漂亮的转化：**悖论不再是矛盾，而是关于「总体不能太大」的证明**。康托尔当年的直觉在此获得了严格形式。

## 策梅洛的公理系统

除了分离公理，策梅洛 1908 年的系统还包括：

- **外延公理**：两个集合若元素相同则相等。
- **基本集公理**：存在空集；存在单元素集与无序对。
- **幂集公理**：任意集合的幂集存在。
- **并集公理**：一族集合的并集存在。
- **无穷公理**：存在一个包含空集且对后继运算封闭的集合（保证自然数集存在）。
- **选择公理**：对任意由非空两两不交集合构成的族，存在一个集合与每个成员恰好交出一个元素。

注意这个系统的气质：它不是在描述「集合是什么」，而是在规定「哪些集合可以由已给的集合生成」。这是一种**生成性**而非**描述性**的基础观。

## 弗兰克尔与斯科勒姆的补强

策梅洛的系统有一个缺口：分离公理中的性质 P 没有被精确界定，而某些构造（如序列的递归定义）无法由它得到。

1922 年，亚伯拉罕·弗兰克尔与托拉尔夫·斯科勒姆各自独立提出了修正：

- **替换公理**（replacement）：若一个函数（可定义的映射）作用于一个集合，则其像也是集合。这保证了像 {ω, ω+1, ω+2, …} 这样的超限序列可以被构造。
- 用**一阶公式**精确界定分离与替换中的「性质」，消除了策梅洛系统中的含混。

由此得到的系统被称为 **ZF**（策梅洛—弗兰克尔集合论）；若加入选择公理，则称为 **ZFC**。这就是今天数学的标准基础。

## 正则公理：禁止自我属于

ZF 的原始公理中，并未明令禁止 x ∈ x。这一点由约翰·冯·诺伊曼在 1925 年提出、后经策梅洛在 1930 年采纳的**正则公理**（也称基础公理，axiom of foundation）完成：

> 每个非空集合 A 都含有一个元素 B，使得 A 与 B 没有公共元素。

形式写法：∀A (A ≠ ∅ → ∃B ∈ A (A ∩ B = ∅))。

这条公理的直觉含义是：**属于关系没有无穷降链**，也不存在循环。推论包括：

- 不存在 x ∈ x（取 A = {x}，则 x 必须与 {x} 无公共元素，但 x ∈ x 且 x ∈ {x}，矛盾）。
- 不存在 x ∈ y ∈ x 这样的循环。
- 整个集合论宇宙可以分层为**累积层级**（cumulative hierarchy）：V₀ = ∅，V_{α+1} = V_α 的幂集，极限序数处取并集；所有集合都出现在某一层。

最后一条尤其重要：它给了集合论一个清晰的「宇宙图景」——集合是按秩（rank）一层层累积起来的，每一层的元素都来自更低的层。

## 正则公理是不是必要的？

一个常被问到的问题是：既然分离公理已经挡住了罗素悖论，为什么还要正则公理？

答案：**正则公理不是为了解决罗素悖论，而是为了使集合论更整洁**。它排除了一些虽然一致但行为怪异的集合（如满足 x = {x} 的对象），使累积层级的构造成为可能，也使归纳法可以在整个宇宙上施行。

事实上，现代集合论中有一整个分支研究**非良基集合论**（non-well-founded set theory），它明确地放弃正则公理，允许循环属于关系。彼得·阿克泽尔在 1988 年的《非良基集合论》中给出了这样的系统，并证明它们是一致的（相对于 ZF）。这些系统在计算机科学中处理循环数据结构、在哲学中处理自指语义时有实际用途。

这说明：**禁止自我属于是一种选择，不是逻辑的必然**。

## ZFC 解决了悖论吗

严格地说，ZFC 并没有「解决」罗素悖论，而是**把它的结论变成了定理，并放弃了产生它的前提**。

- 无限制概括原则被放弃（改为分离与替换）。
- 「所有不属于自身的集合」这一总体被证明不是集合，而是一个**真类**（proper class）。

这里出现了「类」的概念：在冯·诺伊曼—博内斯—哥德尔（NBG）集合论中，「类」是被正式引入的对象，所有集合都是类，但有些类（如所有集合的类）不是集合，不能作为其他类的元素。这样，「所有不属于自身的集合」可以作为一个真类被谈论，只是不能当作元素参与构造。悖论由此被驯服。

## 但一致性并未被证明

最后一个必须说清的事实：**ZFC 的一致性至今没有被证明**。

这不是因为没人试过。恰恰相反，这正是希尔伯特在 1900 年提出的第二个问题的核心，也是希尔伯特纲领的中心目标。1931 年，哥德尔的第二不完备定理表明：**任何包含算术的一致的形式系统，都不能在自身内部证明自己的一致性**。

因此，若 ZFC 是一致的，那么它的一致性不能在 ZFC 内部证明（除非借助更强的系统，而更强系统的一致性又需要更强的系统……）。这并不意味着我们怀疑 ZFC 不一致——八十多年的广泛使用没有发现矛盾——而是说，**一致性是一个我们只能相信而无法在系统内证实的性质**。

这就是罗素悖论留下的最深印记：它逼迫数学重建基础，而重建后的基础，其可靠性本身成了一个无法在内部回答的问题。

> 📜 「从一个已给定的集合中，可以把满足某性质的元素分离出来，构成一个新集合。」 —— 策梅洛分离公理（转述其旨）

> 📝 编者注：教科书常说「罗素悖论被 ZFC 解决了」。更准确的说法是：悖论被**规避**了——我们换了一套使悖论无法被表述的公理，并把它的结论（不存在大全集）收编为定理。这与「治愈」不同：我们至今不知道 ZFC 本身是否一致。区分「问题被解决」与「问题的前提被放弃」，是理解二十世纪数学基础史的关键。

除了类型论与 ZFC，还有其他思路，也有更多的悖论等待处理。
