罗素在 1901 年（他自己回忆是在那年五月或六月）思考康托尔的对角线论证时，得到了一个极其简短的结果。它只需要两个概念：集合与属于。

## 构造

定义一个集合 R 为：

> R = { x | x 不属于 x }

用白话说：R 是所有**不属于自身**的集合所组成的集合。

现在问：R 是否属于 R？

**情形一**：假设 R ∈ R。那么 R 满足 R 的成员条件，即 R 不属于 R。矛盾。

**情形二**：假设 R ∉ R。那么 R 满足 R 的成员条件，所以 R 应当被收进 R，即 R ∈ R。矛盾。

两种情形都推出反面。用形式写法只需一行：

> R ∈ R ⟺ R ∉ R

这是一个直言的矛盾式，与说谎者悖论的「本句为真当且仅当本句为假」同构。

## 为什么它难以回避

罗素悖论之所以造成危机，而不是被当作一个可以修补的边角问题，有四个理由。

**理由一：它只用了最基础的概念。** 悖论的构造里没有「无穷」，没有「最大基数」，没有「语言」「真」「定义」这类语义概念。只有集合、属于、否定、以及概括原则。因此任何以集合为基础的数学理论，都必须面对它。

**理由二：它不依赖任何编码技巧。** 后来的哥德尔不完备定理需要把语法编码为算术（哥德尔数），塔斯基的真不可定义定理需要语言的分层。罗素悖论什么都不需要——它直接从一个显然合法的定义中跳出。

**理由三：它支持「希尔伯特旅馆」式的直觉反驳不成立。** 有人会说：也许 R 根本不存在，因为「所有不属于自身的集合」这个总体太大了。但这恰恰就是问题：**概括原则说它存在**。要否认 R 的存在，就必须修改或放弃概括原则——而这已经是基础性的改动。

**理由四：它落在逻辑主义的要害上。** 弗雷格的第五定律保证了任何概念都有外延。「x 不属于 x」是一个合法的概念（弗雷格的系统里「不属于」完全可以表达），因此它必须有外延，而这个外延正是 R。所以悖论对弗雷格不是「一个麻烦」，而是**逻辑上的自相矛盾**。

## 日常类比：理发师悖论

罗素本人在 1918 年《数理哲学导论》中给出了一个通俗版本：某村有一位理发师，他给且只给**所有不给自己刮胡子的人**刮胡子。问：这位理发师给不给自己刮胡子？

若他给自己刮，则他属于「给自己刮胡子的人」，按规则他不该给自己刮；若他不给自己刮，则他属于「不给自己刮胡子的人」，按规则他必须给自己刮。

这个版本对于普及悖论极有帮助，但作为理解工具它有严重缺陷：**理发师悖论其实不是悖论，只是不一致**。

理由是：我们可以一致地判定「这样的理发师不存在」。村里没有这样一位理发师，问题就解决了。这是一个关于经验事实的否定，没有任何逻辑困难。

而罗素悖论不同：**我们不能说「这样的集合不存在」而不付出代价**——因为在朴素集合论（以及弗雷格的系统）里，它的存在是由公理/基本定律保证的。要说它不存在，就必须重写基础。

这个类比的误导性值得反复强调，因为大量通俗读物正是靠理发师版本来介绍罗素悖论，结果读者以为问题只是「有人吹牛」。这是把逻辑矛盾降格成了日常笑话。

## 罗素的诊断：恶性循环原则

罗素自己对这个悖论的诊断，写进了他与怀特海合著的《数学原理》（1910—1913）。他的核心概念是**恶性循环原则**（vicious circle principle）：

> 凡涉及一个总体的全部者，本身不能是该总体的一员。

换句话说：**不能用「所有 X 的集合」来定义一个本身可能是 X 的东西**。在 R 的定义中，我们用到了「所有集合」这一总体（成员条件对所有集合判定），而 R 本身又被当作集合，可能成为这个总体的成员。这就是恶性循环。

罗素进一步区分了两种违法：

- **直接自指**：一个集合把自己作为元素。（R ∈ R 这种形式）
- **间接循环**：一串集合互相属于，或定义中的量词范围包含了被定义者。

这个诊断后来被概括为**类型论**——禁止混合不同「层次」的对象。但在《数学原理》之前，罗素先做了另一件更紧急的事：给弗雷格写信。

## 与其他悖论的比较

罗素悖论属于一族，把它与邻居们摆在一起，能看清它的位置：

- **康托尔悖论**（1899）：所有集合的集合的幂集应比它大，但它包含一切。涉及基数与幂集。
- **布拉里-福尔蒂悖论**（1897）：所有序数的集合本身有一个序数，该序数大于其中所有序数。涉及序数与良序。
- **罗素悖论**（1901）：只涉及属于与否。最简，也最根本。

三个悖论中，罗素悖论最简洁，因此也最致命：另两个可以用「这些总体太大」来回避，罗素悖论的 R 看起来一点也不大——它就是「那些不属于自己的集合」，凭什么不能收集起来？

罗素本人在《我的哲学的发展》中回忆，他最初是从康托尔悖论入手的：他想检查康托尔「不存在最大基数」的证明是否成立，结果在检验过程中发现了一个更简单的矛盾。

## 一个技术补充：为什么「x ∉ x」是合法的性质

有人会追问：凭什么可以写「x 不属于 x」？凭什么集合可以作为自身的元素？

在朴素集合论里，这没有限制。集合被直觉地理解为「一堆东西」，而 x ∈ x 只是问「这堆东西里有没有它自己」。多数普通集合显然不属于自身（自然数的集合不是自然数），但「所有集合的集合」属于自身，「所有抽象概念的集合」是抽象概念因而属于自身。

因此「x ∉ x」是一个**完全合法、且对绝大多数集合为真**的性质。悖论的力量恰恰在此：**它用的不是一个生僻的性质，而是一个几乎普遍成立的性质**。

> 📜 「一个集合属于自身当且仅当它不属于自身。」 —— 罗素悖论的形式核心

> 📝 编者注：许多人以为罗素悖论的关键教训是「集合不能包含自己」。这个理解只抓住了一半。ZF 集合论确实通过正则公理禁止了 x ∈ x，但这只是附带结果；真正解决问题的是**把概括改为分离**——集合必须从已有集合中分出，不能凭空由性质生成。禁止自我属于是症状，限制生成是病因。

悖论的冲击有多大，看弗雷格收到信时的反应就知道。
