# 查尔斯·达尔文

**查尔斯·达尔文**（Charles Darwin，1809—1882）是英国博物学家、进化论的奠基人。他随"**贝格尔号**"环球考察五年，积累了海量生物与地质观察，于 1859 年出版《**物种起源**》，提出以**自然选择**为核心的进化理论。他用"**共同祖先 + 自然选择**"解释了生物多样性与适应性的由来，从根本上改变了人类对生命与自身位置的理解。

本词条按「生平与贝格尔号 → 自然选择 → 《物种起源》 → 证据与争论 → 影响与遗产」五章展开。

## 导读

- 达尔文的核心机制是**自然选择**：变异 + 繁殖过剩 + 生存竞争 → 适者存活、逐代演化。
- 1859 年《物种起源》以**大量证据**论证共同祖先，而非倚仗思辨。
- 进化论与遗传学结合后形成"**现代综合**"，成为生物学的统一框架。
- 它深刻影响了哲学、社会科学乃至宗教，争议至今未息。

> 📝 编者注：达尔文并非"第一个提出进化的人"，但他第一次给出了可检验的**机制**（自然选择）并以系统证据支撑，这才是其历史地位所在。

## 一个「平庸学生」的一生

查尔斯·罗伯特·达尔文（1809—1882）生于什鲁斯伯里一个富裕的知识家庭：祖父伊拉斯谟·达尔文是诗人兼医生，早有演化猜想；父亲是成功的医生；母亲来自韦奇伍德陶瓷家族。他被父亲斥为「整天只知道打猎、玩狗、抓老鼠的平庸孩子」：爱丁堡学医因惧怕手术而逃，剑桥为当乡村牧师而读神学，却是昆虫采集与地质学的热情把他引上正途——植物学教授亨斯洛推荐他（以「绅士旅伴」而非博物学家的名义）登上贝格尔号，开始了决定其一生的五年环球航行（1831—1836）。

回到英国后他定居肯特郡唐恩小筑（Down House）四十年，晨间写作、午间散步、晚间与妻子爱玛对弈与朗读——一生未再远行，却以书信（据估计逾一万五千封）织成十九世纪最庞大的科学通讯网。他一生饱受不明疾病的折磨（心悸、呕吐、皮疹，现代医学有替加厚斯蒂的「循环性呕吐综合征」、查加斯病、焦虑症等多种假说），却以惊人自律完成二十余部著作：藤壶四卷（八年，使他成为该领域权威）、《物种起源》（1859）、兰科植物、动植物在家养下的变异、《人类的由来》《人与动物的情绪表达》（1872）。1882 年卒，国葬于威斯敏斯特教堂，与牛顿为邻。

> 📜 「我一生中的主要乐趣和唯一职业，就是科学工作；这种工作引起的兴奋，使我暂时忘却或驱除了日常的不适。」 —— 达尔文《自传》
