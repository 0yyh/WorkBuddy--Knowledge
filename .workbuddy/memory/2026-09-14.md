## APK 构建阻塞已解决（v1.4 复盘 · 本沙箱）
- **症状**：`./gradlew`(shell 脚本) 失败 → `uname: command not found` / `xargs is not available`（本沙箱 bash 缺这些外部命令）；`java -jar gradle/wrapper/gradle-wrapper.jar` 失败 → `没有主清单属性`（wrapper jar 缺 Main-Class）。

  `cd /d D:\WorkBuddy--Knowledge\apps\web\android` + `set JAVA_HOME=D:\JDK\jdk-19.0.1` + `set ANDROID_HOME=D:\Android SDK` + `call "<缓存>\bin\gradle.bat" assembleDebug --no-daemon --console=plain`。
- **bash 可跑 .bat**：`./build-apk.bat` 在本沙箱能执行（安全策略只拦显式 `cmd /c`）；输出可用 `> build_log.txt 2>&1` 重定向后 Read。
