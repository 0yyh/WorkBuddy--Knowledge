## 小说阅读页两处修复：字数口径统一 + 面板动画性能

### 1. 字数统计口径不一致（详情页总字数 ≠ 章节字数之和）
- **根因**：`packages/core/src/index/builder.ts` 的 `w` / `cover.word_count` / `titleIndex.words` / `stats.words` 只统计 `entry.md` 导读正文，章节字数在别处累计 → `hegel` 详情页显示 1775，而 4 章实为 8411。
- **修复**：builder 统一为一个口径 `entryTotalWords = 有内容章节时 Σ(非 container 章节 words)，否则回退 entry.md 正文`；container（卷）行不计入、也不显示，避免与子孙双算。`w` / `word_count` / `titleIndex.words` / `totalWords` 全部由它派生。
- **UI 兜底**：`EntryCoverPage.tsx` 的「字数」= 目录中 content 行 `ch.words` 逐行求和（与下方展示严格一致）；无内联目录（超长词条）时回退 `cover.word_count`。
- **校验**：全量扫描 122 词条，`w === Σ(非 container 章节 words)`，0 不一致；hegel 8411 = 2442+2523+2699+747。
- **章节增/改/删后刷新**：字数在构建期计算，跑 `npm run build:index`（增量按内容指纹重算该词条）即同步；若怀疑产物陈旧，`npm run pks -- build:index --full` 强制全量。

### 2. 呼出目录/设置/间距/更多面板掉帧
- **根因（4 条）**：① `.reader-sheet` 上 CSS `@keyframes sheet-up` 与 `BaseSheet` 的 inline `transition` 双机制并存（关键帧优先级高于 inline style → 入场期间覆盖 inline，且两套时长/曲线不同）；② `@keyframes sheet-up` 在 styles.css 有**两份同名定义**，「后者胜出」→ 实际生效的是无 opacity、无 translate3d 的那份；③ 遮罩 `backdrop-filter: blur(2px)` 每帧重算背景快照；④ `useSheetDrag` 每次 pointermove 都 `setTranslateY` → 每帧 React 重渲染（目录面板可达上千节点）。
- **修复**：`tokens.css` 新增 `--sheet-duration/-ease-in/-ease-out`、`--mask-duration/-ease`；面板位移改**单一 transform 过渡**（挂载后双 rAF 再展开，把首帧重排与动画启动错开）；`closing` 由 `open` **派生**（消除"回弹一帧再下滑"）；遮罩改 opacity 过渡 + 去模糊；`useSheetDrag` 改 rAF + 直写 `el.style.transform`（拖拽全程 React 只渲染 2 次）；`.reader-sheet`/`.reader-more-sheet` 加 `will-change:transform`、`overscroll-behavior:contain`；`.chapter-group` 加 `content-visibility:auto`。
- **新增** `apps/web/src/components/sheet/SubSheet.tsx`：字体/间距/更多三个子层共用壳。原先三子层是父级条件渲染、直接摘除，**没有收起动画**；现改「常驻渲染 + open 驱动」，由 SubSheet 播完退场再卸载（`EntryReaderPage` 三处调用同步改造）。
- **样式对象键顺序铁律**：`{ transition, transform }`（transition 在前）。React 按对象键序逐个 setProperty，顺序颠倒会用上一个状态的曲线（收起时走成入场曲线）。
- 删除 styles.css 中一份被覆盖的同名 `@keyframes sheet-up`（**末尾那份被 `.confirm-sheet` 使用，必须保留**）。
