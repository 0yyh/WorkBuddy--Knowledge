## dev server 独立启动（无需 Agent）
- 前台我方启动命令（沙箱 PATH 污染故走绝对 node 入口）：`cd apps/web && node node_modules/vite/bin/vite.js --host 127.0.0.1 --port 5173`（任务曾为 `GWIhg4`，2026-09-12 已 TaskStop 关闭）。
- **用户终端必须用 managed Node 22.22.2 启动**：系统默认 `node` 很可能是 Node 16，Vite 5.4 在 `resolveConfig` 阶段调用 `crypto.getRandomValues`，Node 16 没有该 API，会报 `TypeError: crypto$2.getRandomValues is not a function`。
  - 推荐命令：
    ```cmd
    cd D:\WorkBuddy--Knowledge\apps\web
    C:\Users\Yu\.workbuddy\binaries\node\versions\22.22.2-3\node.exe node_modules\vite\bin\vite.js
    ```
  - 默认 `http://localhost:5173/`；需要显式 host/port 则加 `--host 127.0.0.1 --port 5173`。
  - `npm run dev` 本身没问题，但它会调用 PATH 上那个 `node`；若 PATH 是 Node 16 就会触发上述错误。必须保证运行时 node 为 22.22.2。
- vite 无 `--root`，必须 cd 进 `apps/web` 再跑。
- 依赖已就绪，**不要跑 `npm install`/`pnpm`**（@pks/core 靠手工 junction，`npm install` 会断构建链路）。
- 内容/词典需先投递进 `apps/web/public/content`（gitignored）：`npm run build:index && npm run build:chardict && npm run copy:content`（根目录或按脚本所在位置跑）。`public/content` 已含有当前 index.json + 词典，故直接 `npm run dev` 即可看到效果；改内容/词典后才需重跑上述三步。
