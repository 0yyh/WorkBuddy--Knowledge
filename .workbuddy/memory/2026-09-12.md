## APK 打包（核对事实，供用户自助打包）
- 环境：Node 22.22.2（managed，Vite5 需 ≥20.11）；`JAVA_HOME=D:\JDK\jdk-19.0.1`（JDK17+，AGP 8.7.2/Gradle 8.11.1）；`ANDROID_HOME=D:\Android SDK`（需 SDK Platform 35 + Build-Tools + platform-tools）。
- 脚本：root `android:build` = `npm --prefix apps/web run android:build` = `cap sync android && cd android && gradlew assembleDebug --no-daemon`。**注意 android:build 不含 vite build**！web 产物必须另行构建，否则 cap sync 拷入旧 dist。
- 完整顺序：`build:index`（内含 `tsc -p packages/core`）→ `build:chardict` → `content:copy` → `(cd apps/web && npm run build)` 或 root `npm run build` → `android:sync` → `(cd apps/web/android && gradlew assembleDebug --no-daemon)`。
- 关键配置：`capacitor.config.ts`（appId `com.pks.app`/appName `知识`/webDir `dist`/`android.allowMixedContent:true`）；`variables.gradle`（compileSdk35 / targetSdk34 / minSdk23 / androidxCore 1.13.1）；root `android/build.gradle` 用 `subprojects.afterEvaluate` 把 compileOptions 覆写为 Java17（覆盖 cap 生成的 Java21）；`app/build.gradle` versionCode 1 / versionName "1.0"，**无 signingConfigs → release 为 unsigned**；`AndroidManifest` `usesCleartextTraffic=true`（另一道门，非 WebView 混合内容开关）；`local.properties` 存 `sdk.dir`（gitignored，本机私有）。
- 产物路径：debug = `apps/web/android/app/build/outputs/apk/debug/app-debug.apk`；release = `.../outputs/apk/release/app-release-unsigned.apk`；AAB = `.../outputs/bundle/release/app-release.aab`。项目根 `release/` 是**手工归档目录**（历史 `pks-app-2026-09-10*.apk`），Gradle 不自动写入；root `.gitignore` 忽略 `release/`、`*.apk`。
- 首次构建：`gradlew` 会下载 `gradle-8.11.1-all.zip`（需联网，约 200MB+）；`cap sync` 会重写 `capacitor.build.gradle`/`capacitor.settings.gradle`/`app/src/main/assets/public` 与 `capacitor.config.json`。
- 内容 vs 代码：仅内容变更无需重打 APK，走 `build-update` + `serve-lan` 的局域网 OTA 即可；只有**代码/依赖/原生配置**变更才需重打包。
- 操作文档已落盘：`docs/reports/APK打包操作说明.md`（含 TL;DR 清单、逐步操作、输出路径表、debug/release/AAB 差别、参数速查、报错对策、脚本速查）。
