## 4. 派发批次（与薄章批次同机制）

每批一个领域、一个作者 worker（或并行多 worker），统一 brief：
- 读 `PHILO_SPEC.md` + `AUTHORING_BRIEF.md` 严格守格式；
- 每章正文 **纯汉字 ≥1200**，末行 `<!-- PKS_EXPANDED_V5 -->`；
- `sources[].title` 一律双引号；`see_also` slug 必须已存在（优先互链本批/已有词条）；
- `categories` 用 taxonomy **标题路径**；
- 写后 `git status` 核查、lint 零 error 再 commit。

**批次清单（阶段一）**
1. `tech`：能源/信息/制造/交通 各补 7–8 条（→64）
2. `lit`：中国文学（古/近现）+ 世界文学（欧/亚非）+ 文论（→40）
3. `art`：艺术史/绘画/雕塑/音乐/建筑/影视/设计（→40）
4. `rel`：世界五大宗教各 3–4 + 宗教哲学 4 + 宗教史 3（→24）
5. `ling`：普通/音系/句法语义/历史/社会心理 各 4（→20）
6. `law`：法理学/宪法/民法/刑法/国际法/法律史 各 3–4（→20）
7. `sci-deep`：物理/化学/生物/天文/数学基础 各补 2–3（→90）
