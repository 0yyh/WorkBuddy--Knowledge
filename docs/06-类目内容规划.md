## 2. 逐类目规划

### 2.1 历史（chronological 双轨）

**子类目 / L2 骨架**

- **世界史（W01–W10）**
  - W01 史前与文明起源（农业革命、早期国家）
  - W02 古代近东 / 埃及 / 两河
  - W03 古典希腊与罗马
  - W04 中世纪欧洲（封建、教会、十字军）
  - W05 伊斯兰黄金时代 + 东亚中世（唐—宋—幕府）
  - W06 文艺复兴 / 大航海 / 宗教改革
  - W07 科学革命 / 启蒙 / 英法国美革命
  - W08 工业革命 / 殖民扩张 / 19 世纪
  - W09 第一次世界大战 / 第二次世界大战 / 冷战
  - W10 当代（1945 后 / 全球化 / 数字时代）
- **中国史（C01–C13）**
  - C01 先秦（史前—夏商—西周—春秋战国）
  - C02 秦汉（大一统确立）
  - C03 三国两晋南北朝（分裂与融合）
  - C04 隋唐（盛世与科举）
  - C05 宋（文官政治、经济高峰）
  - C06 元（蒙古帝国、多民族）
  - C07 明（专制强化、海禁与朝贡）
  - C08 清前中期（康雍乾、疆域定型）
  - C09 晚清（内忧外患、变局）
  - C10 民国（共和试验、战乱）
  - C11 共和国前 30 年（建政与探索）
  - C12 改革开放（经济转轨）
  - C13 当代（新时代）

**内部编排**：两条 Track 并列——`世界史主线` 与 `中国史主线`；节点**交叉标注同期对照**（如 `W07 法国大革命 ↔ C05 清乾隆同期`），UI 可一键"看同期的世界/中国"。大类目下挂"时期"节点，时期下挂"事件/人物"词条。

**密度轴（要点 ↔ 全文）**：
- 著作级 `summary`（时期）：`{ tldr: 该时期一句话定位, keyPoints: [转折事件], whyRead, readingTime }`
- 章节级 `section.summary`（事件/人物）：`{ tldr: 事件因果一句话, keyPoints: [起因/经过/影响] }`
- 全文 `section.body`：叙事化正文（长文 chunk 化）。

### 2.2 哲学（thought-history 时序）

**子类目 / L2 骨架**

- **中国哲学**：先秦诸子（儒墨道法名阴阳）、汉唐经学玄学、儒道释交融、宋明理学与心学、近现代转型（中西会通）
- **西方哲学**：古希腊（前苏格拉底—柏拉图—亚里士多德）、中世纪（奥古斯丁—阿奎那）、近代（笛卡尔唯理—洛克经验—康德）、德国古典（费希特—黑格尔—费尔巴哈）、现代（分析哲学—存在主义—现象学—欧陆）
- **其他传统（可选）**：印度哲学、伊斯兰哲学、非洲/拉美思想

**内部编排**：以"思想史时序"为主 Track（如 `从孔子到维特根斯坦`）；**思想家 = 著作级节点**，下设代表作；**流派 = 聚合节点**（把同倾向思想家聚类）。争议命题（如"自由意志"）可跨时代聚合为多视角。

**密度轴**：
- 著作级 `summary`（思想家）：`{ tldr: 核心命题一句话, keyPoints: [生平/代表命题/影响], whyRead }`
- 章节级 `section.summary`（单篇/单章）：`{ tldr: 论证要旨, keyPoints: [前提/推论/结论] }`

### 2.3 科学（difficulty 递进）

**子类目 / L2 骨架**

- **数学**（算术→代数→几何→微积分→概率统计→离散）
- **物理**（运动→力→能量→电磁→相对论→量子）
- **化学**（元素→键→反应→周期→有机）
- **生物**（细胞→遗传→进化→生态→神经）
- **地球与天文**（太阳系→地质→气候→宇宙学）
- **认知 / 神经（可选）**、**计算基础（可选）**

**内部编排**：以"难度阶梯"为主 Track（如 `从数到宇宙`）；**概念 = 节点**，公式是节点的 section；依赖关系隐含在顺序里（先"力"后"能量"）。

**密度轴**：
- 著作级 `summary`（学科/大主题）：`{ tldr: 该领域一句话, keyPoints: [核心概念], whyRead }`
- 章节级 `section.summary`（单概念）：`{ tldr: 概念要义, keyPoints: [直觉/形式化/应用] }`
- 全文：阐述 + 例子 + 公式推导（公式以 `section.body` 内 Markdown 数学块呈现）。

### 2.4 金融（dependency 依赖序）

**子类目 / L2 骨架**

- **货币与银行**（货币本质、利率、央行）
- **投资与证券**（股票、债券、基金）
- **宏观经济指标**（GDP、通胀、就业）
- **风险管理**（分散、对冲、保险）
- **衍生品（可选）**（期权、期货）
- **个人理财**（预算、复利、退休规划）

**内部编排**：以"依赖链"为主 Track（如 `从钱到资产`：货币 → 利率 → 债券 → 久期 → 组合 → 风险）。强调**前置概念未读则后继概念标"依赖未满足"**，引导顺序学习。

**密度轴**：
- 著作级 `summary`（工具/品种）：`{ tldr: 这是什么, keyPoints: [干嘛用/风险点], whyRead }`
- 章节级 `section.summary`（单条款/单公式）：`{ tldr: 条款要点, keyPoints: [定义/例子/例外] }`

### 2.5 政治理论（school + 时序）

**子类目 / L2 骨架**

- **政治哲学**：柏拉图→亚里士多德→霍布斯→洛克→卢梭→密尔→当代（罗尔斯等）
- **意识形态**：自由主义 / 保守主义 / 社会主义 / 马克思主义 / 法西斯主义（**多视角并存**，见 `04 §1.5`）
- **中国政治理论**：马列 → 毛 → 邓 → 三代 → 科学发展观 → 新时代（专门 Track）
- **国际关系理论**：现实主义 / 自由主义 / 建构主义

**内部编排**：以"学派聚类 + 时序"为主；争议话题（如"公平 vs 效率"）**并排列多视角来源**，UI 以"观点 A / 观点 B"呈现，不主张唯一正确。中国马克思主义走独立 Track，与 `02` 的"大部头著作两级提炼"强绑定（毛选/邓选等先要点后原文）。

**密度轴**：
- 著作级 `summary`（思潮/流派）：`{ tldr: 核心主张, keyPoints: [代表/批评], whyRead }`
- 章节级 `section.summary`（单文献/章节）：`{ tldr: 本章论点, keyPoints: [前提/主张/争议] }`

## 3. 工作量排产（含两级摘要 ×2）

对齐 `01b §7`：

| 批次 | 目标 | 内容 | 规模 | 两级摘要增量（×2） | 验收标准 |
|------|------|------|------|-------------------|----------|
| **B0** 骨架验证 | 跑通全链路 | 每学科 3 条（共 15）+《共产党宣言》整本 + 2 Track（中国史前 10 / 金融前 5） | ~20 词条 / ~8 万字 | 著作级 ~16 份 + 章节级 ~10 份（宣言有章节） | ① Web+Android 渲染 ② 序列导航 ③ 导出 zip→手机导入 |
| **B1** 五线并开 | 每学科一条入门路径 | 哲学 20 / 历史 20（世 10+中 10）/ 科学 20 / 金融 20 / 政治理论 20 = **100 条** + 5 Track | ~100 词条 / ~30 万字 | 著作级 ~100 份 + 章节级 ~150–300 份 | ① 五路径点通无断链 ② 历史双时间线切换 ③ 冷启动 ≤2s ④ Lint 全绿 |

> **要点**：两级摘要（著作级 + 章节级）是 `04 §2.5` 强制要求，等于在原有正文之上**再生成约 1–2 倍的结构化摘要文本**。排产必须把这部分计入 Lint 与生成耗时，不能只算正文。
> **大部头著作（B2 起）**：马恩/毛选/邓选等的"章节级摘要"量最大（每本数十章），应优先做模板化生成 + 助手抽校。

## 4. 类目扩展机制（未来加类目怎么搞）

类目由 **`taxonomy.yaml` 驱动**（见 `02` 架构），新增类目尽量**零代码改动**：

1. 在 `taxonomy.yaml` 增加 `category` 块：
   ```yaml
   - id: literature
     name: 文学
     order_axis: thought-history      # 复用既有 5 种策略之一，或自定义
     slug_root: lit
     record_policy: T2                 # 可录策略档（见 04 §2.4.5）
     children: [poetry, novel, drama]  # L2 子类
   ```
2. 内容仓库新增对应目录（如 `content/lit/`），放种子条目（md + yaml）。
3. **索引 Worker 自动扫描新目录**生成分片——slug 命中既有分片算法（`fnv1a(slug)&15`，16 片），无需改索引代码。
4. 可选：在 `tracks/` 增加该类的顺序 Track 定义。
5. UI 类目树与底栏 Tab 由 taxonomy 派生，新增类目自动出现。

> 顺序轴策略可复用：`chronological / sequence / thought-history / difficulty / dependency / school`，不够用时在 yaml 里声明自定义 `order_axis` 并在排序函数加一个分支即可（这是唯一可能需要动代码的点）。

## 5. 通识大家建议：未来可加哪些类目

现有 5 类（历史/科学/金融/哲学/政治理论）偏"硬通识 + 社会"。作为通识大家，我建议按优先级补以下类目，使知识图谱更完整：

### Priority A（强烈推荐，与现有 5 类互补的核心通识）

| 候选类目 | 与现有关系 | 建议顺序轴 | 一句话理由 |
|----------|-----------|-----------|-----------|
| **文学（Literature）** | 与哲学并列"人文双柱" | thought-history / 流派 | 人类精神另一半；读人不只读思想，还要读叙事与情感 |
| **心理学（Psychology）** | 桥接哲学与科学 | difficulty / 主题聚类 | 理解"人自身"的刚需，解释行为动机 |
| **法律（Law）** | 与政治理论强相关 | 体系 / 部门法 | 社会运行规则，政治理论的落地形态 |
| **艺术 / 美学（Art）** | 独立审美维度 | 时期 / 流派 / 媒介 | 审美素养，补足"真善美"的美 |
| **经济学（Economics）** ⚠️ | **区别于"金融"** | 概念依赖 | 金融是市场应用，经济是稀缺配置原理——二者必须拆开 |

### Priority B（进阶通识，建议 B2 后逐步引入）

| 候选类目 | 与现有关系 | 建议顺序轴 | 一句话理由 |
|----------|-----------|-----------|-----------|
| **医学 / 健康（Medicine）** | 实用刚需 | 系统 / 主题 | 身体素养，人人用得上 |
| **地理 / 世界（Geography）** | 与历史互补（空间 ↔ 时间） | 区域 / 主题 | 空间认知，理解"为何此地非彼地" |
| **计算机与信息（Computing）** | 数字时代素养 | difficulty | 做"通识科普"非编程教学 |
| **宗教（Religion）** | 与哲学/历史交叉 | 传统聚类 + 时序 | 理解文明底层动机 |
| **语言学（Linguistics）** | 与哲学/文学交叉 | 主题 / 历时 | 语言即思维，理解符号 |

### Priority C（纵深 / 兴趣向，按需）

| 候选类目 | 说明 |
|----------|------|
| **逻辑学（Logic）** | 方法论基石；可并入哲学或独立成类 |
| **军事 / 战略（Military）** | 与历史/政治交叉，理解冲突结构 |
| **环境 / 生态（Environment）** | 当代生存议题，跨科学+政治 |

> **特别提示**：用户当前定的是"暂时 5 类，未来可能加"。我的建议是**一期先把 5 类做扎实、跑通端到端**；**文学 / 心理学 / 经济学**作为最自然的扩展首选（分别与哲学、科学、金融相邻），列入 B2 候选而非一期，避免过度铺摊子拖慢首个可用版本。

### 7.4 §2.4 金融 → 经济学（含金融）（★ 最大结构修订，替换 v1 §2.4）

**2.4 经济学（dependency 依赖序；金融为其 L2 应用子类）**

**子类目 / L2 骨架**
- **经济原理·微观**：稀缺与选择 / 供需与市场均衡 / 弹性与税收 / 消费者与生产者行为 / 市场结构（完全竞争→垄断）/ 博弈论入门 / 市场失灵（外部性·公共品·信息不对称）
- **经济原理·宏观**：国民收入核算 / 总需求—总供给（AD-AS）/ 货币与财政政策 / 失业与通胀 / 经济增长 / 开放经济（汇率·国际收支）
- **金融**（应用分支，原"金融"L1 降级为 L2 聚合节点）——下设 L3：货币银行与货币政策 / 投资与资产定价 / 固定收益与权益市场 / 公司金融 / 衍生品与风险管理 / 金融市场与机构 / 金融史与危机 /（可选）投资流派与经典著作 /（可选）个人理财
- **经济思想史**（重商→古典→边际革命→凯恩斯→货币主义→新古典综合→新凯恩斯；与 政治理论/政治经济学 复用条目，**不重复建库，靠 categories[] 多归属**）
-（可选，B2+）计量与经济方法 / 公共财政 / 国际经济学——延伸池，不进一期 B0/B1。

**内部编排（多条 Track 并挂经济学节点，全在封闭枚举内）**：
1. `economics-principles-main`（dependency）：稀缺→供需→微观行为→市场结构→宏观核算→AD-AS→货币财政→增长（原理线，软依赖，允许宏观/微观段并行）；
2. `finance-core`（dependency，挂节点 **经济学/金融**）：**沿用既有 Track 文件与全部 items/requires，仅 `category` 从"金融"改为"经济学/金融"**——旧金融 L1 的"单线不跳级 + ⚠前置依赖提示"全部保留（这是迁移不改 Track 的证据）；
3. `economics-thought-history`（chronological，思想史线，可选 B1 少量/B2 铺）。

**顺序轴关键裁决**：金融不"继承"经济学上层模式——order_mode 是 Track 级属性、非 L1 级"继承"概念；金融保留自己的 dependency Track（依赖最强、必须单线），经济学原理另立 dependency Track，两者并列于经济学节点下。用户只学金融可从 finance-core 进入；只学原理从 economics-principles-main 进入；两线不互相强制。横跨两线的词条（如"利率"）用 categories[] 双归属 + requires[] 仅在**同一条 Track 内**做前置约束，**不做跨 Track 硬依赖**。

**密度轴**：经济学原理词条沿用科学行（summary + section.summary + 正文，公式用 Markdown 数学块）；金融子类沿用旧"工具/品种/条款"形态（工具 summary + 章节级 section.summary + 全文）。
