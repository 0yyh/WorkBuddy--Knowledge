## 4. 两条红线

### 红线 A｜framer-motion（依赖安装）

`@pks/core` 靠**手工 symlink** 解析（`apps/web/node_modules/@pks/core → packages/core`）。任何 `npm install` / `pnpm install` 都会重建 `node_modules` 并**断链**，导致构建直接失败。

**三条路径：**

- **路径 1（强烈推荐）：不引入。** 交错入场用 `style={{'--i': i}}` + `animation-delay: min(calc(var(--i,0) * 40ms), 320ms)`；按压反馈用 `:active { transform: scale(0.985) }`。约 15 行 CSS + 每列表 1 行 JSX，**零依赖、零 install、零 bundler 改动**。`min()` 在 Chromium 79+ 可用，Capacitor 7 的 WebView 远高于此。
- **路径 2（不推荐）：手工安装。** 需备份 symlink → 临时目录 `npm pack` 取 tgz → 手工解包 → 手工编辑 package.json → 补 vite `optimizeDeps` → install 后立即重建 symlink 并验证。**任何一次后续 install 都会重演断链**，且需手工补齐传递依赖。
- **路径 3（折中）：自研 `useStagger` hook + CSS。** 零依赖，但路径 1 已足够，无需 hook。

**结论：走路径 1。**

### 红线 B｜Google Fonts（离线）

| 方案 | 体积 | 结论 |
|---|---|---|
| 现状：系统字体栈 | **0 字节** | ✅ 安卓自带 Noto Sans CJK / 宋体，衬线观感已可得 |
| Google Fonts CDN | 0 字节本地，但**运行时联网** | ❌ 违反红线 B 与 Q23「无 INTERNET 权限」 |
| 内嵌 Noto Serif SC 常用 3500 字（GB2312）子集 woff2 | ≈ **1.5–2.5 MB** | 体积可接受（6.9MB→≈9MB，远低于 80MB 上限），但需子集化工具链 |
| 内嵌通用规范汉字 8105 字子集 | ≈ **3.5–4.5 MB** | 同上 |
| 完整 Noto Serif SC | ≈ 5–10 MB | 不划算 |
| Inter 拉丁子集 ×2 字重 | ≈ **0.2–0.3 MB** | 便宜，但中文场景收益有限 |

**关键判断：体积根本不是瓶颈（6.9MB→9MB 仍在上限的 1/9）。否决它的唯一理由是"CDN 运行时联网"违反红线 B。**

若未来确需非系统衬线观感：**只允许子集化后打包进 APK（不得用 CDN）**，且仅限阅读区、字集 ≤3500 字；代价是引入 fonttools/pyftsubset 之类子集化工具链（又一条依赖，需单独评审）。**当前不做。**

## 5. 「零新增依赖」改造方案

> 以下只说明"改哪个文件的哪类规则"，不含实现代码。全部纯 CSS + 极少量 JSX 属性，**不引入任何依赖、不跑 install**。

### P0（零依赖、低成本高收益）

**1. 列表交错入场（唯一真正缺失、性价比最高）**
- `styles.css` 新增 1 个 `@keyframes list-in`（仅 `opacity` + `translateY`，GPU 合成）
- 作用于 `.card-list > li`、`.result-card`、`.tl-item`、`.chapter-row`；`animation: list-in .28s var(--ease) both`；`animation-delay: min(calc(var(--i,0) * 40ms), 320ms)`（封顶防止长列表尾部等待过久）
- JSX：上述列表的 `.map()` 里给每项加 `style={{ '--i': i }}`（每列表 1 行）
- **必须尊重既有偏好**：用 `body:not([data-sys-anim='none'])` 包裹，并补 `@media (prefers-reduced-motion: reduce)`——设置页已有「页面动画：无」开关（`styles.css:433`），不可绕过
- 收益：首页/分类/搜索/时间轴/目录 5 处列表同时获得层次感

**2. 按压反馈（补齐移动端触摸反馈）**
- 现状 8 类元素有 `:active`，但 **`.card-hover`、`.track-card-link`、`.tl-item` 只有 hover 没有 active**——移动端无 hover，等于触摸零反馈
- 改法：补 `:active { transform: scale(0.985) }`；注意 `.card-hover:hover` 已有 `translateY(-2px)`，active 态要写成 `translateY(-2px) scale(.99)` 合并，避免互相覆盖
- 只动 transform/opacity，**禁止动画 box-shadow（触发重绘）**

**3. 时间轴 `.is-cross` 竖线染紫**
- 现状 `.tl-item.is-cross` 已把圆点染紫（`#6b3fd4`）、卡片染紫渐变，**但竖线 `.tl-rail::before` 仍是 `--border` 灰**，紫色在竖直方向断掉
- 改法：给 `.tl-item.is-cross .tl-rail::before` 同步染紫（1 条规则），双轨对照视觉即连贯

### P1（需验证或涉及取舍）

4. **阅读器底栏毛玻璃**：默认不做。现为 `rgba(255,255,255,.96)`，96% 遮挡下 blur 增益≈0 却要在最吃性能的页面常驻合成层。若一定要：降到 ~0.72 alpha + blur，**做成设置项默认关**，并在低端真机验证帧率后再决定。
5. **`Segmented` 复用**：`SettingControls.tsx` 已导出 `Segmented`/`ColorSwatches`/`GroupTitle`，可直接复用到搜索模式切换（L1 标题 / L2 全文）、排序等处，不必新造。
6. **小修**：`SettingsPage` 的 `FAMILY_OPTIONS` 只有「宋体/黑体」，但 `FontFamilyPref` 支持 `kai`/`mono` → 补两个选项（1 行，属既有能力未暴露）。

### P2（锦上添花）

7. 卡片静息态阴影微调（只动 `--shadow-sm`，**不要动 `--shadow-md` 的暖色调**）
8. 字体子集内嵌（仅当确认需要非系统衬线观感，且必须打包进 APK 而非 CDN）

### 否决清单

framer-motion、MUI `createTheme`、`tailwind.config`、Google Fonts、底栏默认毛玻璃、时间轴重做。

## 7. 附：本次评审的方法论教训

外部 AI 生成的优化方案，在**未读取代码**的情况下，其"手段层"建议几乎必然与实际技术栈脱节。使用这类方案时应：

1. **先核对技术栈**（package.json + 配置文件 + 源码 grep 三重验证），再评估建议；
2. **区分"目标"与"手段"** —— 目标（暖色、大圆角、层次感）可能有效，手段（createTheme、tailwind.config）可能完全不可用；
3. **用当前版本截图**，不用旧版本；
4. 涉及**依赖安装**的建议，一律视为架构级决策，走评审而非直接执行。
