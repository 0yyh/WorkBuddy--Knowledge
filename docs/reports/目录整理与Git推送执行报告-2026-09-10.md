## 二、Q1：`git init` 前置修复 —— `.gitignore`

**问题**：原 `.gitignore` 整行忽略 `apps/web/android/`，导致 Capacitor 生成后**手改的 Gradle 配置**（`variables.gradle` 的 targetSdk / `build.gradle` 的 Java 17 覆盖 / `MainActivity.java` 返回拦截等）全部不入库 —— 换机后无法重建 APK。

**修复**：改为精确忽略，只排除构建产物与机器相关文件：

```gitignore
apps/web/android/.gradle/
apps/web/android/build/
apps/web/android/app/build/
apps/web/android/app/src/main/assets/public/
apps/web/android/local.properties
```

同时新增：`release/`、`*.apk`、`*.tsbuildinfo`、`*.timestamp-*.mjs`、`.backup-*/`；
`.workbuddy/*` 但保留 `!.workbuddy/memory/`（项目记忆需入库）。

**验证**：

- `git check-ignore -v apps/web/android/app/build.gradle` → 未命中（会被跟踪）
- `git check-ignore -v apps/web/android/local.properties` → 命中（正确忽略）
